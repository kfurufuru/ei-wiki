# ChatGPT活用

## 30秒まとめ

ChatGPT は対話型AIサービスで、質問への回答・文書作成・翻訳・要約を扱える。無料版と有料版でモデルと機能が異なる。業務では仕様書ドラフトや英語資料の読解に向くが、出力の検証は利用者の責任。

---

## ChatGPTとは

OpenAI社が開発した対話型AIサービス。ブラウザ（`chatgpt.com`。**旧 `chat.openai.com` は現行の入口ではありません**）またはスマホアプリから利用できる。

テキストを入力（チャット）するだけで、質問への回答・文書作成・翻訳・要約など幅広いタスクをこなす。

---

## 無料版と有料版の違い

| 項目 | 無料版 | 有料版 |
|------|--------|--------|
| 使えるモデル | 軽量・標準モデル中心 | 高性能モデルを優先利用 |
| 利用制限 | あり（混雑時・利用量で制限） | 制限が緩和・優先アクセス |
| おすすめ対象 | 試してみたい人・軽い用途 | 毎日業務で使う人 |

!!! note "プラン名・料金・機能の範囲は公式ページで確認"
    プラン名・料金・各機能（画像入力・データ分析等）の提供範囲は頻繁に変わるため、本ページには記載しない。契約前に必ず公式の料金・プラン比較ページで最新情報を確認すること。

!!! tip "まずは無料版で試す"
    無料版でも基本的な文書作成・翻訳・Q&Aは十分使える。毎日使いたいと感じたら有料版を検討。

---

## 基本操作

1. `chatgpt.com` にアクセス（またはアプリを起動）
2. テキストボックスに指示を入力して送信
3. 回答が表示される
4. 不満足な場合は「もっと具体的に」「箇条書きで」「例を追加して」と追加で依頼
5. 新しい話題は「New chat」で新しい会話を始める（会話が長くなると精度が落ちる場合がある）

## 業務別プロンプト例

### 技術調査

```
電気計装エンジニア向けに、HARTプロトコルの以下を説明して：
1. 基本的な仕組み（4-20mAとの関係）
2. HART対応機器で何ができるか
3. 現場での活用場面

専門用語を使ってよいが、各項目は3〜5行程度で簡潔に。
```

### トラブル解析

```
電気計装エンジニアとして回答して。

症状：圧力伝送器（4-20mA、2線式）の出力が急に4mAになった。
設備：DCS側で断線アラーム発報。現場でループ電源確認済み（24VDC正常）。
試したこと：端子台の接触確認済み（異常なし）。

原因候補を確率が高い順に5つ挙げて。各原因に対して現場での確認手順も教えて。
```

### 仕様書ドラフト

```
以下の条件で電動バルブの計装仕様書（概要版）を作成して：
- バルブ種別：電動ゲートバルブ
- 配管口径：4インチ（100A）
- プロセス流体：温水（80℃以下）
- 制御方式：DCSからの開閉指令（DO出力）
- 開閉確認：リミットスイッチによるDI入力
- 電源：AC100V単相
- 防護等級：IP65以上
- 記載項目：概要・電気仕様・信号仕様・設置条件

項目ごとに整理して、A4 1枚程度の内容で。
```

### メール作成（社外向け）

```
以下の内容でメーカーへの問い合わせメールを作成して：
・件名：〇〇（型番）の予備品の在庫確認
・確認したい内容：部品A（品番：XXXXX）の現在の在庫状況と納期
・急いでいる理由：設備の予防保全で翌月に使用予定
・文体：丁寧なビジネスメール、件名〜署名まで

社名・個人名は「〇〇」のままにしておいて。
```

### 英語資料の翻訳

```
以下の英文技術仕様を日本語に翻訳して。
電気計装の専門用語は適切な日本語の業界用語に変換すること。

[英文を貼り付け]
```

## 他ツールとの使い分け

各ツールの得意分野は**モデルの世代交代で入れ替わる**ため、固定的な優劣は書かない。以下は「どんな軸で使い分けるか」の目安。

| 使い分けの軸 | 目安 |
|------|------|
| 長文ドキュメントの作成・読解 | 一度に扱える文章量（コンテキスト長）が大きいツール・プランを選ぶ |
| Web検索が必要な最新情報の調査 | 検索連携機能を持つツール（ChatGPT・Microsoft Copilot（旧 Bing Chat）等の検索モード）を使う |
| Officeツールと連携した作業 | [M365 Copilot](m365-copilot.md)（Word・Excel・Outlook との統合が強み） |
| コード作成・データ分析 | コード実行機能を持つツール・プランを使う（機能名は改定されることがある） |

!!! note "同じ用途でも実際に試して選ぶ"
    「どのAIが賢いか」はモデル更新のたびに変わる。定型業務に組み込む前に、自分のタスクで数回試して出力品質を比較するのが確実。

## 注意事項

!!! danger "社外秘情報の入力は禁止"
    ChatGPT・Claude.aiは個人向けサービスで、入力内容がOpenAI/Anthropicのサーバーに送信される。
    **設備の詳細情報・プロセス条件・社外秘の業務情報は絶対に入力しない。**
    社内データを外部サービスに入力してよいかの最終判断は**社内規程・IT部門**による。
    詳細は[注意事項・情報セキュリティ](security.md)を参照。
