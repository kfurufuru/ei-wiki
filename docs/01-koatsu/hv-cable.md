# 高圧ケーブル

## 30秒まとめ

6.6kV 回路の標準は CV（架橋ポリエチレン絶縁）ケーブル。許容電流は布設条件で大きく変わる。水トリーイングによる絶縁劣化が高圧ケーブルの主要劣化メカニズム。定期的な絶縁診断が必須。

---

## CV と CVT の違い

| 項目 | CV | CVT |
|------|----|----|
| 構造 | 3芯一括 | 3芯を撚り合わせたトリプレックス形 |
| 可とう性 | 低い（径が太い） | 高い（取り扱いやすい） |
| 熱放散 | やや劣る | 良好 |
| 接続作業 | 比較的容易 | 各心を個別に処理（端末部材は単心用） |
| 主な用途 | 既設に多い 3 芯一括形 | 現在の主流（ラック・管路とも取り回しやすい） |

---

## 許容電流と布設条件補正

許容電流はケーブルの布設方法によって大きく異なる。高圧 CV/CVT の基準許容電流と布設別の値は**ケーブルメーカーの技術資料（許容電流表）を正**とし、下表は「布設方式でどの程度変わるか」の感覚をつかむための実務目安である（規格原本未照合。設計値には使わない）。

| 布設方式 | 許容電流補正係数の目安 |
|---------|------------------|
| 気中布設（ケーブルラック・単独） | 1.0（基準） |
| 管路布設（コンクリート管路内） | 0.75〜0.85 |
| 直埋（土中埋設） | 0.90〜1.00（土壌熱抵抗率による） |
| 束ね（複数本密集） | 0.8〜0.9（本数・密度による） |

周囲温度補正・多条布設低減の計算手順（式と JCS 掲載値）は [ケーブル許容電流と補正係数](../reference/ampacity.md) を参照（同ページの数表は低圧 JCS 0168-2 系。高圧はメーカー表の係数を使う）。

!!! warning "束ね補正の見落としに注意"
    複数のケーブルを束ねてケーブルラックに並べる場合、相互加熱で許容電流が大きく下がる。
    設計時に束ね補正係数を忘れると過負荷・絶縁劣化につながる。

## 終端処理の種類

### ストレスコーン方式（旧来型）
絶縁体の遮蔽層を段状に切り落とし、ゴム製のストレスコーンを成形して電界集中を緩和する。現地加工が必要。

### プレハブ型終端（現在の主流）
工場製のゴム製プレハブコネクタを使用。現地で引き伸ばして装着するだけで確実な絶縁処理ができる。

| 種類 | 特徴 |
|------|------|
| 屋内用（ドライタイプ） | 小型・軽量。清浄な屋内環境向け |
| 屋外用（耐候型） | 耐汚損・防水設計。プラント屋外向け |
| GIS 直結型 | ガス絶縁開閉装置への直結 |

## 絶縁劣化診断

### 直流耐圧試験（竣工時／維持時）

試験電圧は電技解釈 第15条に基づく法定値と、経年ケーブルの維持診断で用いる実務値を分けて考える。詳細な竣工試験手順は [耐圧試験・絶縁診断](insulation-test.md) を正典とし、本ページと同一の値で統一している。

竣工時（新設・更新時）の法定試験電圧は次のように求める。

```
最大使用電圧 = 公称電圧 × 1.15 / 1.1
            = 6600 × 1.15 / 1.1 = 6900 V

交流試験電圧 = 最大使用電圧 × 1.5（7000 V 以下）
            = 6900 × 1.5 = 10350 V（約10.35 kV）を10分間

直流試験電圧 = 交流試験電圧 × 2（ケーブルのみ直流代替が可）
            = 10350 × 2 = 20700 V（約20.7 kV）を10分間
```

| 区分 | 試験電圧 | 印加時間 | 根拠 |
|------|---------|---------|------|
| 竣工時 交流 | AC 約10.35 kV | 10 分 | 電技解釈 第15条・15-1表（最大使用電圧×1.5） |
| 竣工時 直流 | DC 約20.7 kV | 10 分 | 同 第15条第二号（交流試験電圧×2、電線にケーブルを使用する交流の電路のみ） |
| 維持（経年診断） | 単一のDC正典値なし（DC非推奨→下記） | 社内基準／VLF・tanδ・PD | 法定でなく劣化診断目的。前回比で判断 |

!!! warning "維持診断に単一のDC試験電圧はない（代替診断へ）"
    経年ケーブルの維持診断には**法定値も単一の正典値も存在しません**（未確定ではなく、固定DC電圧を定めた規格がないという事実）。**XLPE（CV）へのDC直流耐圧は近年非推奨**のため、実務は **VLF（0.1Hz）耐圧・tanδ・部分放電（PD）・残留電荷法**へ移行しています。判定は絶対値でなく**前回比**（目安：前回の 80% 以下で劣化疑い）と漏れ電流の時間変化で行います。やむを得ずDCを使う場合も全電圧（20.7 kV）は健全部を痛めるため**低減電圧の段階印加**とし、印加電圧は社内保全基準・メーカー診断基準で定めること。詳細な区分は [耐圧試験・絶縁診断](insulation-test.md) を正典とします。

!!! danger "XLPE（CV）ケーブルへの直流耐圧は近年非推奨"
    架橋ポリエチレン（XLPE=CV）ケーブルへの直流耐圧試験は、(1)交流と電界分布が異なり実運用と違うストレスを与える、(2)水トリー部に空間電荷を蓄積させ劣化を助長する、(3)試験後の残留電荷が原因で試験後にかえって絶縁破壊（アフターブレークダウン）を招く、との理由で技術的に非推奨となっている。近年は VLF（超低周波 0.1Hz）耐圧・交流耐圧や、tanδ・部分放電・残留電荷法などの非破壊診断へ移行している。ただし電技解釈 第15条の直流代替規定そのものは法的に廃止されておらず、竣工試験としては現在も適法である点に注意する。

試験中の漏れ電流を測定し、電圧上昇に対して急激な電流増加がないことを確認する。

!!! danger "直流耐圧後の残留電荷"
    直流耐圧試験後はケーブルに高電圧の残留電荷が蓄積されている。
    接地棒で放電確認（接地後数分待つ）してから触れること。

### 誘電正接（tan δ）試験
誘電正接の値と電圧依存性（チップアップ：印加電圧を上げたときの tanδ の増加）から絶縁劣化度を評価する。

判定値に**単一の正典値はない**。測定方式（商用周波か VLF 0.1Hz か）・測定電圧・ケーブル種別で数値の意味が変わり、%表記と小数表記が資料により混在するため、絶対値の一覧表で判定せず、**診断機関・メーカーの判定基準**と**前回測定値との比較（トレンド）**で評価する。チップアップが大きい（電圧を上げると tanδ が明確に増える）ことは水トリー等の電圧依存性劣化を示唆する定性指標として使える。

### 部分放電試験
絶縁体内のボイド（空洞）や水トリーに起因する部分放電を検出する。近年は活線状態での高周波測定が普及してきている。

## 水トリーイング

架橋ポリエチレン（XLPE）絶縁体内に水分が侵入し、電界の繰り返しによって樹枝状の劣化トラック（水トリー）が発展する現象。

```
劣化進展ルート：
水分侵入 → ボウタイトリー（内部）またはベントトリー（外部から） → 絶縁破壊
```

| 対策 | 内容 |
|------|------|
| 遮水型ケーブルの採用 | 縦方向の水分浸入を防ぐ金属遮水層付き |
| 接続部の確実な防水処理 | プレハブ型接続材の適切な施工 |
| 定期診断 | 誘電正接・部分放電試験で進展監視 |

---

## 布設時の最小曲げ半径

ケーブルを過度に曲げると絶縁体・シースが損傷する。

| ケーブル外径 D | 最小曲げ半径 |
|------------|-----------|
| D ≤ 25 mm | 6D 以上 |
| 25 < D ≤ 50 mm | 8D 以上 |
| D > 50 mm | 10D 以上 |

（参考値。メーカー仕様書を必ず確認すること）

## 根拠

### 本ページが正典の範囲

CV/CVT の構造比較・水トリーイングの機序・布設時の取り扱いは本ページが正典です。**耐圧試験の電圧・時間・メガー印加電圧・PI 値は [耐圧試験・絶縁診断](insulation-test.md) が正典**で、本ページの数値は同ページと同一値に統一しています（高圧ケーブルのメガーは 5000V、判定はトレンド管理）。

### 一次照合・一次計算で確認済み

- **竣工時試験電圧の導出**: 最大使用電圧 6,600 × 1.15 ÷ 1.1 = 6,900 V、交流 6,900 × 1.5 = 10,350 V（10 分）、直流 10,350 × 2 = 20,700 V（10 分）。2026-08-06 に再計算で一致を確認。条文根拠（電技解釈 第15条・15-1表・直流代替規定）の照合記録は [耐圧試験・絶縁診断](insulation-test.md) の根拠節を参照
- **維持診断に単一の DC 正典値が無いこと・XLPE への DC 耐圧非推奨**: 同ページの根拠節と同一の整理（本ページは要約のみ）

### 是正の記録（2026-08-06）

- **tanδ の判定表（0.01 以下良好／0.05 以上要交換検討）を撤去**: 単位（％か小数か）も出典も特定できず、測定方式（商用周波／VLF）で数値の意味が変わるため、絶対値表のまま残すと誤判定を招きます。「診断機関・メーカー基準＋前回比トレンドで判定」に置き換えました
- **CVT の主な用途「長距離・屋外架空」を是正**: CVT はラック・管路を含む現在の高圧配電の主流であり、「架空」に限定する記述は実態と異なります
- **許容電流補正の表を「実務目安・設計値には使わない」と明示**: 従来は出所不明のまま係数だけが並んでおり、規格値と誤読される書き方でした。基準許容電流はメーカー技術資料を正とし、補正の計算体系は [ケーブル許容電流と補正係数](../reference/ampacity.md) への参照を追加しました

### 実務慣行（規格・法令の裏付けなし）

- 布設方式別の補正係数（管路 0.75〜0.85 等）・最小曲げ半径（6D／8D／10D）は実務目安です。曲げ半径は JCS・メーカー仕様で「単心／多心」「布設中／固定時」の区分により異なるため、施工時は必ず当該ケーブルの仕様書によってください
- 終端処理の分類（ストレスコーン／プレハブ型）は施工実務の整理で、規格の分類名ではありません

### 限界の明示

- 本ページは 6.6kV 級を対象とし、特別高圧ケーブルには適用しません
- 部分放電試験・残留電荷法の判定基準は診断機関ごとに異なり、本ページでは数値を示しません
