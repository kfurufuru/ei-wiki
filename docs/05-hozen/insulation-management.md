# 絶縁管理

## 30秒まとめ

絶縁測定の要点は「測定前の残留電荷放電」と「測定後の放電」の徹底。測定値は温度補正して基準温度 20℃ 換算で比較する。単点の値より「経年トレンド」で判断することが早期劣化検出の核心。

---

## メガーの種類と測定電圧の選定

| 測定電圧 | 対象設備 | 選定の理由（法令ではなく実務慣行） |
|---------|---------|------|
| 250V | 低圧機器（AC100V 以下） | 過電圧による絶縁破壊を防ぐ |
| 500V | 低圧電路（AC200V 級）・計装ケーブル | 低圧の標準（実務慣行） |
| 1000V | 低圧動力設備・電動機 | 回路電圧が高い低圧機器で使う慣行値 |
| 5000V | 高圧設備（6.6kV 級）・高圧ケーブル | 高圧の標準。実務慣行 |
| 10000V | 特別高圧設備・発電機 | 特別高圧用 |

!!! warning "メガーの印加電圧を定めている法令は無い"
    **電技解釈第14条は「メガーを何ボルトで掛けるか」を定めた条文ではありません。**同条が定めているのは低圧電路の**絶縁性能**で、「省令第58条の絶縁抵抗値によること」または「絶縁抵抗測定が困難な場合は漏えい電流 1mA 以下であること」のいずれかに適合せよ、という内容です（令和7年11月版で 2026-07-30 に逐語照合）。

    したがって上表の印加電圧は**法定値ではなく実務慣行**です。実際の選定は、絶縁抵抗計の適用規格・**対象機器の製造者仕様**・回路の使用電圧・接続機器の耐電圧から決めてください。

!!! note "メガー印加電圧の基本（全ページ共通の基準）"
    実務の原則は「**低圧回路＝500V メガー／高圧機器・ケーブル（6.6kV 級）＝5000V メガー**」。低圧でも AC100V 以下の弱電機器は 250V、高圧機器でも用途により 1000V・2500V を使う場合がある。他ページの絶縁測定もこの基準に統一する。

!!! danger "測定前に電子機器を切り離す"
    低圧設備には SPD・ノイズフィルタ・インバータ・PLC・電子式リレー・計器などが接続されています。**端子を外さずに 500V／1000V を印加すると破損します。** 切り離せない回路は製造者指定の試験電圧・試験方法に従ってください。

!!! warning "測定電圧の誤選定は機器を損傷させる"
    電子回路（PLC・DCS・伝送器）は 500V 以上のメガーをかけると回路が破壊される。電子機器の測定前は必ず電子回路側の端子を外してから測定する。

## 測定手順

```
Step 1: 対象設備の停電確認（開放→施錠→検電器で無電圧を確認）
Step 2: 残留電荷の放電
  - コンデンサ・ケーブルには残留電荷が蓄積している
  - 接地棒を当てて放電する（大容量コンデンサ・長距離ケーブルは 5 分以上を目安に接地を保持）
  - 時間だけで判断せず、放電後に検電器で残留電圧が 0 V であることを確認してから測定器を接続する
Step 3: メガーを接続
  - LINE 端子 → 測定対象（導体）
  - EARTH 端子 → 接地（設備外箱または接地線）
  - GUARD 端子 → 表面漏れ電流の除去（高精度測定時）
Step 4: 測定
  - 電圧印加後 1 分間の値を記録（IR₁）
  - 10 分間の値も測定する場合は IR₁₀ を記録
Step 5: 測定終了後の放電
  - メガーの放電スイッチで放電し、接地棒でも確認放電
Step 6: 記録
  - 測定値・周囲温度・湿度・天候を記録
```

## 温度補正（基準温度 20℃ への換算）

絶縁抵抗は温度が上がると低下し、下がると増加する。異なる温度での測定値を比較するために補正が必要。

```
R₂₀ = Rt × K_T

R₂₀ : 20℃ 換算絶縁抵抗 [MΩ]
Rt  : 測定温度 t℃ での絶縁抵抗 [MΩ]
K_T : 温度補正係数
```

### 温度補正係数（CV ケーブル・ビニル絶縁の目安）

| 測定温度 | 補正係数 K_T |
|---------|------------|
| 10℃ | 0.5 |
| 15℃ | 0.7 |
| 20℃ | 1.0 |
| 25℃ | 1.4 |
| 30℃ | 2.0 |
| 40℃ | 4.0 |

補正の向きは上式（乗算）に統一する。高温（20℃ 超）で測定した実測値 Rt には係数 K_T（≥1）を **乗じて** 20℃ 換算値 R₂₀ を求める。逆に低温（20℃ 未満）では K_T < 1 を乗じるため換算値は下がる。「係数で割る」という説明は誤りなので注意する。

!!! example "計算例（30℃ で測定）"
    30℃ で 0.6 MΩ を測定した場合、K_T = 2.0 を乗じて R₂₀ = 0.6 × 2.0 = 1.2 MΩ（20℃ 換算）。高温で低く出た実測値を換算すると値は上がる。

## 判定基準表

判定値は「法定最低値（守らなければ違法）」と「実務管理値（経験的な良否境界）」を分けて考える。本ページを両者の正典（SSOT）とし、他ページはここを参照する。

### 法定絶縁抵抗値（電技省令 第58条）

電気使用場所における低圧電路の電線相互間および電路と大地間の絶縁抵抗は、開閉器・過電流遮断器で区切ることのできる電路ごとに、下表の値以上に保つことが電気設備技術基準省令 第58条で定められている（電気使用場所以外の低圧電路も電技解釈 第14条第2項により本表に準じる）。これは**最低基準**であり、これを下回ると法令違反となる。

| 電路の使用電圧の区分 | 絶縁抵抗値 |
|------|---------|
| 300 V 以下（対地電圧 150 V 以下） | 0.1 MΩ 以上 |
| 300 V 以下（対地電圧 150 V 超） | 0.2 MΩ 以上 |
| 300 V 超 | 0.4 MΩ 以上 |

!!! note "「対地電圧」の定義（第58条かっこ書き）"
    接地式電路では**電線と大地との間の電圧**、非接地式電路では**電線間の電圧**を指します。したがって高圧側から絶縁された非接地の 200 V デルタ回路は対地電圧 200 V の扱いとなり、0.2 MΩ の区分が適用されます。

!!! warning "法定値と実務管理値の違い"
    第58条の値（0.1／0.2／0.4 MΩ）はあくまで**下限**。実務では下表の実務管理値（電動機で概ね 1 MΩ 以上を良好とする）で余裕をもって管理し、法定値ぎりぎりまで低下する前に対処する。高圧設備には第58条の法定絶縁抵抗値の定めはなく、トレンド管理（前回比の急低下に注意）で判断する。

### 低圧設備の実務管理値（200V 系）

以下は経験的な良否境界（実務管理値）であり、低圧電動機では概ね「1 MΩ 以上＝良好、0.5〜1 MΩ＝要注意、0.5 MΩ 未満＝危険」を採用する。

| 設備 | 良（合格） | 要注意 | 危険（要修理） |
|------|---------|--------|-------------|
| 幹線ケーブル | 1MΩ 以上 | 0.1〜1MΩ | 0.1MΩ 以下 |
| 電動機（200V） | 1MΩ 以上（新品 5〜10MΩ） | 0.5〜1MΩ | 0.5MΩ 以下 |
| 制御回路 | 1MΩ 以上 | 0.5〜1MΩ | 0.5MΩ 以下 |
| 電熱器 | 0.1MΩ 以上 | — | 0.1MΩ 以下 |

### 高圧設備（6.6kV 系）

| 設備 | 良（合格） | 要注意 |
|------|---------|--------|
| 高圧ケーブル（新品） | 100MΩ 以上 | — |
| 高圧ケーブル（使用中） | 10MΩ 以上 | 1〜10MΩ |
| 変圧器一次側 | 100MΩ 以上 | 10〜100MΩ |
| 高圧電動機 | 設備電圧 [kV] + 1 [MΩ] 以上 | — |

## 根拠と適用上の注意

- **法定絶縁抵抗値（0.1／0.2／0.4 MΩ）**: 電気設備に関する技術基準を定める省令（平成9年通商産業省令第52号）**第58条**。e-Gov 法令検索の現行条文で **2026-07-30 に逐語照合**しました。区分はまず使用電圧 300 V 以下を対地電圧 150 V で二分し、300 V 超は一律 0.4 MΩ です。「対地電圧」の定義（接地式＝電線と大地との間の電圧、非接地式＝電線間の電圧）も同条かっこ書きによります。
- **絶縁抵抗測定が困難な場合の代替基準**: 電気設備の技術基準の解釈（令和7年11月版）**第14条第1項第二号**「当該電路の使用電圧が加わった状態における漏えい電流が、1mA以下であること」。同項第一号が「省令第58条によること」、同条第2項が電気使用場所以外の低圧電路への準用です（原典 PDF で 2026-07-30 に逐語照合）。
- **高圧設備の法定絶縁抵抗値は無い**: 第58条は低圧電路のみの規定です。高圧電路に求められるのは絶縁耐力（電技解釈 第15条・第16条）で、正典は [絶縁耐力試験](../01-koatsu/insulation-test.md) です。本ページの高圧設備の判定値はすべて実務管理値です。
- **メガーの印加電圧（250 V／500 V／1000 V／5000 V 等）**: 法令に定めはありません（本文 warning のとおり）。絶縁抵抗計の定格測定電圧の区分は JIS C 1302（絶縁抵抗計）に基づく製品仕様とされますが、**同規格の原本は未照合**のため本ページでは条文・表番号を引用しません。内線規程（JEAC 8001）にも測定の目安があるとされますが、同じく**原本未照合**です。選定は対象機器の製造者仕様を優先してください。
- **温度補正係数（10℃ で約 2 倍）**: 「絶縁抵抗は温度が 10℃ 上がるとおよそ半減する」という実務目安に基づく概算表で、**規格・原典の裏付けは確認できていません**。絶縁材料の種類・劣化状態で係数は大きく変わるため、厳密な管理は当該ケーブル・機器メーカーの温度特性曲線によってください。
- **実務管理値（1 MΩ 以上を良好、0.5 MΩ 未満を危険 等）**: 法定値ではなく経験的な管理値で、**一次資料による裏付けはありません**。社内基準・メーカー推奨値がある場合はそちらを優先してください。
- **高圧電動機の「設備電圧 [kV] + 1 [MΩ]」**: IEEE Std 43 系の伝統的な最小絶縁抵抗の判定式として広く使われる形ですが、**同規格は有料規格で原本未照合**（二次資料の一致のみ）です。巻線の年式・構造で推奨最小値は異なるため、条文・表番号は引用しません。
