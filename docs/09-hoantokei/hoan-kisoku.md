# 保安規程の管理

## 30秒まとめ

保安規程は自家用電気工作物の設置者が作成する社内規程で、根拠は電気事業法第42条。自家用電気工作物の必須記載事項は施行規則第50条**第3項**の9号。変更したときは内容の大小を問わず届出が必要（工事計画届出のような「軽微なもの」の除外規定は無い）。実態と規程が乖離すると法令違反になるため、定期的な見直しが要点。

---

## 保安規程とは

自家用電気工作物の設置者が、電気工作物の工事・維持・運用に関する保安を確保するために作成する社内規程。

**法的根拠**: 電気事業法第42条

```text
電気事業法第42条（保安規程）
第1項 事業用電気工作物を設置する者は、工事・維持・運用に関する保安を確保するため、
       主務省令で定めるところにより、保安を一体的に確保することが必要な
       事業用電気工作物の組織ごとに保安規程を定め、
       当該組織における事業用電気工作物の使用の開始前に、主務大臣に届け出る。
第2項 保安規程を変更したときは、遅滞なく、変更した事項を主務大臣に届け出る。
第4項 設置者およびその従業者は、保安規程を守らなければならない。
```

---

## 保安規程の必須記載事項（電気事業法施行規則第50条第3項）

!!! warning "自家用電気工作物に適用されるのは第50条「第3項」の9号"
    第50条は保安規程を2種類に分けています（第1項）。**第2項の15号は一般送配電事業・送電事業・配電事業・発電事業用**の規程に適用される事項で、化学プラント等の**自家用電気工作物には適用されません**。
    自家用電気工作物（第1項第二号「前号に掲げるもの以外のもの」）に適用されるのは**第3項の9号**です。第2項の号数・文言（経営責任者の関与、保安の計画的実施＝PDCA、文書管理手順 等）を自家用の必須記載事項として引用しないでください。

| 号 | 必須記載事項（第50条第3項） |
|------|------------|
| 一 | 事業用電気工作物の工事・維持又は運用に関する業務を管理する者の職務及び組織に関すること |
| 二 | 事業用電気工作物の工事・維持又は運用に従事する者に対する保安教育に関すること |
| 三 | 事業用電気工作物の工事・維持及び運用に関する保安のための巡視・点検及び検査に関すること |
| 四 | 事業用電気工作物の運転又は操作に関すること |
| 五 | 発電所又は蓄電所の運転を相当期間停止する場合における保全の方法に関すること |
| 六 | 災害その他非常の場合に採るべき措置に関すること |
| 七 | 事業用電気工作物の工事・維持及び運用に関する保安についての記録に関すること |
| 八 | 法定自主検査（使用前・溶接・定期の各自主検査）又は使用前自己確認に係る実施体制及び記録の保存に関すること |
| 九 | その他事業用電気工作物の工事・維持及び運用に関する保安に関し必要な事項 |

第八号は、法定自主検査または使用前自己確認を実施する電気工作物を持つ場合の事項です。

### 実務的な重要ポイント

**職務・組織（第一号）**: 電気主任技術者の職務範囲と指揮命令系統を明確化。
「誰が主任技術者か」「主任技術者が不在の時は誰が代行するか」を明記する。

**点検スケジュール（第三号）**: 月次・年次の点検頻度・方法・使用計器を具体的に記載。
曖昧な表現（「適宜」「随時」）は避け、頻度を数字で明記する。

**事故連絡（第六号）**: 条文の見出しは「災害その他非常の場合に採るべき措置」。事故発生時の連絡先（電力会社・産業保安監督部・社内報告先）と連絡手順は、この号を受けて規程本文に書き込む実務事項です。

!!! info "条文に「電気工事の保安」「事故が発生した場合の措置」という独立の号はありません"
    自家用向けの第3項に、これらを名指しした号はありません。工事時の保安は第一号（職務・組織）・第三号（巡視点検検査）、事故時の措置は第六号（災害その他非常の場合）と第七号（記録）で受けるのが実務上の整理です。**号の名前を創作しないでください**。

## 保安規程の変更届出

!!! danger "保安規程には「軽微な変更だから届出不要」という除外規定はありません"
    法第42条第2項は「保安規程を変更したときは、**遅滞なく**、変更した事項を主務大臣に届け出なければならない」と定めるのみで、**変更の大小による除外を置いていません**。手続を定める施行規則第51条第2項にも除外はありません。
    「軽微なもの」の除外があるのは**工事計画届出**のほう（法第48条第1項ただし書＋施行規則第65条第2項）です。この2つを混同し、保安規程の小改訂を「軽微だから不要」と処理すると届出漏れになります。
    実務上の線引きは「軽微か否か」ではなく「**保安規程そのものが変わったか否か**」です。

### 届出の要否は「保安規程本文が変わったか」で判断する

| 変更内容 | 届出要否 |
|---------|---------|
| 保安規程本文の改訂（保安監督の組織体制、点検頻度の緩和・強化、事故時の連絡体制、対象設備の増減、誤字修正・条番号の整理を含む） | **要届出**（変更の大小を問わない） |
| 保安規程が引用するだけの別冊・付属資料の更新（担当者名簿、連絡先一覧、作業要領書など。規程本文の記述が変わらない場合） | 保安規程の「変更」ではないため対象外（社内保管版の更新のみ） |
| 電気主任技術者の選任・解任 | 保安規程変更とは**別建て**の届出（法第43条第3項）。規程本文で職名・組織を書き換えたなら、保安規程変更届出も併せて必要 |

!!! tip "「別冊に逃がす」設計が効く"
    担当者名・電話番号のように頻繁に変わる情報を保安規程の本文に直書きすると、人事異動のたびに変更届出が発生します。本文には「連絡体制は別紙◯による」と書き、可変情報は別紙に置く構成にしておくと、届出の頻度を実態に合わせて下げられます。ただし**別紙が保安規程の一部として届け出られている場合は別紙の改訂も変更**になるため、規程本文で別紙の位置付けを明確にしておくこと。

### 変更届出の手順

```text
1. 変更内容の決定
    ↓
2. 保安規程変更届出書の作成（様式第四十二）
    ↓
3. 添付書類の準備
    （変更を必要とする理由を記載した書類＝施行規則第51条第2項）
    ↓
4. 産業保安監督部へ提出
    （経産省電子申請システム e-Gov 経由または郵送）
    ↓
5. 受理確認・控えの保管
    ↓
6. 社内版保安規程の更新・周知
```

!!! info "新規作成時の様式は第四十一"
    使用開始前の保安規程届出（法第42条第1項）は**様式第四十一**の保安規程届出書に保安規程を添えて提出します（施行規則第51条第1項）。変更届出の様式第四十二と取り違えないこと。

## 保安規程に基づく点検スケジュール管理

### 年間点検カレンダーの整備

保安規程に記載した点検頻度と実施日を管理する年間カレンダーを作成・更新する。

| 点検種別 | 頻度 | 担当 | 記録様式 |
|---------|------|------|---------|
| 日常巡視 | 毎日（運転当番） | オペレーター | 運転日誌 |
| 月次点検 | 毎月（第○週） | 電計チーム | 月次点検記録表 |
| 年次点検（停電） | 年1回（○月） | 電計チーム＋外部業者 | 年次点検報告書 |
| 精密点検（変圧器油分析等） | 3〜5年毎 | 外部業者 | 精密点検報告書 |

### 記録の保管期間

!!! warning "下表の年数は法定値ではなく、保安規程で定める慣行値"
    自家用電気工作物について施行規則第50条**第3項**が求めているのは、保安規程に**第七号「保安についての記録に関すること」**と**第八号「法定自主検査又は使用前自己確認に係る実施体制及び記録の保存に関すること」**を定めることであって、**同項に保存年限の数値規定はありません**（2026-07-30 に e-Gov 現行条文で逐語照合。第50条の全項を通じて年限の数値は存在しない）。
    下表は一般的な慣行値です。**自事業場の保安規程で定めた値が優先**します。規程に年限の定めが無ければ、まず規程側を整備してください。

| 記録種別 | 保管期間（慣行値） |
|---------|---------|
| 月次点検記録 | 3年以上 |
| 年次点検報告書 | 3年以上 |
| 事故記録 | 5年以上（事故報告書の控えを含む） |
| 絶縁抵抗・接地抵抗測定記録 | 3年以上 |

## 実態と保安規程の乖離リスク（定期見直しの重要性）

### よくある乖離パターン

| 乖離の種類 | 例 |
|-----------|---|
| 組織変更の反映漏れ | 保安規程上の担当部署名が古い組織名のまま |
| 点検頻度の形骸化 | 規程では月次と書いてあるが実際は2〜3か月に1回 |
| 設備追加の未反映 | 新設した変圧器・発電機が保安規程の対象設備リストに未記載 |
| 連絡先の陳腐化 | 事故時連絡先が退職した担当者のまま |
| 外部委託範囲の不一致 | 外部保安法人に委託したが保安規程が直営前提のまま |

### 保安監督部の立入検査で指摘されやすい点

1. 保安規程と実態の乖離（特に点検記録）
2. 電気主任技術者が実際に監督を行っていない（名義だけ）
3. 記録の保管期間不足
4. 工事計画届出が必要な工事を届出なしに実施

### 定期見直しサイクル（推奨）

```
毎年: 担当者名・連絡先・設備リストの更新確認
3年毎: 点検実施状況との整合確認、設備変更の全体反映
10年毎 or 大規模設備変更時: 規程全文の抜本的な見直し
```

!!! tip "設備投資案件との連動"
    大型設備を新設・廃棄する際は、保安規程の対象設備リスト更新と届出要否の確認をセットで行う。
    設備投資プロジェクトのチェックリストに「保安規程の更新」項目を入れておくと漏れが防げる。

### 根拠

- 電気事業法 第42条第1項（保安規程の作成・使用開始前の届出）／第2項（**変更したときは遅滞なく届出。変更の大小による除外規定なし**）／第4項（設置者・従業者の遵守義務）
- 電気事業法 第43条第3項（主任技術者の選任・解任の届出＝保安規程変更届出とは別建て）
- 電気事業法施行規則 第50条第1項（保安規程を2区分。第二号が自家用電気工作物）／**第3項第一号〜第九号**（自家用電気工作物の必須記載事項。年限の数値規定なし）
- 電気事業法施行規則 第51条第1項（新規届出＝**様式第四十一**の保安規程届出書に保安規程を添付）／第2項（変更届出＝**様式第四十二**の保安規程変更届出書に変更を必要とする理由を記載した書類を添付。除外規定なし）

いずれも **e-Gov 法令検索の現行条文で 2026-07-30 に逐語照合**（電気事業法＝昭和三十九年法律第百七十号、電気事業法施行規則＝平成七年通商産業省令第七十七号）。

**限界の明示**:

- 第50条第2項の15号は一般送配電事業・送電事業・配電事業・発電事業用の規程に適用される事項であり、本ページが扱う自家用電気工作物には適用されない。両者の混同が実務で最も多い誤りのため、引用時は必ず項番号まで確認すること。
- 保存年限（記録の保管期間の表）は条文照合の対象外＝**一次資料で裏付けた数値ではない**。自事業場の保安規程で定めた値が唯一の正である。
- 「別冊に逃がす」設計の届出要否は、別冊が保安規程の一部として届け出られているかに依存する。個別判断は所轄の産業保安監督部に確認すること。
