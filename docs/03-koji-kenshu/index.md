# 工事・検収・試運転フロー

## 30秒まとめ

工事完了宣言は **確認開始の合図**。発注者側の設備担当が **企画→設計→施工→竣工→検収→引継ぎ** の各段階で、  
現場・性能・書類・安全・維持管理を 閉じる必要がある（段階の数え方は [工事フロー全体図](flow-overview.md) が正典で **7段階**）。

---

## 全体フロー（工事フェーズ別ガイド）

| フェーズ | タイミング | 主な確認項目 | 関連記事 |
|---------|-----------|-----------|--------|
| **工事企画・設計** | 工事着手前 | 仕様・予算・リスク | [設備投資フロー](../04-sekkei/investment-flow.md) |
| **ベンダー施工** | 工事実施中 | 進捗・品質確認 | （保全担当と連携） |

| **現地検査** | 竣工から3営業日以内 | 施工品質・外観 | [工事完了後の受入実務](../03-keiso/koji-kanryo.md) |
| **試運転・性能確認** | 現地検査後1週間以内 | 性能・安全・運転模擬 | [工事完了後の受入実務](../03-keiso/koji-kanryo.md) |
| **検収判断** | 試運転完了後 | 結果確認・支払準備 | [工事完了後の受入実務](../03-keiso/koji-kanryo.md) |
| **運転/保全部門への引継ぎ** | 検収合格後 | 図書・教育・マニュアル | [工事完了後の受入実務](../03-keiso/koji-kanryo.md) |

## よくあるミス・見落とし

!!! danger "後戻りコストが高い順"
    1. **完了範囲の曖昧さ** — 「そこは対象外」で手戻り（最優先確認項目）
    2. **試運転計画の欠落** — 性能確認の判定基準が決まっていない
    3. **完成図書の未回収** — 保全がマニュアル不足で運用開始後にトラブル
    4. **安全基準の確認漏れ** — 検査官指摘で施工やり直し
