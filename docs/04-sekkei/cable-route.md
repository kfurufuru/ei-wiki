# 電路設計

## 30秒まとめ

電路設計の核心は「強電と弱電の物理的分離」と「防爆エリア境界へのシーリングフィッチング」。ケーブルラックの充填率は設計段階で 50 % 以下を目標に置く。将来の追加配線を想定した余裕設計が保全性に直結する。

---

## ケーブルラックサイズ選定

### 充填率の計算

```text
充填率 = 収容ケーブルの断面積合計 / ラック有効断面積 × 100 [%]

設計目標：50 % 以下（将来の追加を考慮）
施工上限：ケーブルトレイ施工要領（80 % 以下）を正典とする
```

!!! warning "金属ダクト工事の 20 % を持ち込まない"
    電気設備の技術基準の解釈 第162条第1項第二号が定める **20 % 以下**（制御回路等のみなら 50 % 以下）は、**低圧屋内配線の金属ダクト工事**に対する規定です。ケーブルラック（トレイ）の充填率とは対象が別で、上記の 50 % / 80 % はいずれも実務値です。盤内配線ダクトはさらに別で [盤設計](panel-design.md) が正典です。

### ラック幅の目安

| 収容ケーブル数・サイズ | 推奨ラック幅 |
|-------------------|------------|
| 小径ケーブル（〜CV5.5sq）× 10 本程度 | 200mm |
| 中径ケーブル（〜CV22sq）× 10 本程度 | 300mm |
| 大径ケーブル（〜CV100sq）混在 | 400〜600mm |

### ラック種類

| 種類 | 特徴 | 適用 |
|------|------|------|
| はしご形 | 放熱性良好・重量物 OK | 動力幹線 |
| 水平トレー形 | ケーブル保護優れる | 計装・通信ケーブル |
| パンチング板形 | 中間的性能 | 一般動力 |

## 強電・弱電の分離基準

!!! danger "強電と弱電の混在は計装誤動作の原因"
    電力ケーブルの磁界が計装信号ケーブルに誘導ノイズを与える。物理的分離が最も確実な対策。

| 分離方法 | 最小離隔距離 | 条件 |
|---------|------------|------|
| 別ラック（水平分離） | 300mm 以上 | 標準的な分離 |
| 同一ラック（仕切板使用） | 仕切板で完全分離 | スペースが限られる場合 |
| 上下配置（強電下・弱電上） | 200mm 以上 | スペース制約時の代替 |

離隔距離は実務目安です（下記「根拠」参照）。

**ここでいう弱電ケーブル：**
- 計装信号（4-20mA、パルス、熱電対）
- 通信ケーブル（Ethernet、PROFIBUS、CC-Link）
- DC 24V 制御配線

## 管路配線の選定

| 種類 | 板厚・特徴 | 適用 |
|------|-----------|------|
| 薄鋼電線管（C 管） | 薄肉・低コスト | 屋内・一般環境 |
| 厚鋼電線管（G 管） | 厚肉・強度大 | 屋外・機械的損傷の恐れがある場所 |
| ねじなし電線管（E 管） | コネクタ接続・施工容易 | 盤内配管・屋内一般 |
| PF 管（合成樹脂可とう電線管） | 可とう・軽量・耐腐食 | 計装ケーブル保護・腐食雰囲気 |
| 金属製可とう管 | 可とう・EMI シールド | 振動機器への接続部分 |

**化学プラントの選定基準：**

- 腐食雰囲気・屋外は SUS または耐腐食 PVC コーティング厚鋼管
- 防爆エリアは鋼製管（シールを施工できる材質）

## 防爆エリアのシーリングフィッチング施工

!!! danger "シーリングは施工後の手戻りが困難"
    シーリングフィッチング（sealing fitting）は電線管路の内部空間を密封遮断し、管路を伝ってガスが移動するのを防ぐ施工です。設計時点でシーリング位置を図面に明示すること。**「シールド（遮蔽）」ではありません。**

### シーリングを施す箇所

「ユーザーのための工場防爆設備ガイド（平成24年11月）」3.7.6.3 は、次の2箇所を挙げています（下記「根拠」参照）。

| 箇所 | 要件 |
|---|---|
| 異なる危険箇所の間／危険箇所と非危険場所の間の境界 | 境界に隔壁がある場合は**いずれか一方の 3 m 以内**に設け、それと隔壁の間の電線管路に**継ぎ目を設けない** |
| 分岐接続・端末処理を行う防爆電気機器と電線管路との間 | 製品に付属したシーリングフィッチングを使う。既にシーリングされた容器に重ねる必要はない |

### 施工手順

1. シーリングフィッチングを上記の箇所に設置する
2. フィッチング内にシーリングファイバ等でコンパウンドの流出防止用区画を作る
3. シーリングコンパウンドを製造者の説明に従って溶解し、**充填層の有効厚さが電線管の内径以上（最低 16 mm）**になるようにすきまなく充填する
4. 軽くたたいて隅々まで行き渡らせ、静置して十分に硬化させる
5. 硬化した充填層に欠陥がないことを確認し、注入口にねじ栓を確実に取り付ける
6. 施工記録写真を撮影し保管する

### 施工確認ポイント

| 確認項目 | 基準 |
|---------|------|
| シール材の充填量 | 空隙なし・**充填層の有効厚さ ≧ 電線管の内径**（最低 16 mm） |
| 充填の行き渡り | 水平配管では注入口を高い位置にとる（空洞防止） |
| 硬化後の確認 | 充填層に欠陥がないことを確認し、注入口にねじ栓を取り付けたか |
| 境界との位置関係 | 隔壁から 3 m 以内・隔壁との間の管路に継ぎ目がないこと |

## ケーブルドラム図の書き方

ケーブルドラム図（ケーブルリスト）は施工・保全の基本資料。

```text
必須記載項目：
- ケーブル番号（設備 TAG に連動した番号付け）
- 起点（FROM）：盤名・端子台番号
- 終点（TO）：現場機器・端子台番号
- ケーブル種類・サイズ（例：CV 3.5sq × 3C）
- 敷設長さ [m]
- 経路（ラック名・管路番号）
- 防爆シール要否
- 配線色（心線番号と色の対応）
- 接続先機器 TAG 番号
```

!!! tip "番号付け規則の統一"
    ケーブル番号は「エリアコード + 設備 TAG + 連番」の形式で統一する。例：`1F-P001-001`（1 階、ポンプ 001、1 本目）。工事会社と事前に規則を合意しておく。

## 根拠

### シーリングの用語と充填厚さを一次照合で是正しました（2026-08-03）

「ユーザーのための工場防爆設備ガイド（平成24年11月）」の PDF 原本を **2026-08-03 に逐語照合**し、2点を是正しました。

| 項目 | かつての記述 | ガイドの記述（3.7.6.3 / 3.7.6.4） |
|---|---|---|
| 名称 | シールド**フィッティング** | **シーリングフィッチング**（sealing fitting） |
| 充填厚さ | 充填厚さは**ケーブル外径**以上（最小 16mm） | 充填層の有効厚さが**電線管の内径**以上（最低 16mm） |

**充填厚さの基準は危険側にずれていました。** 電線管には複数のケーブルを収めるため、電線管の内径は一般に個々のケーブル外径より大きくなります。ケーブル外径を基準にすると、ガイドが求める厚さに届かないまま「基準どおり」と判定してしまいます。

名称の「シールド」は shield（遮蔽）で、シーリング（sealing＝密封）とは別の概念です。ガイドは一貫して「シーリングフィッチング」と表記しています。

あわせて、ガイドが挙げるシーリング箇所のうち**「分岐接続・端末処理を行う防爆電気機器と電線管路との間」が本ページに書かれていなかった**ため追加し、境界での **3 m 以内・継ぎ目なし**の要件も明記しました。

### ケーブルラック充填率のページ間不一致を解消

本ページは上限を 60 % としていましたが、[ケーブルトレイ施工要領](../guidelines/cable-tray.md) は 80 % 以下としており、**同じ対象に対して判定が食い違っていました**（施工要領の計算例 66.7 % は、本ページの旧上限では NG になります）。[盤設計](panel-design.md) の先例（設計目標と施工上限を分け、施工側の値に統一）に合わせ、**本ページは設計目標 50 %、施工上限は施工要領の 80 % を正典参照**とし、出所不明の 60 % は撤回しました。いずれも実務値で、規格上の正解はありません。

### 一次照合済み（電気設備の技術基準の解釈・令和7年11月版）

- **第162条第1項第二号（金属ダクト工事）**: ダクトに収める電線の断面積（絶縁被覆を含む）の総和は、ダクトの**内部断面積の 20 % 以下**。ただし電光サイン装置・出退表示灯その他これらに類する装置または制御回路等の配線のみを収める場合は **50 % 以下**とすることができる。**対象は低圧屋内配線の金属ダクト工事**であり、ケーブルラックにも盤内配線ダクトにも適用されません（原典 PDF で 2026-08-03 に逐語照合）

### 実務慣行（規格・法令の裏付けなし）

- **強電・弱電の離隔 300 mm／200 mm、仕切板による分離**。誘導ノイズの抑制はケーブル種別・並走長さ・電流の大きさで決まり、一律の法定距離はありません。実際の分離方針はプロジェクトごとに定めてください
- **上下配置で強電を下・弱電を上に置く**のも慣行です
- ラック幅の目安（200／300／400〜600 mm）、ラック種類の使い分け
- ケーブル番号の付け方（エリアコード + 設備 TAG + 連番）

### 原本未照合（honest-hold）

- **内線規程（JEAC 8001）は有償で未照合**です。ケーブルラック・トレイの充填率について同規程が数値を持つかどうかを本 Wiki では確認していません
- **JIS C 8305（鋼製電線管）・JIS C 8411（合成樹脂製可とう電線管）等の管の規格も未照合**です。C 管／G 管／E 管という区分は流通している呼称に従っています
- ガイドの参考資料9（シーリングフィッチングの具体的施工）は本ページで扱っていません。実施工はガイドと製品の施工要領によってください

### 限界の明示

- 危険箇所の区分（Zone / 第一類・第二類）そのものは [防爆](../03-keiso/explosion-proof.md) が正典です。本ページは電路側の施工に絞っています
- **シーリング位置は検定合格品の範囲に関わります。** 機器に付属するシーリングフィッチングを勝手に別品に替えないでください
