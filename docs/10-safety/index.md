# 安全管理・作業許可

> 電気作業における安全管理は「知っている」だけでなく、**手順を守り続けること**が全て。
> このセクションでは、化学プラントの実運用に即した安全管理の基本を整理する。

## 安全の基本原則

!!! danger "絶対厳守"
    - 作業許可書なしの電気作業は禁止
    - LOTO未実施での機器内作業は禁止
    - 検電未実施での接触作業は禁止

!!! info "このセクションの活用方法"
    - 新入メンバーの安全教育資料として使用可能
    - KY活動・ツールボックスミーティングの参考資料として活用
    - 変更管理（MOC）時のリスクアセスメントのチェックリストとして参照

| 法規・規格 | 主な内容 |
|-----------|---------|
| 労働安全衛生法 | 電気取扱の特別教育（第59条第3項）・リスクアセスメント（義務／努力義務の別は[リスクアセスメント](risk-assessment.md)参照） |
| 労働安全衛生規則 第339条 | 停電作業を行なう場合の措置（開閉器の施錠／通電禁止の表示／監視人の**いずれか**＝第1項第一号／残留電荷の放電／高圧・特別高圧であった電路の検電と短絡接地＝第1項第三号。第2項で通電前の確認） |

| 社内保安規程 | 自工場独自の作業基準 |
