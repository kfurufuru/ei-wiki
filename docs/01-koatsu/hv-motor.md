# 高圧モーター

## 30秒まとめ

6.6kV 高圧モーターは始動電流が大きく、電圧降下管理が重要。絶縁管理（PI 値）と軸受管理が予防保全の核心。始動方式の選定は「始動トルク要件」と「電圧降下許容値」のトレードオフで決まる。

---

## 始動方式比較

| 始動方式 | 始動電流（対直入れ） | 始動トルク（対直入れ） | 特徴 |
|---------|--------------|--------------|------|
| 直入れ（DOL） | 100%（最大） | 100% | シンプル・低コスト。小〜中容量 |
| リアクトル始動 | 65〜75%（タップ電圧比に比例） | 42〜56%（電圧比の2乗） | リアクトルで電圧を下げて始動。トルク低下あり |
| コンドルファ始動 | 約25〜64%（タップ電圧比の2乗） | 約25〜64%（タップ電圧比の2乗） | 単巻変圧器（オートトランス）で降圧して始動。タップ例 50・65・80% |
| インバータ始動（VFD） | 定格電流の 100〜150% 程度に制御可 | 定格トルク確保 | 最も制御性が良い。高コスト |

!!! tip "インバータ始動が最良だが"
    インバータ（VFD）始動は始動電流・始動ショックが最小で速度制御も可能。
    ただし高調波発生・絶縁への影響（サージ電圧）があるため、既設モーターに追加する場合は
    絶縁確認のうえ、**サージ対策は出力側**（出力リアクトル・dV/dtフィルタ等）、
    **高調波対策は入力側**（ACリアクトル・フィルタ等）で検討する。詳細は [インバータ](../02-teiatsu/inverter.md)・[高調波対策](harmonics.md) を参照。

## 始動電流と電圧降下の確認

高圧モーターの始動電流は定格電流の**5〜8倍**に達する。これにより母線電圧が一時的に降下する。

### 電圧降下の計算

三相回路の線間電圧降下は、抵抗分とリアクタンス分の両方を負荷力率で重み付けして求めます。

```
e ≒ √3 × I × (R·cosθ + X·sinθ) × L

e   ：線間電圧降下 [V]
I   ：線電流（始動時は始動電流）[A]
R   ：導体1 mあたりの抵抗 [Ω/m]
X   ：導体1 mあたりのリアクタンス [Ω/m]
L   ：亘長 [m]
cosθ：負荷力率、sinθ：無効率
```

```
電圧降下率 ΔV（%） ≒ e / 定格線間電圧 × 100

目安：始動時の母線電圧が定格の 85% 以下にならないよう設計する
```

!!! warning "始動時はリアクタンス分（X·sinθ）が効く"
    始動時のモーターは力率が低く（cosθ ≒ 0.2〜0.3）、sinθ が 0.95 前後まで大きくなります。
    このため定常運転時には無視できる X·sinθ 項が支配的になり、始動電流の大きさと相まって
    電圧降下が最大化します。R だけの簡易式では始動時の電圧降下を過小評価するため、
    始動計算では必ず X·sinθ 項を含めます。

!!! warning "電圧降下が許容値を超える場合"
    - リアクトル始動またはインバータに変更する
    - 専用変圧器（モーター専用フィーダー）を設置する
    - 始動時間を制限する（他の大型負荷との同時始動を避ける）

## 保護設定

| 保護機能 | 継電器 | 整定の考え方 |
|---------|--------|-----------|
| 過電流保護 | OCR | 定格電流の 110〜125%（限時）、短絡電流以下（瞬時） |
| 始動時保護 | OCR（タイマー付き） | 始動時間＋余裕で時限を設定（始動中はOCRを一時的に延長または無効化） |
| 過負荷保護 | サーマルリレー | 定格電流の 115〜120%、熱時定数はモーター仕様による |
| 欠相保護 | 欠相継電器 | いずれか1相の電流が極端に低下したとき検出 |
| 差動保護 | 差動継電器（87） | 大容量モーター（1000kW以上）に適用。内部故障を高感度で検出 |

### 差動保護の必要性判断

| モーター容量 | 差動保護 |
|-----------|---------|
| 300 kW 未満 | 通常不要 |
| 300〜1000 kW | ケースバイケース（重要度による） |
| 1000 kW 以上 | 推奨（内部地絡・相間短絡を高感度検出） |

## 絶縁管理

### 絶縁抵抗測定と PI 値

6.6kV 級高圧モーターの絶縁抵抗は **5000V メガー**で測定する（メガー印加電圧の正典は [耐圧試験・絶縁診断](insulation-test.md)）。絶縁抵抗の最小の目安は「**設備電圧 [kV] + 1 [MΩ] 以上**」（実務管理値。正典は [絶縁管理](../05-hozen/insulation-management.md)）とし、絶対値よりも**前回比のトレンド管理**を重視する。

PI（Polarization Index：成極指数）はモーター巻線の絶縁状態を評価する指標。

```
PI = 10分後の絶縁抵抗値 / 1分後の絶縁抵抗値
```

判定表は [耐圧試験・絶縁診断](insulation-test.md) と同一基準（PI ≥ 2.0 を良好とする実務慣行値）。

| PI 値 | 判定 |
|-------|------|
| 4.0 以上 | 優良 |
| 2.0〜4.0 | 良好 |
| 1.5〜2.0 | 要注意（清掃・乾燥を実施して再測定） |
| 1.0〜1.5 | 不良（使用停止・巻線清掃・乾燥処置） |
| 1.0 未満 | 危険（運転禁止・巻線修理または交換） |

!!! note "温度をそろえて比較する"
    絶縁抵抗値は温度に大きく依存する（温度が10℃上がると抵抗は約1/2に低下する経験則）。
    測定値は巻線温度の記録と合わせて管理し、同条件（同温度）での値を比較すること。
    温度換算を行う場合の基準温度・換算式は社内保全基準・メーカー推奨による。

## 軸受管理

| 管理項目 | 基準 | 実施周期 |
|---------|------|---------|
| グリスアップ | メーカー推奨量・周期（例：3〜6ヶ月） | 定期点検時 |
| 振動測定 | 判定目安は [データ活用・予兆保全](../05-hozen/predictive-maintenance.md) が正典（規格値ではなく実務目安）。実際の判定値はメーカー推奨値による | 月次またはオンライン監視 |
| 温度測定 | ベアリング外輪温度 80℃以下（目安） | 月次または定期点検時 |
| 異音確認 | 聴音棒・振動センサで確認 | 月次 |

!!! warning "グリスの入れ過ぎに注意"
    グリスを入れ過ぎると撹拌発熱でかえって軸受を傷める。
    グリスニップルから押し込む量はメーカー指定量を守る（通常は古いグリスを少し押し出す程度）。

## 根拠

### 本ページが正典の範囲

本ページは「高圧モーターの始動方式の選定・保護整定の考え方・絶縁/軸受管理の運用」の正典です。メガー印加電圧・PI 判定表・耐圧試験の法定値は [耐圧試験・絶縁診断](insulation-test.md)、絶縁抵抗の判定境界は [絶縁管理](../05-hozen/insulation-management.md)、振動判定値は [データ活用・予兆保全](../05-hozen/predictive-maintenance.md) が正典で、本ページは同一基準で参照します。

### 一次計算で検算済み

- **減電圧始動の始動電流・始動トルクの比率**: 誘導電動機の始動トルクは端子電圧の2乗に比例する。リアクトル始動（端子電圧 65〜75%）のトルク 42〜56% は 0.65²＝0.42、0.75²＝0.56 と一致。コンドルファ始動（単巻変圧器タップ 50・65・80%）は電源側始動電流・トルクともタップ電圧比の2乗（0.25・0.42・0.64）となることを検算した
- **電圧降下式** e ≒ √3 × I × (R·cosθ + X·sinθ) × L は三相回路の線間電圧降下の標準的な近似式で、始動時（cosθ ≒ 0.2〜0.3 → sinθ ≒ 0.95）に X·sinθ 項が支配的になる論理は式から直接導かれる

### 実務慣行（規格・法令の裏付けなし）

- 始動電流「定格の 5〜8 倍」、始動時の母線電圧「定格の 85% 以下にしない」目安
- 保護整定の目安（OCR 110〜125%・サーマル 115〜120%・差動保護は 1000 kW 以上で推奨 等）
- 軸受管理の目安（グリスアップ 3〜6ヶ月・ベアリング外輪 80℃以下）
- 「10℃上昇で絶縁抵抗が約 1/2」の温度依存の経験則（[耐圧試験・絶縁診断](insulation-test.md) と同一の記述）

いずれも法定値・規格値ではなく、実際の整定・判定はモーター仕様書・メーカー推奨値・社内保全基準を正とする。

### 是正の記録（2026-08-06）

- コンドルファ始動「スターデルタ原理で電流・トルクを低減」→「**単巻変圧器（オートトランス）で降圧して始動**」 → 始動原理の誤帰属を是正（スターデルタとは別方式）。比率も出所不明の「33〜50%」からタップ電圧比の2乗（約25〜64%）へ是正
- PI 判定表を正典 [耐圧試験・絶縁診断](insulation-test.md) と同一の5段（1.5〜2.0 要注意／1.0〜1.5 不良／**1.0 未満** 危険）に統一 → 旧表は「1.0〜2.0 要注意／1.0 **以下** 危険」で、境界値 1.0 の扱いと段数が正典と食い違っていた
- 「測定値を標準温度（40℃）に換算」→ 換算基準温度の規格帰属を撤回し「同条件（同温度）比較・換算式は社内基準/メーカー推奨による」に変更 → 40℃ 基準の原本（IEEE Std 43 系とされる）は未照合のため権威づけしない
- メガー印加電圧（5000V）と絶縁抵抗の最小目安（設備電圧 [kV] + 1 [MΩ] 以上）を正典参照の形で追記 → 従来は測定電圧・判定境界の記載がなかった
- インバータ追設時の対策「入力フィルタ（または出力リアクトル）」→ **サージ対策は出力側・高調波対策は入力側**に書き分け → 対策と設置側の対応が混線していた

### 原本未照合（honest-hold）

- PI 値の判定表（2.0 以上で良好等）は回転機絶縁の実務慣行値で、由来とされる IEEE Std 43 は原本未照合（正典 [耐圧試験・絶縁診断](insulation-test.md) の限界の明示と同じ扱い）
- 差動保護の適用容量の目安（1000 kW）は保護継電の実務書等で広く使われる水準だが、特定規格への帰属は未照合

### 限界の明示

- 始動方式ごとの電流・トルク比率は理論値（電圧比の2乗則）で、実機は始動器のタップ・モーター特性で変わる。選定時はメーカーの始動特性計算書を正とする
- 振動の判定値は本ページに数値を書かない。[データ活用・予兆保全](../05-hozen/predictive-maintenance.md)（実務目安）とメーカー推奨値による
