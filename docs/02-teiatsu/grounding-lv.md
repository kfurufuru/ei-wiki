# 接地（低圧）

## 30秒まとめ

低圧接地の基本は「D 種接地（100Ω以下）で機器を保護接地する」こと。計装信号のシグナルグランドは保護接地と分離して一点接地にする。インバータのノイズ接地はシールド線と本体を同一点に落とし、ループアースを作らない。

!!! info "用語・分類の整理は計装側へ"
    GND と接地の **違いと種類（FG/SG/AGND/DGND/PGND）の定義** は [グランドと接地](../03-keiso/grounding-gnd.md) に整理しています。
    本ページは **低圧の接地工事（D 種など）の実装** を扱います。

---

## D 種接地（第 3 種接地工事）

| 項目 | 内容 |
|------|------|
| 接地抵抗値 | 100Ω 以下（低圧電路で地絡時 0.5 秒以内に自動遮断する装置を施設する場合は 500Ω 以下） |
| 対象機器 | 使用電圧 300 V 以下の機械器具の金属製外箱・台（電動機外箱・制御盤など） |
| 接地線（法定最小） | 直径 1.6 mm 以上の軟銅線（または引張強さ 0.39 kN 以上の容易に腐食し難い金属線） |
| 色（実務慣行） | 緑または緑/黄縞 |

!!! note "接地線の太さと対象機器の注意"
    - 直径 1.6 mm の軟銅線は断面積換算で約 2 mm² です。実務では機械的強度や回路容量を考慮して IV より線 2 mm²・5.5 mm² などの太めを使うのが一般的ですが、この実務太さは法定値ではありません（下記「根拠」参照）。
    - 変圧器の低圧側**中性点**に施す接地は B 種接地工事であり、本表（D 種）の対象ではありません。D 種の対象はあくまで**機器の金属製外箱・台**です。

!!! info "C 種接地との違い"
    C 種（旧・特別第 3 種接地工事）は **300V を超える低圧機器の保護接地** に使用し、10Ω 以下（0.5 秒以内に自動遮断する装置を施設する場合は 500Ω 以下）とします。D 種は 300V 以下の低圧機器が対象で、両者は「対象機器の電圧区分」で使い分けます。<!-- lint-ok: 20260710-dshu-setchi-10ohm C種の10Ωは正・D種との対比行 -->
    なお、高低圧混触時に低圧側の電位上昇を抑制する接地は **B 種接地**（変圧器低圧側中性点）の役割であり、C 種・D 種とは目的が異なります。<!-- lint-ok: 20260710-cshu-konshoku 混触抑制はB種の役割と明記する正当行 -->

## シグナルグランドと保護接地の分離原則

### 混触リスク

保護接地（PE）は漏電電流・ノイズ電流が流れる。計装信号のシグナルグランド（SG）と同一接地にすると、ノイズが信号に乗り込む。

```
悪い例（PE と SG を共用接地）:
    センサー SG ─────┬── 共用接地 ── 大地
                     │
    インバータ PE ───┘
    （インバータのスイッチングノイズがセンサー信号に干渉）

良い例（分離接地）:
    センサー SG ──── 計装用接地 ──── 大地  ┐
                                            ├ 等電位ボンディング（低インピーダンス）
    インバータ PE ── 保護接地 ──── 大地    ┘
```

### 一点接地の原則

シグナルグランドは計装盤内の一点（スター接地点）に集め、そこから 1 本で大地に落とす。複数点で接地するとループが形成され誘導ノイズの原因になる。

## インバータのノイズ接地（EMC 対策）

| 対策 | 内容 |
|------|------|
| インバータ本体 PE | D 種接地極に直結（専用線、最短経路） |
| モーターケーブル シールド | 盤側端のみ接地（両端接地はループアース）または両端接地（EMC フィルタと組み合わせ） |
| EMC フィルタ接地 | インバータ一次側と同一接地点に接続 |
| 計装ケーブルとの分離 | インバータ配線と計装信号線を **600mm 以上**離隔（通常の動力線 300mm の2倍。正典は [計装配線](../03-keiso/wiring.md)） |

!!! warning "シールドの接地方法"
    シールドケーブルの両端接地はループアンテナになりノイズを拾う場合がある。原則は盤側の一端接地とし、長距離でノイズが乗る場合は両端接地＋EMC フィルタの組み合わせを検討する。

## 等電位ボンディング

### 目的

1. **感電防止**：人体が触れる金属部分の電位差をなくす
2. **爆発防止**：静電気の放電スパークを防ぐ（化学プラント）

### 対象

- 金属製ケーブルラック
- 金属製配管（工程ライン・ユーティリティ配管）
- プラント構造物の金属フレーム
- 機器の金属外箱

```
接地銅バー（等電位ボンディングバー）
    │
    ├── ケーブルラック（ボンディング線 22mm² 以上）
    ├── 配管支持金物（ボンディング線 14mm² 以上）
    ├── 操作盤外箱
    └── D 種接地極
```

## 接地線の色規格と断面積選定

| 用途 | 色 | 太さ |
|------|----|---------|
| 保護接地線（PE） | 緑または緑/黄縞 | 法定最小は直径 1.6 mm の軟銅線（D 種・C 種）。実務では 2 mm² 以上のより線とし回路容量に応じて太くする |
| 中性線（N） | 白または水色 | 相線と同断面積 |
| 等電位ボンディング線 | 緑または緑/黄縞 | 2.5mm² 以上（実務目安） |
| 計装シグナルグランド | 緑または裸線 | 2mm² 以上（実務目安） |

!!! danger "緑の電線は接地専用"
    緑色の電線を接地以外の配線に使用してはならない。誤って信号線や制御線に使うと保守作業時の感電事故につながる。なおこの色分けは内線規程等によるとされる実務ルールで、電技解釈に電線色の規定は無い（下記「根拠」参照）。

## 根拠

- **D 種接地 100Ω 以下・500Ω への緩和条件**: 電気設備の技術基準の解釈（令和7年11月版）**第17条第4項第一号**「接地抵抗値は、100Ω（低圧電路において、地絡を生じた場合に0.5秒以内に当該電路を自動的に遮断する装置を施設するときは、500Ω）以下であること」。**2026-08-01 に原典 PDF で逐語照合**。緩和条件は「0.5 秒以内の自動遮断装置」のみで、感度電流などの数値条件は条文にありません。
- **C 種の抵抗値**: 同**第17条第3項第一号**により 10Ω 以下（500Ω への緩和条件は第4項と同文）。同日逐語照合。
- **接地線の法定最小太さ**: D 種は解釈**第17条第4項第二号**が C 種の規定（**第3項第二号**）を準用し、「引張強さ0.39kN以上の容易に腐食し難い金属線又は直径1.6mm以上の軟銅線」です。かつて本ページは太さを「2.5mm² 以上（電技解釈第17条）」と記載していましたが、**第17条にこの数値はない**ため 2026-08-01 に是正しました。2.5 mm² 等の実務太さは内線規程由来とされますが、内線規程（JEAC 8001）は有料規格で**原本未照合**のため、本ページでは節番号・表番号を引用しません。
- **対象区分（300 V 以下＝D 種、300 V 超過＝C 種、高圧・特別高圧＝A 種）**: 解釈**第29条第1項 29-1表**（機械器具の金属製外箱等の接地）。2026-08-01 に逐語照合。変圧器の低圧側中性点に施すのは B 種接地工事（第17条第2項）で、本ページの対象外です。
- **上位省令**: 電気設備に関する技術基準を定める省令（平成9年通商産業省令第52号）**第10条**（電気設備の接地）・**第11条**（電気設備の接地の方法）。e-Gov 法令 API の現行条文で 2026-08-01 に照合。
- **接地線の「緑／緑黄縞」**: 電技解釈に電線の色を定める規定はありません（令和7年11月版 PDF の全文検索で「緑」は 0 件。2026-08-01 確認）。内線規程・JIS の配線識別によるとされますが、いずれも**原本未照合**のため条項・表番号は挙げません。
- **等電位ボンディング線 2.5 mm²・ラック 22 mm²・配管支持金物 14 mm² などの太さ**: 実務目安であり、**一次資料の裏付けはありません**。社内基準・設計標準がある場合はそちらを優先してください。
- **インバータ配線と計装信号線の離隔 600 mm**: 正典は [計装配線](../03-keiso/wiring.md)。本ページでは根拠を重複記載しません。
- **A〜D 種の基準値一覧・測定手順**: 正典は [接地抵抗測定手順](../guidelines/grounding-inspection.md)。
