# 特別教育・資格一覧

## 30秒まとめ

電気取扱業務に就かせる場合、事業者には特別教育の実施義務がある（労働安全衛生法第59条第3項）。低圧・高圧で必要な教育内容が異なるため、担当させる作業範囲から必要な教育を先に確定する。

---

## 電気取扱の特別教育（法定要件）

電気取扱業務に就かせる場合、事業者は**特別教育の実施が義務**（労働安全衛生法第59条第3項）。

### 低圧電気取扱特別教育

| 項目 | 内容 |
|------|------|
| 対象業務 | 低圧（直流 750 V 以下・交流 600 V 以下）の**充電電路の敷設・修理**の業務、および配電盤室・変電室等**区画された場所**に設置する低圧電路のうち**充電部分が露出している開閉器の操作**の業務（対地電圧 50 V 以下のもの、電信用・電話用等で感電の危害のおそれのないものは除く） |
| 法的根拠 | 労働安全衛生規則 第36条第四号 |
| 必要時間 | 学科7時間＋実技7時間以上（開閉器の操作の業務のみを行う者は実技1時間以上）＝安全衛生特別教育規程第6条 |
| 実施主体 | 事業者（社内実施または外部機関に委託） |
| 対象者 | 上記の対象業務に就く者。実務上は配電盤・制御盤を扱う担当全員に受講させる運用が多い（安全側の社内基準であり法定の範囲より広い） |

### 高圧・特別高圧電気取扱特別教育

| 項目 | 内容 |
|------|------|
| 対象業務 | 高圧（直流 750 V 超 7,000 V 以下・交流 600 V 超 7,000 V 以下）または特別高圧（7,000 V 超）の**充電電路またはその支持物の敷設・点検・修理・操作**の業務 |
| 法的根拠 | 労働安全衛生規則 第36条第四号 |
| 必要時間 | 学科11時間＋実技15時間以上（活線作業・活線近接作業）。充電電路の操作の業務のみを行う者は実技1時間以上＝安全衛生特別教育規程第5条 |
| 実施主体 | 事業者（社内実施または外部機関に委託） |
| 対象者 | 6kV受変電設備・高圧ケーブル作業を行う電気担当者 |

!!! warning "特別教育の記録保管義務"
    特別教育を行ったときは、**受講者・科目等の記録を作成し、3年間保存**しなければならない（労働安全衛生規則第38条）。
    講師名・実施時間などを記録様式に含めるのは実務上の整備です。チームの特別教育記録は人事・安全担当と連携して管理すること。

## 電気計装エンジニアが持っておくべき資格一覧

| 資格 | 法的根拠 | 対象業務 | 優先度 |
|------|---------|---------|--------|
| 第三種電気主任技術者（電験3種） | 電気事業法（第44条第5項・施行規則第56条） | 電圧5万V未満の事業用電気工作物（出力5,000kW以上の発電所・蓄電所を除く）の保安監督 | **高** |
| 低圧電気取扱特別教育 | 労働安全衛生法 | 低圧電気作業全般 | **必須** |
| 高圧・特別高圧電気取扱特別教育 | 同上 | 高圧受変電設備の操作・点検 | **高** |
| 危険物取扱者（乙4） | 消防法 | 引火性液体（ガソリン・灯油等）の取扱 | 中 |
| 高圧ガス製造保安責任者 | 高圧ガス保安法 | 高圧ガス設備（アンモニア・塩素等）の管理 | 状況による |
| エネルギー管理士 | 省エネ法（エネルギーの使用の合理化及び非化石エネルギーへの転換等に関する法律） | エネルギー管理業務、省エネ計画立案 | 中 |
| 第一種衛生管理者 | 労働安全衛生法 | 職場の衛生管理（50人以上の事業場で選任義務） | 状況による |
| 消防設備士（甲/乙4類） | 消防法 | 自動火災報知設備・消火器の点検・工事 | 低〜中 |

### 各資格の補足説明

**第三種電気主任技術者（電験3種）**

化学工場の自家用電気工作物（受変電設備・動力設備）の保安監督には、電験3種以上の免状保有者を**電気主任技術者として選任する義務**がある（電気事業法第43条）。

チームリーダーが取得することで、選任の選択肢が広がる。また、資格取得の過程で得る電気理論・電力・機械・法規の知識は、日常業務での判断力に直結する。

!!! info "電験3種の試験制度"
    年複数回実施・科目別合格制（合格科目の免除に有効期間あり）が採用されており、計画的に受験できる。実施回数・免除条件は変わり得るため、最新の情報は電気技術者試験センターの案内で確認すること（試験制度は法令ではなく試験実施機関の運用）。

**乙種第4類危険物取扱者**

化学工場では引火性液体（溶剤等）を取り扱う設備が多い。消防法上、危険物施設での作業に立ち会う必要がある場面で持っていると有用。計装エンジニアが防爆エリアでの機器選定・工事を担当する際にも知識として役立つ。

**エネルギー管理士**

省エネ法では一定規模以上の工場に「エネルギー管理者」の選任義務がある。電気エネルギー管理の観点から、動力設備の効率改善・省エネ提案を行う際の知識基盤になる。

## 電計チームメンバーへの教育計画の立て方

### ステップ1：現状把握

チームメンバーの資格・特別教育受講状況を一覧化する。

```
チェック項目:
□ 低圧電気取扱特別教育：受講済み / 未受講
□ 高圧・特別高圧電気取扱特別教育：受講済み / 未受講
□ 電験3種：合格済み / 受験中（〇科目合格） / 未受験
□ 乙4：取得済み / 未取得
□ 上記以外（保有資格を自己申告）
```

### ステップ2：業務内容との照合

担当業務に必要な資格・教育が揃っているか確認。

| 業務 | 必要な資格・教育 |
|------|---------------|
| 低圧配電盤の点検・操作 | 低圧電気取扱特別教育 |
| 受変電設備（6kV）の操作・点検 | 高圧・特別高圧電気取扱特別教育 |
| 電気設備全体の保安監督 | 電験3種（電気主任技術者として選任） |
| 防爆エリアでの工事立会 | 低圧または高圧特別教育＋防爆の知識（OJT） |

### ステップ3：優先順位をつけた取得計画

!!! tip "メンバーへの説明ポイント"
    「なぜその資格が必要か」を業務と紐づけて説明すると、自発的な学習意欲につながる。
    電験3種は「会社に言われたから」ではなく、「自分の専門性を高める武器」として伝える。

**年次別モデルプラン（新入〜中堅）**

| 年次 | 取得目標 | 備考 |
|------|---------|------|
| 入社1年目 | 低圧電気取扱特別教育 | 配属直後に実施（OJT前に必須） |
| 入社1〜2年目 | 高圧・特別高圧電気取扱特別教育 | 受変電設備OJT開始前に |
| 入社2〜3年目 | 電験3種（1〜2科目）受験開始 | 業務経験と並行 |
| 入社3〜5年目 | 電験3種合格 / 乙4取得 | キャリアの核となる資格 |
| 中堅以降 | エネルギー管理士 / 高圧ガス等 | 担当業務に応じて選択 |

### ステップ4：フォロー体制

- 月1回程度、電験3種受験中メンバーと進捗確認（科目別の理解状況・苦手分野）
- 特別教育は外部機関（労働基準協会・電気工事士会等）の講習に送り出す
- 受験費用・テキスト代は会社負担のルールを事前確認し、メンバーに案内

## 根拠

- **特別教育の実施義務**: 労働安全衛生法（昭和47年法律第57号）**第59条第3項**（危険又は有害な業務で厚生労働省令で定めるものに労働者をつかせるときは、当該業務に関する安全又は衛生のための特別の教育を行わなければならない）。
- **対象業務（電気取扱）**: 労働安全衛生規則（昭和47年労働省令第32号）**第36条第四号**。低圧・高圧・特別高圧の電気取扱は**いずれも同じ第四号**に定められており、条文が対象とするのは次の3類型です。
    - 高圧・特別高圧の**充電電路またはその支持物**の敷設・点検・修理・操作の業務
    - 低圧の**充電電路**の敷設・修理の業務（対地電圧 50 V 以下のもの、電信用・電話用等で感電の危害のおそれのないものを除く）
    - 配電盤室・変電室等**区画された場所**に設置する低圧電路のうち**充電部分が露出している開閉器**の操作の業務
    - 電圧区分の定義（低圧＝直流 750 V 以下・交流 600 V 以下、高圧＝これを超え 7,000 V 以下、特別高圧＝7,000 V 超）も同号のかっこ書きが定めます。なお、対地電圧 50 V 超の蓄電池を内蔵する自動車の整備は**第四号の二**（別の特別教育）です。
- **教育時間**: 安全衛生特別教育規程（昭和47年労働省告示第92号）**第5条**（高圧・特別高圧＝学科計11時間、実技は活線作業・活線近接作業の方法について15時間以上。**充電電路の操作の業務のみを行う者は実技1時間以上**）・**第6条**（低圧＝学科計7時間、実技は活線作業・活線近接作業の方法について7時間以上。**開閉器の操作の業務のみを行う者は実技1時間以上**）。かつて本ページは低圧の実技を一律「1時間」とし「充電部分が露出しない場合は実技不要」としていましたが、**規程第6条の原則は実技7時間以上**であり、1時間以上で足りるのは開閉器の操作の業務のみを行う者に限られるため、2026-08-01 に是正しました。
- **記録の保存**: 安衛則**第38条**（特別教育を行ったときは、受講者・科目等の記録を作成し、**3年間保存**）。
- **電気主任技術者**: 選任義務は電気事業法第43条第1項（条項レベルの正典は [法定業務一覧](../09-hoantokei/legal-duties.md)）。免状の種類ごとの監督範囲は法**第44条第5項**の委任を受けた施行規則**第56条**の表で、第三種は「電圧五万ボルト未満の事業用電気工作物（**出力五千キロワット以上の発電所又は蓄電所を除く**）」です。かつて本ページは除外対象を「発電所」のみとしていましたが、現行条文は「発電所**又は蓄電所**」のため 2026-08-01 に是正しました。
- **衛生管理者**: 労働安全衛生法**第12条第1項**・同施行令（昭和47年政令第318号）**第4条**（常時50人以上の労働者を使用する事業場で選任）。

労働安全衛生法・安衛則・施行令・電気事業法・同施行規則は **e-Gov 法令検索の現行条文（API取得）で 2026-08-01 に逐語照合**しました。安全衛生特別教育規程は e-Gov 法令データベースに収録されていない**告示**のため、**厚生労働省の法令等データベースに掲載の告示本文で 2026-08-01 に照合**しています。

**限界の明示**:

- 学科教育の**科目別の内訳時間**（規程第5条・第6条が科目ごとに定める時間）は本ページでは合計のみ記載しています。教育カリキュラムを組む際は告示原文の科目・時間の表に当たってください。
- 電験3種の**試験制度**（実施回数・科目別合格の免除条件）は法令ではなく試験実施機関の運用であり、条文照合の対象外です。受験時は電気技術者試験センターの最新案内で確認してください。
- 危険物取扱者・消防設備士・高圧ガス製造保安責任者・エネルギー管理士の各行は資格制度の概要であり、**選任義務の発生条件（指定数量・規模区分等）の条文照合は行っていません**。該当し得る場合は各法令の原典と所轄で確認してください。
- フォークリフト等、電気以外の特別教育（安衛則第36条の他の号）は本ページの対象外です。
