# 制御回路

## 30秒まとめ

展開接続図は「電源左右 → 素子を横に並べる」基本形。インターロック設計の核心はフェールセーフ（断線 = 停止）。制御電源は DC24V が現代の標準。AC100V 制御回路は制御変圧器（絶縁トランス）で主回路から絶縁し、DC24V は絶縁型スイッチング電源から供給して系統を分ける。

---

## 展開接続図の読み方

### 横書き形式（一般的な日本の制御盤）

```text
制御電源 L（ホット） ────素子────────── N（ニュートラル）

各行に 1 回路ずつ並べる。左が電源、右が負荷（コイルや表示灯）。
```

### 縦書き形式（ラダー形式）

```text
左母線（＋または L）
│
├─[素子]─[素子]─ (コイル) ─┤
│
├─[素子]───────── (コイル) ─┤
│
右母線（－または N）
```

縦書きはラダー図とほぼ同じ構造。DCS・PLC のラダープログラムを読む際に必要。なお、図記号そのものの規格は JIS C 0617（電気用図記号）です。展開接続図の縦書き／横書きという書式を定める規格ではなく、本ページの `─┤ ├─` 等はテキスト表現の便宜的な略記です（規格の主題は [JIS規格マップ](../03-keiso/jis-standards.md) 参照）。

---

## 基本素子一覧

| 記号 | 名称 | 説明 |
|------|------|------|
| ─┤ ├─ | 常開接点（NO） | コイル励磁時に閉 |
| ─┤/├─ | 常閉接点（NC） | コイル励磁時に開 |
| ─( )─ | コイル | 励磁すると対応接点が動作 |
| ─[TMR]─ | タイマ | 遅延動作（ON 遅延 / OFF 遅延） |
| ─[CNT]─ | カウンタ | 入力パルス数のカウント |
| ─[CR]─ | 補助リレー | 内部接点の増幅 |
| ─┤PB├─ | 押しボタン | 手動操作（瞬時接点） |
| ─┤LS├─ | リミットスイッチ | 位置検出 |
| ─┤PRS├─ | 圧力スイッチ | 圧力検出 |

## インターロック設計の 3 原則

### 1. フェールセーフ（Fail-Safe）

回路の断線・電源喪失・故障のいずれが起きても「安全な状態（停止・閉）」へ向かうように設計します。

核心は保護・許可リレーを**常時励磁（normally energized）**にすることです。正常運転中は常にコイルを励磁して運転許可接点を保持し、「電源が生きている＝運転を許可」という向きにします。こうすると、トリップ・電源喪失・配線断線のどれでもコイルが消磁し、運転許可が外れて自動的に安全側（停止）へ落ちます。

```text
良い例（フェールセーフ / 常時励磁）:
正常時 = 許可リレー励磁 → 運転許可接点を保持 → 運転
異常（トリップ）・電源喪失・断線 = コイル消磁 → 運転許可が外れる → 停止
→ 「電源が切れる = 停止する」向きなので、断線・停電でも安全側に落ちる

悪い例（動作時励磁）:
停止指令リレーを「異常時だけ励磁して停止させる」設計
→ 断線・電源喪失時はコイルを励磁できない → 停止指令が出ず、危険側で運転継続
```

- 非常停止（EMS）：NC接点を直列にして常時励磁ループを組む。押下または断線でループが切れ、コイル消磁で停止
- 保護リレー：正常時に励磁して運転許可を出し、動作（トリップ）または補助電源喪失で消磁して遮断器を開放する

いずれも「コイルが消磁する＝停止」という一方向の論理に統一する点がフェールセーフの要です。

### 2. フールプルーフ（Fool-Proof）

誤操作しても危険な動作が起きないようにする。

- 正逆転 MC の同時投入を機械・電気インターロックで防止
- 作業者の手が届く範囲では起動条件に扉インターロックを追加

### 3. 二重化（Redundancy）

単一故障で保護機能が失われないよう、重要な保護回路は二重化する。

| 対象 | 二重化の方法 |
|------|------------|
| 非常停止回路 | 2 系統の NC 接点を直列 |
| 高温保護 | 温度スイッチ + 独立した温度リレー |
| 重要ポンプ起動許可 | 2 個のフロートスイッチ |

## 制御電源系統（AC100V vs DC24V の使い分け）

| 項目 | AC 100V | DC 24V |
|------|--------|--------|
| 主な用途 | 大型 MC・コイル・電磁弁（大容量） | PLC I/O・センサー・小型 MC |
| 安全性 | 感電リスクあり（保護対策必要） | 低電圧で比較的安全 |
| 伝送距離 | 電圧降下が少ない | 長距離では電圧降下に注意 |
| ノイズ耐性 | 高い（外来ノイズの影響小） | 低い（シールド・フィルタが必要） |
| 機器コスト | 低い（汎用品が豊富） | やや高い（DC 電源が必要） |

**現代の標準：** DC24V を制御主体とし、大型 MC・電磁弁のみ AC100V に残す。AC100V 制御回路は制御変圧器（絶縁トランス）で主回路から絶縁し、DC24V は絶縁型スイッチング電源（トランスで一次側と絶縁）から供給して系統を分ける。

## 非常停止回路

### 設計要件

1. 停止カテゴリは **0**（即時動力遮断）を選ぶことが実務上多い（カテゴリ分類と適用例の正典は [モーター制御](motor-control.md) の停止カテゴリ節）
2. 非常停止ボタンは必ず NC 接点を使用
3. 非常停止ボタンは機械的ラッチ式（押しロック・ひねり解除等）とし、ボタンの解除操作だけでは再起動しない
4. 非常停止後の再起動は意図的な操作（起動 PB 押下）が必要

```text
L1 ─[EMG 停止 NC]─[EMG 停止 NC 2系]─[停止 NC]─┬─[起動 PB NO]──┬─(MC コイル)─ L2
      非常停止1           非常停止2            └─[MC 補助接点 a]─┘ ← 自己保持
         └────二重化────┘
```

自己保持（MC 補助接点）が無いと起動 PB を押している間しか運転できない。自己保持回路の実体は [モーター制御](motor-control.md) が正典。

!!! info "IEC 60204-1（JIS B 9960-1）の停止カテゴリ"
    カテゴリ 0: 即時動力遮断（非制御停止）。カテゴリ 1: 制御停止後に動力遮断。カテゴリ 2: 制御停止・動力保持。化学プラントのポンプ・コンプレッサーはカテゴリ 0 とするのが実務慣行（分類・適用例・照合状態は [モーター制御](motor-control.md) の根拠節が正典）。

### 是正の記録（2026-08-06）

- **「縦書き形式（JIS C 0617 準拠）」の誤帰属を削除**: JIS C 0617 は電気用図記号の規格であり（規格の番号・主題は [JIS規格マップ](../03-keiso/jis-standards.md) で JSA カタログ確認済み）、展開接続図の縦書き／横書きという書式を定める規格ではありません。見出しを「縦書き形式（ラダー形式）」に改め、図記号の規格としての位置づけを本文に注記しました。
- **「非常停止回路（IEC 60204 準拠）」の準拠宣言を削除**: 原本未照合の規格への準拠宣言だったため見出しから外しました。停止カテゴリ 0/1/2 の照合状態（箇条は原本未照合・適用例は実務慣行）は [モーター制御](motor-control.md) の根拠節が正典です。
- **「非常停止回路は自己保持しない」を是正**: 旧記述は「非常停止装置自体はラッチ保持しない」と逆に読めます。ラッチしない非常停止ボタンは手を離すと復帰してしまい危険側です。「非常停止ボタンは機械的ラッチ式とし、解除操作だけでは再起動しない」に改めました（非常停止機器の製品規格として IEC 60947-5-5〔機械的ラッチ付き〕への言及は [操作盤・表示の配色](panel-hmi.md) と整合）。
- **非常停止回路例に自己保持分岐を追記**: 旧回路例は起動 PB に並列の自己保持接点が無く、押している間しか運転できない不完全な回路でした。MC 補助接点の自己保持分岐を追記しました（回路の実体は [モーター制御](motor-control.md) が正典）。
- **「AC と DC は絶縁トランスで分離し混触を防ぐ」の機序を是正**: DC24V は絶縁型スイッチング電源の内部トランスで一次側（AC）と絶縁されるのであって、AC/DC 間に絶縁トランスという部品を挟むのではありません。「AC100V 制御回路は制御変圧器（絶縁トランス）で主回路から絶縁、DC24V は絶縁型スイッチング電源から供給」に改めました（30秒まとめ側の同一記述も同時に是正）。

### 実務慣行（規格・法令の裏付けなし）

- 保護・許可リレーの常時励磁（normally energized）設計、二重化の対象例、DC24V 主体・AC100V を大容量に残す使い分け、AC/DC の特徴比較表は実務の定石・目安であり、規格の規定値として照合したものではありません。
