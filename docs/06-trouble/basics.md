# トラブル対応の基本

## 30秒まとめ

化学プラントのトラブル対応は「安全確保 → 情報収集 → 切り分け → 対処・記録」の4ステップが基本。**まず現場の安全を確認してから動く**。焦って触ると二次災害になる。

!!! danger "緊急時はまず初動対応フロー"
    実際にトラブルが発生したら、まず [トラブル初動対応フロー](../guidelines/trouble-first-response.md) に従って動いてください。安全確保・製造課への第一報・現状把握・エスカレーション判断まで1枚で完結する初動SOPです。
    本ページは初動対応の背景にある **切り分けの考え方** を教育目的で解説するページです。

---

## 化学プラント特有の注意事項

!!! danger "防爆エリアでの作業前確認"
    可燃性ガス・蒸気が存在する防爆エリアでは、電気作業前にガス検知を行うこと。
    火花・アーク発生が引火源になるリスクがある。防爆対応工具・防爆対応機器以外を持ち込まない。

!!! warning "高圧ガス保安法上の記録義務（帳簿）"
    第一種製造者は、**製造施設に異常があった場合、その年月日と講じた措置**を帳簿に記載し、
    記載の日から **10 年間**保存する義務があります（高圧ガス保安法第60条第1項・一般高圧ガス保安規則第95条第1項の表第三号。下の「根拠」参照）。
    法定の帳簿対象は「製造施設の異常」ですが、実務では対象を限定せず、トラブル対応の内容・結果を
    トラブルログ（`factory/trouble-log.md` 相当）に残す社内運用とします。
    「直ったからいい」で終わらせると、後の検査・監査で記録の欠落を指摘されます。

!!! warning "単独作業の禁止"
    6.6kV 高圧系統や密閉空間付近での作業は必ず2名以上で実施すること。
    保護具（絶縁手袋・絶縁長靴・保護メガネ）の着用を怠らない。
    （「2名以上」は法令の一般的義務ではなく、安全側の社内基準です。下の「根拠」参照）

## トラブル対応4ステップ

### STEP 1 — 安全確保

安全確保は初動対応の最優先事項です。具体的な手順（目視確認・ガス検知・プロセス影響確認・ロックアウト/タグアウト）は初動SOPに一本化しています。

- 手順の詳細 → [トラブル初動対応フロー STEP 1：安全確認](../guidelines/trouble-first-response.md#safety)

安全確保前に機器へ触れないことが大原則です。状況が把握できない段階での操作は厳禁です。

---

### STEP 2 — 情報収集

対応が速くなる情報収集の優先順位：

| 優先 | 確認項目 | 確認方法 |
|------|----------|----------|
| 高 | いつ発生したか（発生時刻） | DCS趨勢・アラームログ |
| 高 | 何が変化した直前に起きたか | 製造担当へのヒアリング |
| 高 | アラームの種類・内容 | DCS画面・現場盤のランプ |
| 中 | 最後の正常状態はいつか | 設備台帳・点検記録 |
| 中 | 最近の変更作業 | 作業報告書・MOC記録 |
| 低 | 過去の同じ症状の履歴 | トラブルログ |

!!! tip "製造担当への第一報"
    プロセスへの影響が不明な段階で、まず製造当直に連絡を入れること。
    「電気設備のトラブルを確認中。プロセスへの影響を調査しています」と伝えるだけでよい。
    放置して後から「なぜ早く言わなかった」と言われる方が問題になる。

---

### STEP 3 — 切り分け

#### 基本原則：「計器を疑う」

実際のプロセス異常ではなく、計測・制御系の問題である可能性を常に念頭に置く。
切り分けの順序：

```
センサ（一次側）
  └→ 伝送器（変換・増幅）
       └→ 配線（断線・ノイズ）
            └→ 制御システム（DCS/PLC設定・ソフト）
```

現場で直接測定できるものから確認する。DCS表示だけを信用しない。

#### 系統別の分類

| 系統 | 確認ポイント |
|------|------------|
| 電源系 | 電圧・電流・MCCB状態・ヒューズ |
| 信号系 | 4-20mA値・配線導通・シールド |
| 機械系 | 軸受温度・振動・カップリング |
| 制御系 | PLCラダー・DCS設定値・インターロック条件 |

!!! tip "切り分けの鉄則"
    一度に複数箇所を変更しない。1点変更 → 確認 → 次の変更。
    複数点を同時に変更すると、どれが効いたかわからなくなる。

---

### STEP 4 — 対処・記録

#### 対処の判断基準

- **応急処置で対応可能**：バイパス運転・手動操作・部品交換で継続できる場合
- **定修まで保留**：プロセスを止めずに監視継続できる場合（部品調達・計画修理）
- **緊急停止が必要**：安全に関わる場合・悪化が予見される場合

#### 記録に残す内容

記録項目のフォーマットは初動SOPに一本化しています。

- 記録項目の一覧 → [トラブル初動対応フロー STEP 6：復旧後の記録](../guidelines/trouble-first-response.md#record)

製造施設の異常と講じた措置は、高圧ガス保安法第60条第1項に基づく帳簿への記載・保存の対象です（条文の範囲は下の「根拠」参照）。記録は「自分が覚えているから不要」ではなく、**組織の資産として残す**意識を持ってください。

## よくある思い込みと正しい考え方

| 思い込み | 実際 |
|---------|------|
| 「さっきまで動いていたから電気じゃない」 | 間欠的な接触不良・熱膨張による影響は突然現れる |
| 「アラームが出ていないから問題ない」 | アラーム設定が甘い・センサ自体が壊れている可能性 |
| 「リセットしたら直った。もう大丈夫」 | 根本原因が残っている。再発する可能性が高い |
| 「電気じゃなくて機械の問題だ」 | 電気と機械は相互に影響する。分野をまたいで確認する |
| 「前回もこうやって直した」 | 症状が似ていても原因が違うことがある。先入観で動かない |

- エスカレーション要否の判断基準 → [トラブル初動対応フロー STEP 5：エスカレーション判断](../guidelines/trouble-first-response.md#escalation)

!!! warning "電気主任技術者への報告"
    電気主任技術者への社内報告は、電気事業法第42条第1項に基づき事業場ごとに定める**保安規程**の事故連絡手順によります（電気事業法そのものに「主任技術者へ報告せよ」という直接の条文はありません。なお従事者には、主任技術者が保安のためにする指示に従う義務があります＝法第43条第5項）。
    国への法定の事故報告は電気関係報告規則第3条の**限定列挙**で、対象判定と速報・確報の期限は [電気事故対応と報告](../09-hoantokei/jiko-taiou.md) を参照してください。
    「軽微だと思ったので報告しなかった」が通用しないのは、社内報告でも同じです。

## 根拠

本ページの4ステップ・優先順位表・切り分け順序は、法令・規格が要求する手順ではなく**実務経験則**です。記載内容の位置づけを次のとおり区分します。

### 法令に基づく事項（一次照合済み）

- **高圧ガスの帳簿（記録義務）**: 高圧ガス保安法（昭和26年法律第204号）**第60条第1項**が第一種製造者等に帳簿の記載・保存を義務付け、一般高圧ガス保安規則（昭和41年通商産業省令第53号）**第95条第1項**の表**第三号**が「製造施設に異常があつた場合」に「異常があつた年月日及びそれに対してとつた措置」を記載し、**記載の日から10年間**保存することを定めています（e-Gov 法令検索の現行条文で **2026-08-01 に逐語照合**）。法定の帳簿対象は「製造施設の異常」に限られ、あらゆるトラブル対応の記録が法定義務なのではありません。トラブルログ全般を残すのは社内運用としての上乗せです。
- **国への電気事故報告**: 電気関係報告規則第3条の限定列挙です。対象事故の判定（感電死傷は死亡または入院した場合に限る等）と速報・確報の期限は [電気事故対応と報告](../09-hoantokei/jiko-taiou.md) が正典のため、本ページには数値を書きません。
- **電気主任技術者への社内報告**: 電気事業法**第42条第1項**（保安規程）に基づき事業場ごとに定める保安規程の事故連絡手順によります（保安規程の制度は [保安規程の管理](../09-hoantokei/hoan-kisoku.md) が正典）。かつて本ページは「電気事業法に基づき電気主任技術者への報告が必要」としていましたが、**電気事業法に主任技術者への報告を直接義務付ける条文は無い**ため 2026-08-01 に是正しました。法第43条が定めるのは選任（第1項）・主任技術者の誠実職務義務（第4項）・従事者が保安のための指示に従う義務（第5項）です（e-Gov 逐語照合 2026-08-01）。

### 実務慣行・社内基準（法定ではない）

- 4ステップ（安全確保 → 情報収集 → 切り分け → 対処・記録）、情報収集の優先順位表、「計器を疑う」切り分け順序（センサ → 伝送器 → 配線 → 制御システム）、「1点変更 → 確認」の鉄則、「よくある思い込み」表、対処の判断基準（応急処置／定修まで保留／緊急停止）— いずれも実務経験則であり、法令・JIS の要求ではありません。
- 「2名以上での作業」は安全側の社内基準です。労働安全衛生規則には停電作業時の監視人等の規定（第339条第1項第一号の選択肢）はありますが、「常に2名以上」を一般的に義務付ける条文は本ページでは確認していません。
- 防爆エリアでの作業前ガス検知は安全側の実務です。可燃性ガスの測定を義務付ける労働安全衛生規則の個別条文への照合は行っていません（honest hold）。Zone 区分・防爆構造の一般知識は [防爆の基礎](../03-keiso/explosion-proof.md) を参照してください。

### 照合の限界

- 高圧ガス保安法の下位規則は施設区分で異なります（液化石油ガス保安規則・冷凍保安規則・大規模石油化学地区向けの保安規則など）。本ページで帳簿の規定を照合したのは**一般高圧ガス保安規則のみ**で、適用規則が異なる施設では帳簿の記載事項・保存期間が異なり得ます。必ず自社の適用規則と保安規程で確認してください。
