# 計装配線

## 30秒まとめ

計装配線のトラブルの多くは「シールドの多点接地によるグラウンドループ」「動力線との近接によるノイズ」「ループ抵抗計算漏れ」の3つ。ケーブル選定・離隔距離・シールド接地を正しく管理する。

---

## ケーブル種別の選定

型式記号は**規格ごとに実体が決まっています**。似た記号の取り違えが起きやすいので、下記「根拠」も併せて確認してください。

| 種別 | 構造・シールド | 芯数 | 主な用途 |
|------|---------|------|---------|
| **CVV-S**（制御用ビニル絶縁ビニルシースケーブル 遮へい付） | 銅テープの総合遮へい。**対より（ツイストペア）ではない** | 2〜30 心 | 制御回路・信号一般 |
| **KPEV-S 系**（弱電計装用ケーブル。メーカーにより IPEV-S 等） | **対より＋一括（総合）遮へい** | 1〜20 対 | 4-20 mA 信号・複数ループの一括配線 |
| **補償導線**（KX / KCA / KCB 等） | あり/なし | 2芯 | 熱電対の延長。記号・識別色・使用温度は [温度計測](temperature.md) が正典 |
| フッ素樹脂絶縁（ETFE・FEP・PFA 等） | あり | 2芯〜 | 100 ℃超の高温箇所。**汎用の型式記号はなくメーカー型式で選定** |
| 耐薬品ケーブル | あり | 2芯 | フッ酸・塩酸等の薬液環境。シース材で選定 |

- 接地点は **DCS（制御盤）側の1点のみ**
- フィールド側は絶縁テープ等でシールド端末を絶縁処理する
- 補償導線のシールドも同様

!!! note "グランドと接地の違いがあいまいな場合"
    「グランド（基準電位）」と「接地（大地接続）」の区別、グランドの種類（FG/SG/AGND/DGND/PGND）は
    [グランドと接地](grounding-gnd.md) で整理しています。

## 動力線との離隔基準

離隔距離は**実務目安**で、法令・規格が定めた値ではありません（下記「根拠」参照）。

| 条件 | 最小離隔距離 |
|------|-----------|
| 平行布設（金属仕切りなし） | 300 mm 以上 |
| 平行布設（金属仕切りあり） | 150 mm 以上 |
| 交差（クロス） | 90°で交差すれば離隔不要 |

!!! warning "インバータ配線との離隔"
    インバータ（VFD）の電力ケーブルは通常の動力線より高周波ノイズが多い。
    計装ケーブルとの離隔は通常動力線の**2倍（600mm以上）**を確保することを推奨する。

## 強電 / 弱電ケーブルラックの分離

プラントのケーブルラックは以下の原則で分離する。

```text
上段ラック：6.6kV・440V 動力ケーブル
中段ラック：100V 制御ケーブル
下段ラック：計装信号ケーブル（分離が難しい場合は金属セパレータで仕切る）
```

!!! warning "段の並び順を定めた法令・規格はありません"
    電気設備の技術基準の解釈 **第167条**（低圧配線と弱電流電線等又は管との接近又は交差）が定めているのは
    **離隔距離・絶縁性の隔壁・同一の管／ダクト／ボックスに収容しないこと**であって、
    **上下どちらに置くかではありません**（2026-08-03 に原典 PDF で逐語照合。下記「根拠」参照）。
    上の並びは本 Wiki が採る一例です。**守るべき本質は「接触させない」「離隔をとる」「同一ダクトに混在させない」**の3点で、
    段の順序は設計側の裁量です。

## ループ抵抗計算

4-20mA ループで計器が正常動作するためには、ループ内の全抵抗が許容負荷抵抗以下であること。

### 計算式

```text
許容負荷抵抗 = (電源電圧 - 伝送器最低動作電圧) / 最大電流
             = (24V - 12V) / 0.020A
             = 600 Ω  （標準的な24V系の目安）
```

### ループ抵抗の内訳

| 要素 | 抵抗値の目安 |
|------|-----------|
| ケーブル往復抵抗 | 導体断面積 1.25mm²（銅）の場合：片道 約 14.6 Ω/km（20℃。出所は下記「根拠」参照）→ 往復で約 29 Ω/km |
| DCS 入力抵抗 | 100〜250 Ω |
| 本安バリア（Zener型） | 100〜300 Ω |
| ループキャリブレータ接続時 | +50 Ω |

!!! note "本安バリア追加時の注意"
    本安バリアを後から追加すると 100〜300 Ω が加算される。
    既存ループに追加する場合はループ抵抗の再計算が必要。

## 端子台番号管理

計装配線は端子台経由で接続されることが多い。番号管理のルールを統一しておくことで保全・調査の効率が大きく向上する。

### 番号管理の推奨ルール

```text
ループ番号 - 端子番号 の形式で管理
例：FIC-101 の配線は FIC101-01（+）、FIC101-02（-）、FIC101-03（シールド）
```

| 項目 | 推奨ルール |
|------|---------|
| AI（アナログ入力） | +線・-線・シールドを連番で管理 |
| DI（接点入力） | 接点番号を明記 |
| 共通線（COM） | COM を明示して隣の端子と区別 |
| 予備端子 | SPARE として明記 |

!!! tip "端子台の配線図（ループ図）との照合"
    端子番号は「ループ図（Loop Diagram）」に記載されているはずなので、
    工事後に必ずループ図と現場配線の照合を行う。ループ図が古いままのプラントでは
    この照合作業が保全工数削減の第一歩になる。

## 根拠

### ケーブル型式記号3件を是正しました（2026-08-03）

型式記号の実体を各社の公開カタログ・規格の全文で確認し、**3件が別物を指していた**ことが分かりました。

| 記号 | かつての本ページ | 確認結果 |
|---|---|---|
| **MVVS** | マルチペア（対シールド＋総合）。複数ループの一括配線 | **マイクロホン用ビニルコード**（JCS 4271）。1〜4 心・総合編組シールドのみで、**対より構成も対別シールドも持ちません**。計装用マルチペアは別系統の **JCS 4364「弱電計装用ケーブル」**（市中通称 KPEV-S、メーカーにより IPEV-S 等） |
| **KV** | 補償導線。2芯 | **通信機器用ビニル電線**（JCS 3368。機器内配線用・100 V 未満）。**補償導線ではありません。** 補償導線は JIS C 1610:2012 の **KX / KCA / KCB**（K 型）等で、[温度計測](temperature.md) が正典です |
| **FRXX-S** | 耐熱・2芯・シールド付 | 規格一覧・主要メーカーの公開資料を探した範囲で**この記号は見つかりませんでした**。100 ℃超はフッ素樹脂系（ETFE・FEP・PFA 等）を**メーカー型式で選定**するのが実態で、汎用の型式記号は確認できていません |

**CVV-S** は実在の記号でしたが、芯数を「2〜37芯」としていたのを **2〜30 心**に是正しました。あわせて **CVV-S は対より構造ではない**ことを表に明記しています（4-20 mA の定番はむしろ対よりの KPEV-S 系で、ここを混同すると誘導ノイズ対策の前提が崩れます）。

### 段の並び順は法令・規格の定めがありません（ページ間不一致の解消）

本ページは「上段＝動力／下段＝計装信号」、[電路設計](../04-sekkei/cable-route.md) は「上下配置（強電下・弱電上）」と、**同じ repo 内で真逆**でした。

**電気設備の技術基準の解釈 第167条**（低圧配線と弱電流電線等又は管との接近又は交差）を原典 PDF で **2026-08-03 に逐語照合**した結果は次のとおりで、**並び順の規定はありません**。

- 第1項（がいし引き工事）: 離隔 **10 cm**（裸電線は **30 cm**）以上、または使用電圧 300 V 以下での**絶縁性の隔壁**・難燃性の絶縁管
- 第2項（管・ダクト・ケーブル工事等）: **接触しないように施設**すること
- 第3項: **同一の管・線ぴ・ダクト・ボックスに収めない**こと（堅ろうな隔壁＋C種接地等の例外あり）

一次資料でどちらが正しいとは決められないため、**値を推測で入れ替えることはせず**、本ページを段配置の正典として「並び順は設計裁量」と明示し、電路設計側からは方向の指定と出所不明の 200 mm を撤回しました。

### 実務慣行（規格・法令の裏付けなし）

- **離隔距離 300 mm / 150 mm、交差 90°で離隔不要、インバータ配線は2倍（600 mm）**。いずれも実務目安です。第167条が定めるのは上記の 10 cm / 30 cm・隔壁・同一ダクト禁止であって、これらの数値ではありません
- **DCS 入力抵抗 100〜250 Ω・本安バリア 100〜300 Ω・キャリブレータ +50 Ω**は機種によります。実際の値は機器仕様書で確認してください
- ループ抵抗計算の**伝送器最低動作電圧 12 V** は代表値です（機種により 10.5〜12 V 程度）。式そのもの（許容負荷抵抗 =（電源電圧 − 最低動作電圧）÷ 最大電流）は定義どおりで、24 V・12 V・20 mA から 600 Ω になることを 2026-08-03 に再計算して確認しました
- 端子番号の付け方（ループ番号 − 端子番号）

### 原本未照合（honest-hold）

- **JCS 4258 / 4271 / 4364 / 3368（日本電線工業会規格）・JIS C 3401 / C 1610 の原本は未照合**です。上表は各社の公開カタログと規格全文の転載サイトで一致を確認したもので、条項番号・表番号までは引用しません
- **1.25 mm² の片道抵抗 14.6 Ω/km の出所は特定できていません。** 本 Wiki の導体抵抗の正典は [電圧降下計算](../04-sekkei/voltage-drop.md)（JIS C 3605 系）ですが、同表は CV の 2 mm² 以上で 1.25 mm² を含みません。ループ抵抗の検討では**使用するケーブルのメーカー値**を使ってください
- **対別遮へい＋総合遮へいの二重シールド品を表す統一型式記号は確認できていません**（メーカー個別仕様です）

### 限界の明示

- 型式記号は**メーカー・時期によって呼称が変わります**。本ページの記号は選定の入口であり、**実物の仕様は必ず最新カタログで確認**してください
- シールドの片端接地は**アナログ信号回路の原則**です。高周波を扱う通信ケーブルでは別の考え方（多点接地）を採ることがあります。グランド種別の整理は [グランドと接地](grounding-gnd.md) が正典です
