# 電気事故対応と報告

## 30秒まとめ

報告対象となる電気事故は電気関係報告規則 第3条で限定列挙されており、すべての不具合が報告対象ではない。まず該当するかを条文で判定し、該当すれば速報・確報を期限内に提出する。

---

## 電気事故の定義（電気関係報告規則 第3条）

電気事業法の「事故報告」対象となる電気事故は以下に限定される。すべての不具合が報告対象ではない。

### 自家用電気工作物の設置者に関係する号（第3条第1項）

下表は条文の限定条件を落とさずに整理したものです。**括弧内の限定こそが判定の本体**であり、これを省いて覚えると報告要否を誤ります。

| 号 | 事故 | 報告先 |
|---|------|------|
| **一** | 感電**または**電気工作物の破損・誤操作・**操作しないこと**により人が死傷した事故（**死亡または病院・診療所に入院した場合に限る**） | 産業保安監督部長 |
| **二** | 電気火災事故（**工作物にあっては、その半焼以上の場合に限る**） | 産業保安監督部長 |
| **三** | 電気工作物の破損・誤操作・操作しないことにより、**他の物件に損傷を与え、またはその機能の全部もしくは一部を損なわせた**事故 | 産業保安監督部長 |
| **四ヌ** | **電圧1万V以上の需要設備**に属する主要電気工作物の破損事故 | 産業保安監督部長 |
| **十二** | 一般送配電事業者・配電事業者・特定送配電事業者の電気工作物と電気的に接続されている**電圧3,000V以上**の自家用電気工作物の破損・誤操作・操作しないことにより、これらの事業者に**供給支障を発生させた**事故 | 産業保安監督部長 |
| **十四** | 第一号から第十三号までの事故以外で、**電気工作物に係る社会的に影響を及ぼした事故** | 産業保安監督部長 |

!!! danger "「主要電気工作物の破損」で報告義務が生じるのは受電電圧1万V以上"
    第四号ヌの需要設備は **電圧1万V以上**（自家用電気工作物を設置する者に限る）という限定付きです。したがって**6.6 kV 受電の一般的な高圧需要家では、変圧器・遮断器が壊れただけでは第四号の報告対象になりません**。
    ただしその破損が**電力会社側に供給支障を波及させた**なら、電圧3,000 V 以上という別基準の**第十二号**で報告対象になります。「うちは6.6 kVだから機器破損は報告不要」と機械的に打ち切らず、**第一号（人身）・第二号（火災）・第三号（他物件への損傷）・第十二号（供給支障）・第十四号（社会的影響）を必ず併せて当てる**こと。
    受電電圧の閾値が1万Vという点は[工事計画届出](legal-duties.md)と同じですが、**両者は別の制度**であり、閾値が一致するのは偶然です。片方の結論をもう片方に流用しないでください。

!!! warning "第十四号が受け皿になっている"
    第十四号「社会的に影響を及ぼした事故」は限定列挙の穴を埋める包括条項です。**第一号〜第十三号のどれにも当たらないから報告不要、という推論は成り立ちません**。近隣への影響・報道・行政への通報が生じた事故は、この号で報告対象になり得ます。

### 報告対象外の事例（記録は残す）

条文のどの号にも当たらない、という判定ができた場合に限ります。

- ヒューズ切れ・漏電ブレーカーの作動（すぐに復旧、人身被害・他物件損傷・供給支障なし）
- 構内の短時間停電（機器損傷なし、感電なし、電力会社側への波及なし）
- モーターの軽微なトラブル（焼損なし、火災に至らず）
- 通院のみで入院に至らなかった感電（第一号は入院・死亡に限定）。ただし労働安全衛生法に基づく**労働者死傷病報告**は別途必要になり得ます

!!! warning "迷ったら報告する"
    報告要否の判断が難しいケースは、まず**産業保安監督部に電話で確認**する。
    「報告不要だった」より「報告が必要だったのにしなかった」方が重大な問題になる。
    確認した内容と担当者名をメモしておく。

## 速報・確報の提出期限

| 報告種別 | 提出期限 | 提出先 | 提出方法 |
|---------|---------|--------|---------|
| **速報** | 事故の発生を**知った時**から**24時間以内**、可能な限り速やかに | 所轄産業保安監督部 | 電話等 |
| **確報** | 事故の発生を**知った日**から起算して**30日以内** | 所轄産業保安監督部 | 様式第13の報告書（電子申請 e-Gov または書面） |

!!! warning "起算点は「発生」ではなく「発生を知った時／知った日」"
    電気関係報告規則 第3条第2項は「事故の発生を**知つた時**から二十四時間以内可能な限り速やかに…電話等の方法により行うとともに、事故の発生を**知つた日**から起算して三十日以内に様式第十三の報告書を提出して行わなければならない」と定めています。
    「発生から」と読むと、**休日夜間に発生し翌朝に覚知したケースで期限判断を誤ります**。起算するのは覚知の時点です。
    （e-Gov 法令検索の現行条文で 2026-07-30 に逐語照合。電気関係報告規則＝昭和四十年通商産業省令第五十四号）

!!! info "確報（様式第十三の報告書）が不要になる例外がある"
    第3条第2項ただし書により、第1項の表**第八号から第十三号まで**に掲げるもののうち**当該事故の原因が自然現象であるもの**は、様式第十三の報告書の提出を要しません（ほかに第四号ハ＝小規模汽力発電設備も対象）。
    自家用電気工作物で実際に当たり得るのは**第十二号（供給支障事故）が落雷等の自然現象による場合**です。この場合も**24時間以内の速報は必要**で、免除されるのは30日以内の確報だけです。速報まで不要と読み違えないでください。
    第一号（人身）・第二号（電気火災）・第三号（他物件損傷）・第四号（主要電気工作物の破損）・第十四号（社会的影響）は、原因が自然現象であっても**確報が必要**です。

!!! warning "報告先が異なる号に二重該当したら経済産業大臣へ"
    第3条第1項後段は「二以上の号に該当する事故であつて報告先の欄に掲げる者が異なる事故は、**経済産業大臣に報告**しなければならない」と定めています。上表の各号は自家用電気工作物ではいずれも産業保安監督部長宛ですが、大規模事故で経済産業大臣宛の号（第五号・第九号・第十一号）に併せて該当した場合は提出先が変わります。

> **管轄の確認**: 所轄の産業保安監督部（事業所所在地に応じて確認）
> TEL: 事前に確認して電気主任技術者の手帳に記録しておくこと。

### 速報の内容（最低限）

速報は詳細より**速さが優先**。以下の内容を24時間以内に報告する：

```
速報記載事項:
1. 事故発生日時・場所
2. 事故の概要（何が起きたか）
3. 人身被害の有無（感電・負傷者の人数・状況）
4. 現時点の状況（継続中か、収束したか）
5. 応急措置の内容
6. 連絡先（電気主任技術者の氏名・電話番号）
```

### 確報の内容

確報は詳細な**事故調査結果**を含む報告書（電気関係報告規則 様式第13）。

```
確報記載事項:
1. 事故の概要（日時・場所・設備名称）
2. 事故の原因（根本原因を含む）
3. 事故の状況と経過
4. 人身被害の最終状況（入院期間等）
5. 設備の損傷状況
6. 応急措置・復旧措置の内容
7. 再発防止策
8. 電気主任技術者の署名・捺印
```

## 報告書の書き方

### 原因記述のポイント

**悪い例（表面的な原因止まり）**:
> 「ケーブルが絶縁劣化していたため漏電した」

**良い例（根本原因まで掘り下げ）**:
> 「経年劣化（敷設後22年）により絶縁被覆が劣化し、接続部の水分侵入で絶縁抵抗が低下した。
> 年次点検の絶縁抵抗記録を確認すると過去3年で徐々に低下しており、更新計画が立てられていなかった。
> 根本原因は設備更新基準の未整備と絶縁劣化トレンド管理の不在。」

### 再発防止策の記述ポイント

原因に対応した具体的な対策を記述する。

| 原因 | 対策の例 |
|------|---------|
| 設備の経年劣化 | 更新基準の整備（年数・絶縁値）と計画的更新 |
| 点検漏れ | 点検チェックリストの改訂・点検記録の記入フォーマット化 |
| 操作ミス | 手順書の改訂・操作ロック・表示の改善 |
| 知識不足 | 教育訓練計画の追加、OJTの実施 |

## 社内報告フローと電力会社への連絡

### 事故発生時の社内報告フロー

```
事故発生
    ↓（発見者）
【即時】現場の安全確保・人命救助最優先
    ↓
【即時】班長・直属上司に第一報（電話）
    ↓
【15分以内】電気主任技術者へ連絡
    ↓
【1時間以内】工場長・安全管理部門へ報告
    ↓（電気主任技術者）
【24時間以内】産業保安監督部へ速報
【24時間以内】電力会社の保安窓口へ連絡（設備・系統に影響する場合）
    ↓
【30日以内】確報（調査完了後）
```

### 電力会社への連絡が必要なケース

| 状況 | 連絡要否 |
|------|---------|
| 構内事故で受電設備・保護継電器が動作した | **要連絡**（保護協調の確認） |
| 事故で特別高圧ケーブルが損傷した | **要連絡**（電力会社系統に影響の可能性） |
| 構内事故で電力会社の供給に影響した | **要連絡**（即時） |
| 構内のみの低圧機器故障（系統への影響なし） | 不要（社内処理） |

## 事故調査の進め方（根本原因分析）

### 5Why（なぜなぜ分析）の適用例

**事象**: 高圧ケーブル地絡事故により工場が停電した

```
なぜ①: ケーブルが地絡した
  → 絶縁被覆が破損していたから

なぜ②: 絶縁被覆が破損したのは
  → 経年劣化（15年使用）と外傷が重なったから

なぜ③: 外傷がついたのは
  → 改造工事時に隣接ケーブルを傷つけたから

なぜ④: 工事で傷ついたのは
  → ケーブル敷設図面が最新でなく、ルートが不明だったから

なぜ⑤: 図面が最新でないのは
  → 工事後の図面更新が徹底されていなかったから

根本原因: 工事後の図面・台帳更新プロセスの不備
```

### 電気事故調査のチェックリスト

- [ ] 事故発生箇所の写真記録（損傷状況）
- [ ] 保護継電器の動作記録・ログの取得
- [ ] PIヒストリアン等のトレンドデータの保存（事故前後30分）
- [ ] 関係者へのヒアリング（発見者・作業者・オペレーター）
- [ ] 設備台帳・工事記録・点検記録の確認
- [ ] 類似設備の点検状況の確認（水平展開）

!!! tip "証拠保全を最初にやる"
    調査より先に「証拠の保全」を行う。
    PIトレンドデータは上書きされる前に保存。
    保護継電器の動作記録・ログはリセット前に取得する。
    復旧を急ぐ現場では証拠が消えやすいため、電気主任技術者が意識的に動く必要がある。

### 根拠

- 電気関係報告規則 第3条第1項（事故報告の対象。表の第一号〜第十四号と報告先。後段＝報告先の異なる号への二重該当時は経済産業大臣宛）
    - 第一号（人身。**死亡または病院・診療所に入院した場合に限る**）／第二号（電気火災。**工作物にあっては半焼以上に限る**）／第三号（他の物件の損傷・機能喪失）
    - 第四号ヌ（主要電気工作物の破損事故。**電圧1万V以上の需要設備**に限る）
    - 第十二号（**電圧3,000V以上**の自家用電気工作物の破損等により一般送配電事業者等に供給支障を発生させた事故）／第十四号（社会的に影響を及ぼした事故）
- 電気関係報告規則 第3条第2項（**事故の発生を知つた時**から24時間以内に電話等で速報、**事故の発生を知つた日**から起算して30日以内に**様式第十三**の報告書を提出）
- 電気関係報告規則 第3条第2項ただし書（第四号ハ、および第八号〜第十三号のうち**原因が自然現象であるもの**は様式第十三の報告書の提出を要しない＝確報免除。速報は免除されない）

いずれも **e-Gov 法令検索の現行条文で 2026-07-30 に逐語照合**（電気関係報告規則＝昭和四十年通商産業省令第五十四号）。

**限界の明示**:

- 上表は**自家用電気工作物の設置者**に関係する号のみを抜き出したもの。第五号〜第十一号・第十三号は電気事業者または発電所・蓄電所・変電所・送電線路を対象とする号で、一般的な高圧・特別高圧需要家の構内設備には通常適用されない。発電設備・蓄電設備を構内に持つ場合は原典の全表に当たること。
- 各号の限定条件（入院、半焼以上、1万V、3,000V）は改正で変わり得る。実際の報告判断では最新の条文と所轄の産業保安監督部への確認を優先すること。
- 「報告書の書き方」「社内報告フロー」「根本原因分析」の各節は**条文に根拠を持つ内容ではなく実務上の運用例**である。様式第十三の記載欄そのものは原典の様式を参照すること。
- 労働安全衛生法に基づく労働者死傷病報告は本規則とは別制度であり、本ページでは照合していない。
