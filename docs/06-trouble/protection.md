# 保護装置誤動作

## 30秒まとめ

保護装置のトラブルは「動くべきでない時に動いた（不要動作）」と「動くべき時に動かなかった（不動作）」の2種類。不動作は発見が難しいので定期試験が必須。

---

## 不要動作（誤トリップ）の原因一覧

保護継電器が動作すべきでない状況で動作した場合。

| 原因 | 詳細 | 確認方法 |
|------|------|---------|
| 整定値が低すぎる | 通常運転電流に対して電流整定値が小さい | タップ設定・CT 比を再確認 |
| CT 飽和 | 大電流時に CT が飽和して正確な電流を伝えられない | CT 仕様・実測電流と比較 |
| ノイズ・サージ | 開閉サージ・落雷サージが継電器入力に侵入 | サージアブソーバー・SPD の有無確認（[雷・サージ保護](../03-keiso/lightning-surge.md)） |
| 高調波電流 | インバータ負荷による高調波が継電器を誤動作 | 電流波形の高調波分析 |
| 整定値タイムオーバーラップ | 上下段の保護協調が取れていない | 保護協調図の確認 |
| 継電器の劣化 | 内部接点の劣化・感度変化 | 継電器単体での動作試験 |

!!! info "高調波が原因と疑われる場合"
    高調波電流による継電器の誤動作が疑われるときは、発生源・次数・抑制対策の全体像を[高調波対策](../01-koatsu/harmonics.md)で確認してください。ここでは継電器側の切り分けに絞ります。

!!! tip "誤トリップ直後にすること"
    1. 発生時刻・アラームの種類を記録する
    2. DCS トレンドでトリップ直前の電流・電圧を確認
    3. 原因調査前に**復電の可否を電気主任技術者と判断する**
    4. 再発防止策を決めてから復電する（「とりあえず復電」は NG）

---

## 不動作（動作すべきなのに動かない）

!!! danger "不動作は「事故が起きるまで発見できない」最悪のケース"
    保護装置が動作しないことは、通常運転では分からない。
    定期試験（トリップ確認試験）でのみ確認できる。

### 不動作の主な原因

| 原因 | 確認方法 |
|------|---------|
| 配線断線・接触不良 | CT 二次回路・継電器への配線の導通確認 |
| 整定値が高すぎる | タップ設定・時限設定の見直し |
| 継電器内部故障 | 継電器単体での動作試験 |
| バッテリー電圧低下（デジタル継電器） | バッテリー電圧確認・交換 |
| 遮断器のトリップコイル断線 | トリップコイル抵抗測定 |
| 遮断器のメカニズム固着 | 遮断器の手動操作確認 |

### 不動作リスクの高い設備

- 長期間試験を実施していない継電器
- 過去にニュートラル（整定変更なし）のまま放置している設備
- 定修でトリップ確認試験を省略した設備

## OCR 整定値の確認ポイント

OCR（過電流継電器）の整定値は適切に設定されているか定期的に確認する。

### タップ設定の確認

```
OCR 動作電流 = タップ値 × CT 変流比

例：タップ 5A × CT 比 200/5 = 200A
   → 200A 以上の電流でトリップ
```

**確認手順：**
1. 設備の定格電流と CT 比を確認
2. OCR タップ設定値を確認
3. 計算した動作電流が負荷定格電流の **1.1〜1.5 倍** 程度であることを確認
4. 時限設定（Time dial / 限時設定）が上位との保護協調を満たしているか確認

### 時限設定（保護協調）

| 保護段 | 整定の考え方 |
|--------|-----------|
| 末端 MCCB | 瞬時（限時なし） |
| フィーダー OCR | 末端より遅らせる（例：0.3 秒） |
| 変圧器一次側 OCR | フィーダーより遅らせる（例：0.6 秒） |
| 受電 OCR | 変圧器より遅らせる（例：1.0 秒） |

!!! warning "整定値変更は電気主任技術者の承認が必要"
    OCR 整定値の変更は保護協調に影響する重要な作業。
    電気主任技術者の確認・承認を必ず得ること。

## GR/DGR の誤動作

### 地絡継電器（GR/DGR）が誤動作しやすい状況

| 原因 | 説明 | 対策 |
|------|------|------|
| 対地静電容量電流 | ケーブルが長い・多い場合に対地静電容量が大きくなり零相電流が流れる | 整定値を適切に設定 |
| 高調波電流 | インバータ負荷の高調波が零相変流器（ZCT）に影響 | 高調波フィルタ・波形確認 |
| インバータ漏洩電流 | インバータからの漏洩電流が地絡と誤検知される | ZCT の位置とインバータ側の EMC 対策 |
| 一線完全地絡ではない | 間欠的な地絡・高抵抗地絡 | 絶縁測定・地絡点の探索 |

### ZCT（零相変流器）の確認

ZCT は**貫通させた導体の電流のベクトル和**を測ります。地絡がなければ和はゼロになるはずで、ゼロにならない配線をすると誤動作・不動作の原因になります。

1. **その回路の電流路をまとめて貫通させているか**（三相3線なら3本、中性線がある回路なら**中性線も含めて**）。中性線を外すと不平衡分がそのまま零相電流に見えて**誤動作**する
2. **保護接地線（PE）を一緒に貫通させていないか**。地絡電流が往復して打ち消され、**不動作**になる
3. ZCT 二次回路の配線確認（断線・接続不良）

!!! warning "旧記載からの是正"
    本ページはかつて「中性線（N線）が ZCT を貫通していないか（貫通している場合は誤動作の原因）」と、**向きを逆に**書いていました。中性線は電流路なので**貫通させるのが正**で、外すと誤動作します。貫通させてはいけないのは**接地線**側です（2026-08-05 是正）。
    なお、高圧ケーブルのシールド接地線の引き回しや、変圧器のB種接地線に ZCT を設ける方式は、**方式ごとに正解が変わります**。機器の技術資料に従ってください。

## ELCB 頻繁トリップ

### 切り分け手順

!!! warning "ELCB を繰り返しリセットしない"
    地絡が継続しているのにリセットを繰り返すと、漏電箇所が焼損し火災になることがある。

**手順：**

1. **漏電電流の測定**
   - クランプメーター（漏電電流測定対応品）で各回路の漏電電流を測定
   - 漏電電流が大きい回路を絞り込む

2. **回路の分離**
   - ELCB の二次側回路を1つずつ切り離してトリップが止まる回路を特定

3. **絶縁抵抗測定**
   - 特定した回路の絶縁抵抗をメガーで測定
   - 絶縁低下箇所（配線か機器か）をさらに切り分ける

| 漏電電流の目安 | 判断 |
|-------------|------|
| ELCB 定格（例：30mA）以上 | トリップは正常動作。漏電箇所を探す |
| ELCB 定格の 1/3 以下 | 正常範囲内だがノイズ・高調波の影響の可能性 |

## 保護継電器試験（トリップ確認試験）

!!! danger "試験前には必ず製造担当・電気主任技術者の承認を得ること"
    トリップ試験中は実際に遮断器がトリップするため、プロセスへの影響がある。
    定修期間中（設備停止中）に実施するのが原則。

### 試験の概要

| 試験項目 | 内容 |
|---------|------|
| 動作値試験 | 整定電流（電圧）で正確に動作するか |
| 時限試験 | 整定時間で動作するか |
| 通電試験 | 継電器出力から遮断器トリップコイルまでの配線を確認 |
| 特性試験 | 動作特性カーブの確認（デジタル継電器はソフトで確認） |

### 試験記録の保管

試験記録は**保安規程・社内規程で定めた期間**保管する。試験結果は「合否」だけでなく「**実測値**」を記録すること（経年変化の比較は実測値がないとできない）。

!!! warning "「法令で3〜5年」ではありません"
    本ページはかつて「高圧ガス保安法および電気事業法に基づき、試験記録は定められた期間（通常 3〜5 年）保管する」と書いていましたが、**保護継電器試験記録の保存期間を定めた条文は確認できませんでした**（2026-08-05 是正）。一般高圧ガス保安規則第83条第5項が定めるのは検査記録の**記載事項**（検査した設備・方法及び結果・検査年月日・監督者の氏名）で、**保存期間の定めはありません**。保存期間が条文にあるのは法第60条の**帳簿**（一般則で記載の日から2年間、危害の発生等に係るものは10年間）です。**自分の事業所の保安規程で確認**してください。

## プロセス停止を伴う保護動作の連絡フロー

保護装置が実際に動作してプロセスが停止した場合：

```
保護装置動作
  ↓
① 電気担当：動作表示確認・原因の初期判断
  ↓
② 製造当直への第一報（「○○の遮断器がトリップ。原因調査中」）
  ↓
③ 電気主任技術者への報告
  ↓
④ 原因特定（絶縁測定・ケーブル確認・継電器確認）
  ↓
⑤ 製造担当と協議（復電可否・プロセス対応）
  ↓
⑥ 問題解消後、電気主任技術者承認のもとで復電
  ↓
⑦ トラブルログへの記録（高圧ガス保安法の自主検査記録として）
```

!!! tip "「誤動作では？」と思っても原因確認を先に"
    「設備に問題はないから誤動作だ」と判断して復電する前に、
    必ず絶縁抵抗測定・外観確認を実施する。
    原因不明のまま復電して再度トリップした場合、状況が悪化することがある。

### 本ページが正典の範囲

**誤動作・不動作の切り分け手順**（OCR / GR・DGR / ELCB・ZCT 配線・連絡フロー）が本ページの正典範囲です。継電器の種類と整定の考え方は [保護継電器](../01-koatsu/relay.md)、時限協調と TCC は [保護協調](../01-koatsu/coordination.md)、二次電流注入試験の手順は [保護リレー試験手順](../guidelines/protective-relay-test.md)、高調波の発生源・限度値は [高調波対策](../01-koatsu/harmonics.md) が正典で、本ページは数値を再記述しません。

### 一次照合済みの条項号（e-Gov 現行条文・2026-08-05 照合）

| 条項 | 確認した内容 |
|---|---|
| 一般高圧ガス保安規則 第83条第5項 | 定期自主検査の**検査記録に記載すべき事項**（検査したガス設備／検査の方法及び結果／検査年月日／監督を行った保安係員又は取扱主任者の氏名）。**保存期間の定めはない** |
| 一般高圧ガス保安規則 第83条の2 | 検査記録の電磁的方法による保存を認める規定。**ここにも期間の定めはない** |
| 高圧ガス保安法 第60条第1項（一般則の帳簿規定） | 保存期間が条文にあるのは**帳簿**で、記載の日から**2年間**（危害の発生等に係るものは**10年間**） |

### 是正の記録（2026-08-05）

- **試験記録の保存期間の誤帰属**: 「高圧ガス保安法および電気事業法に基づき…通常 3〜5 年」と書いていましたが、**保護継電器試験記録の保存期間を定めた条文は確認できませんでした**。上表のとおり、高圧ガス側で期間が定められているのは帳簿（2年／10年）で、定期自主検査の記録は記載事項のみの規定です。**保安規程で定めた期間**に書き換えました
- **ZCT 配線の向きの反転**: 「中性線が ZCT を貫通していないか（貫通していると誤動作）」は逆でした。ZCT は貫通導体の電流のベクトル和を測るため、**中性線は電流路として貫通させるのが正**（外すと不平衡分が零相電流に見えて誤動作）。貫通させてはいけないのは**接地線**側（貫通させると地絡電流が打ち消されて不動作）です

### 原本未照合（honest-hold）

- **電気事業法・電気関係報告規則の側で、保護継電器試験記録の保存期間を定めた規定があるかは確認していません。** 「無い」と断定はせず、**未照合**として扱ってください
- **保護継電器の試験周期**（定期試験の間隔）も、本 Wiki では法令の条項を特定していません。保安規程・メーカー推奨によってください
- **JEAC 8011（高圧受電設備規程）は未入手**です。ZCT の設置位置・シールド接地線の引き回しの標準的な扱いは本ページで断定していません

### 実務慣行（規格・法令の裏付けなし）

- OCR の動作電流を**負荷定格電流の 1.1〜1.5 倍程度**とする目安（電技解釈第153条は過負荷保護装置の規定であり、この目安の条文根拠ではありません）
- 時限整定の段差（末端瞬時 → フィーダー 0.3 秒 → 変圧器一次 0.6 秒 → 受電 1.0 秒）の例示値
- 漏電電流が **ELCB 定格の 1/3 以下**なら正常範囲とみなす切り分けの目安
- 誤トリップ直後の記録・復電判断の手順、プロセス停止時の連絡フロー

### 限界の明示

- **「整定値が原因」と決める前に必ず一次側を疑ってください。** 不要動作の一覧は原因の候補であって、優先順位ではありません
- **整定値の変更は保護協調全体に影響します。** 本ページ単独で変更を決めず、[保護協調](../01-koatsu/coordination.md) と電気主任技術者の承認を経てください
- **不動作は定期試験でしか見つかりません。** 本ページの切り分けは「起きた事象」への対応で、不動作リスクそのものは試験の実施でしか下がりません
