# 力率改善ROI

## 30秒まとめ

力率は有効電力と皮相電力の比で、低いと同じ仕事に余分な無効電流が流れる。進相コンデンサの投資回収は電力会社の力率特典（85%基準）で決まるが、高調波対策の直列リアクトル費用を加算して評価する。

!!! info "経済性はこのページ、技術は力率改善ページ"
    本ページは**投資回収の判断**（力率割引制度・85%基準・回収年数の試算）を扱います。
    **技術面**（力率の定義とベクトル図・コンデンサ容量計算・直列リアクトルがなぜ必要か・APFR の動作）は [力率改善](../01-koatsu/power-factor.md) が正典です。本ページの容量計算は ROI 試算に必要な範囲の再掲です。

## 力率改善の経済効果

### なぜ力率が重要か

力率（power factor）は**有効電力と皮相電力の比**。力率が低いと、同じ有効仕事（kW）をするために電線・変圧器に余分な電流（無効電流）が流れる。

```
力率 = 有効電力（kW）÷ 皮相電力（kVA）= cos θ

有効電力: 実際に仕事をするエネルギー
無効電力: 磁束をつくるだけで仕事をしないエネルギー（モーターのコイル分）
```

電力会社の基本料金は**力率が85%を基準**に割引・割増が設定されている。

## 電力会社の力率特典・ペナルティの仕組み（85%基準）

### 力率割引・割増の仕組み（高圧契約の例）

| 力率 | 基本料金への影響 |
|------|---------------|
| 85%未満 | 1%低下するごとに基本料金が**1%割増** |
| 85% | 基準（割引も割増もなし） |
| 85%超 | 1%上昇するごとに基本料金が**1%割引** |
| 100%（上限） | 最大15%割引 |

この関係は次の1本の式にまとまる（旧一般電気事業者の伝統的メニュー）。

```text
基本料金 = 基本料金単価 × 契約電力 × (185 − 力率[%]) ÷ 100

例: 力率100% → ×0.85（15%割引）
    力率 85% → ×1.00（基準）
    力率 70% → ×1.15（15%割増）
```

### 具体的な金額感

**前提条件**: 契約電力1,000kW、基本料金単価1,600円/kW・月（単価は計算手順を示すための**仮置きの例**。実際の試算では自社の請求書・契約書の実額に置き換えること）

```
月額基本料金（85%時） = 1,000kW × 1,600円 = 1,600,000円/月

力率70%の場合（15%の割増）:
  割増額 = 1,600,000円 × 15% = +240,000円/月 → 年間+288万円

力率90%の場合（85%から5ポイント上昇 → 5%の割引）:
  割引額 = 1,600,000円 × 5% = -80,000円/月 → 年間-96万円

力率改善の経済効果（70%→90%）:
  288万円 + 96万円 = 年間384万円のコスト改善
```

!!! info "力率の算定タイミング"
    料金に使う力率は、電力量計で計った有効電力量（kWh）と無効電力量（kvarh）から**月ごとに算定**される。
    ピーク時だけ瞬間的に悪くても、月の算定値が85%以上なら割引側になる。
    算定対象を**昼間時間帯（例: 8〜22時）に限る**契約が一般的（夜間の進み力率は算定に入らない）。対象時間帯は自社の契約条件で確認のこと。

!!! warning "力率割引制度は契約先・メニューにより異なる（要確認）"
    本ページの「85%基準・1%あたり基本料金±」の仕組みは、旧一般電気事業者（大手電力）の伝統的な高圧料金メニューを前提としています。**新電力（新規参入小売事業者）や新しい料金メニューでは、力率割引・割増制度自体が無い、または基準力率・割引率が異なる場合があります。**
    投資回収（ROI）を試算する前に、必ず自社の電力需給契約書・料金メニューで「力率割引条項の有無と条件」を確認してください。制度が無い契約では、力率改善のメリットは基本料金割引ではなく、変圧器・幹線の余裕確保や電圧安定・損失低減といった構内側の効果が中心になります。

## 進相コンデンサ設置の投資回収計算

### 必要コンデンサ容量の計算

```
補正量（kvar）= P × (tan θ₁ - tan θ₂)

P   : 有効電力（kW）
θ₁ : 改善前の力率角（現在の力率からarccos）
θ₂ : 目標の力率角（目標力率からarccos）
```

**計算例**: 有効電力800kW、力率70%→90%に改善する場合

```
tan(arccos 0.70) = tan 45.6° = 1.020
tan(arccos 0.90) = tan 25.8° = 0.484

補正量 = 800 × (1.020 - 0.484) = 800 × 0.536 = 429 kvar

→ 430kvar程度の進相コンデンサが必要
```

### コンデンサ設備費の目安

| 容量 | 設備費（概算） | 備考 |
|------|-------------|------|
| 100kvar以下 | 50〜100万円 | 直列リアクトル込み |
| 100〜500kvar | 100〜300万円 | 自動力率調整盤（APFR）の場合 |
| 500kvar以上 | 300万円〜 | 大型・特注品 |

### 投資回収計算

```
年間削減額（円/年）= 基本料金単価 × 契約電力 × 力率改善率 × 割引係数 × 12

投資回収年数 = 設備費 ÷ 年間削減額
```

**計算例（前述の70%→90%改善・単価は仮置きの例）**:

```
基本料金単価: 1,600円/kW（仮置き。実額は請求書で確認）
契約電力: 1,000kW
力率割増の解消: 15% → 割増解消 = 1,600 × 1,000 × 0.15 × 12 = 2,880,000円/年
力率割引の追加: 5ポイント上昇 → 5% → 割引 = 1,600 × 1,000 × 0.05 × 12 = 960,000円/年
合計: 384万円/年

設備費200万円の場合: 単純回収年数 = 200 ÷ 384 ≈ 0.52年（約6か月）
```

!!! note "単純回収年数で評価している"
    ここでの回収年数は**設備費 ÷ 年間削減額の単純回収年数**（割引率・金利・保守費を考慮しない）。
    社内の投資基準が正味現在価値（NPV）等を要求する場合は、経理部門の基準に沿って計算し直すこと。

## 高調波対策コスト（直列リアクトル）の加算

### なぜ直列リアクトルが必要か

インバータ・整流器などの非線形負荷が多い工場では、電源に高調波が含まれる。
進相コンデンサは高調波に対してインピーダンスが低いため、**高調波電流が集中して過熱・破損**する。

直列リアクトルをコンデンサと直列に入れ、抑制したい高調波の次数に対して回路を誘導性にすることで、高調波電流の集中を防ぐ。**容量比（6%/13%）の選定と共振次数の考え方は [力率改善](../01-koatsu/power-factor.md) が正典**（本ページでは数値の根拠を再記述しない）。

### 設置の考え方

| 状況 | 対応 |
|------|------|
| インバータ・UPS・整流器が多い | **直列リアクトル必須**（容量比の選定は [力率改善](../01-koatsu/power-factor.md)） |
| 負荷が主に誘導電動機のみ | 省略可能な場合も（ただし念のため設置推奨） |
| 既設コンデンサへの増設時 | 増設分だけでなく既設も確認 |

### コスト加算率

直列リアクトル込みの設備費は、コンデンサ単体より**20〜30%増**が目安。
ROI計算時はこの分を設備費に加算する。

!!! warning "コンデンサ破損の事例"
    直列リアクトルなしでコンデンサを設置→インバータ増設後に高調波集中→コンデンサ過熱・漏液→全交換。
    後付けリアクトルの追加工事費も含めると初回の節約分が消えた事例あり。
    初期設計で含めておくことが重要。

## 力率測定と現状把握の方法

### 簡易確認（電力量計から計算）

電力会社の検針票（または電力量計のパルス）から：

```
月間の力率 ≈ kWh（有効電力量）÷ √(kWh² + kvarh²)
```

積算kWhと積算kvarhが読める電力量計（多機能型）があれば毎月確認可能。
料金算定に使われる力率の対象時間帯（昼間のみ等）は契約により異なるため、正確には検針票・請求書の力率欄で確認する。

### 現場測定（クランプメーター）

クランプ式電力計（横河のCW240等）を使えば：
- 電圧・電流・有効電力・無効電力・力率を同時測定
- 各盤ごとの力率を個別に把握できる

### 力率が悪い設備の特徴

| 設備種別 | 典型的な力率 |
|---------|------------|
| 誘導電動機（軽負荷） | 50〜70%（低負荷時は特に悪い） |
| 誘導電動機（全負荷） | 80〜90% |
| 蛍光灯（安定器式） | 70〜85% |
| インバータ駆動機器 | 95%以上（インバータ側は高力率） |
| 溶接機・電熱装置 | 設備による |

> **軽負荷モーターの力率対策**: 常時軽負荷で運転しているモーターは、コンデンサよりも**モーターを小型化**する方が根本対策として有効。

## 根拠

### 本ページが正典の範囲

力率改善の**経済性**（力率割引・割増制度、回収年数の試算）は本ページが正典です。**技術面**（力率の定義とベクトル図・コンデンサ容量計算・直列リアクトル 6%/13% の選定・APFR）は [力率改善](../01-koatsu/power-factor.md)、高調波の発生源・限度値・ガイドラインは [高調波対策](../01-koatsu/harmonics.md) が正典です。

### 一次照合済み（電力会社公式ページで照合）

- **力率割引・割増の率**: 中部電力ミライズ公式「電気料金の計算方法」（2026-08-05 参照）の記載「力率が85%を上回る場合は、上回る1%につき基本料金を1%割引します。一方、85%を下回る場合は、下回る1%につき基本料金を1%割増しします」で照合。割増側・割引側とも **1%につき1%**（対称）です
- **力率の算定方法**: 同ページで「昼間時間帯（8時〜22時）の有効電力量と無効電力量により各月ごとに決定」と照合。夜間を算定対象から外す扱いは契約により異なりうるため、本文では「一般的」の表現にとどめ、自社契約での確認を促しています
- 注意: 公式 Web ページでの照合であり、**供給約款・需給契約書の原本そのものではありません**。また旧一般電気事業者の伝統的メニューの照合であり、新電力・新メニューには本文の警告のとおり適用されない場合があります

### 一次計算で検算済み

| 項目 | 検算 |
|---|---|
| (185 − 力率)/100 の整合 | 力率100% → 0.85（15%割引）、85% → 1.00、70% → 1.15（15%割増）。表・図と一致 |
| コンデンサ補正量 | tan(arccos 0.70) = √(1−0.70²)/0.70 = 1.0202、tan(arccos 0.90) = √(1−0.90²)/0.90 = 0.4843。差 0.5359 × 800 kW = 428.7 ≈ 429 kvar |
| 金額例（70%→90%） | 割増解消 1,600,000円 × 15% = 240,000円/月 = 288万円/年。割引追加 1,600,000円 × 5% = 80,000円/月 = 96万円/年。合計 384万円/年 |
| 単純回収年数 | 200万円 ÷ 384万円/年 = 0.52年 ≈ 6.3か月 |

### 是正の記録（2026-08-05）

- **割引率の誤り**: 「85%超は1%上昇ごとに**0.5%割引**・上限100%で最大**7.5%**割引」と書いていましたが、旧一般電気事業者の伝統的メニューでは割引側も**1%につき1%**（上限100%で最大15%割引）です。表・SVG・金額例・ROI計算例をすべて是正しました（90%の割引 2.5%→5%、経済効果 336万円/年→384万円/年、回収 約7か月→約6か月）
- **図の傾きの説明**: 是正前の figcaption にあった「割増側の傾きは割引側の2倍」は上記に伴い削除しました（両側とも同じ傾きが正）
- **直列リアクトルの数値の再記述をやめた**: 6%/13% の選定根拠は正典（力率改善ページ）への参照に置き換えました
- **「力率 = kWh ÷ kVAh」の等式を近似に修正**: √(kWh²+kvarh²) は積算 kVAh と厳密には一致しないため「≈」とし、正確には検針票の力率欄で確認するよう促しました

### 実務慣行（規格・法令の裏付けなし）

- **基本料金単価 1,600円/kW・月**は計算手順を示すための仮置きの例です。実際の試算では必ず自社の請求書・契約書の実額に置き換えてください
- **コンデンサ設備費の目安表**（50〜100万円等）と**直列リアクトル込みで20〜30%増**は工事見積の経験的な目安であり、出所となる統計・規格はありません。稟議にはメーカー・工事会社の見積実額を使ってください
- 力率が悪い設備の典型力率の表（誘導電動機 50〜70% 等）も経験的な目安です

### 原本未照合（honest-hold）

- **供給約款・需給契約書の原本**は未照合です（照合したのは電力会社公式の解説ページ）。契約ごとの適用条件（対象時間帯・上限・特別高圧での扱い）は自社の契約書で確認してください
- 「負荷が主に誘導電動機のみなら直列リアクトルを省略可能な場合も」の記述は、高圧受電設備規程（JEAC 8011）等の**原本を未照合**のまま実務判断として書いています。規程上の位置づけは未確認です

### 限界の明示

- 回収年数は**単純回収年数**です（割引率・金利・保守費・コンデンサの寿命更新費を含みません）
- 力率割引制度が無い契約では、本ページの ROI 計算はそのまま使えません（本文の警告のとおり、構内側の効果が中心になります）
