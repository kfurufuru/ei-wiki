# 温度計測

## 30秒まとめ

RTD（Pt100）は精度重視・低温〜中温向け。熱電対は高温・応答速度重視向け。補償導線の誤接続・逆接は計測値を大きく狂わせる現場での代表的ミス。

---

## RTD vs 熱電対 比較表

| 項目 | RTD（Pt100） | 熱電対 K型 | 熱電対 J型 |
|------|------------|-----------|-----------|
| 測定範囲 | -200〜+600℃ | -200〜+1200℃ | -40〜+750℃ |
| 精度（標準） | ±0.3℃（Class B） | ±2.5℃ または ±0.75%（クラス2） | ±2.5℃ または ±0.75%（クラス2） |
| 高精度品 | ±0.15℃（Class A）／±0.1℃（Class AA=1/3DIN） | ±1.5℃ または ±0.4%（クラス1） | ±1.5℃ または ±0.4%（クラス1） |
| 出力 | 抵抗値（Ω） | 起電力（mV） | 起電力（mV） |
| 配線方式 | 2線/3線/4線式 | 2線式 | 2線式 |
| コスト | 中〜高 | 低〜中 | 低 |
| 応答速度 | 遅め | 速い | 速い |
| 主な用途 | 化学プロセス管理 | 高温炉・燃焼管理 | 蒸気・一般用途 |

!!! tip "化学プラントでの選び方"
    精度が要求されるプロセス温度管理（反応器・蒸留塔）→ RTD（Pt100）
    高温（600℃超）または応答速度重視 → K型熱電対

!!! note "Pt100 の許容差クラス（JIS C 1604）"
    許容差は温度に依存し、0℃での値は次のとおりです（|t| は摂氏温度の絶対値）。
    - Class B: ±(0.30 + 0.005|t|)℃ → 0℃で ±0.30℃
    - Class A: ±(0.15 + 0.002|t|)℃ → 0℃で ±0.15℃
    - Class AA（1/3 DIN 相当）: ±(0.10 + 0.0017|t|)℃ → 0℃で ±0.10℃
    「±0.1℃ 相当」は Class A ではなく Class AA（1/3 DIN）である点に注意します。

!!! note "熱電対の許容差クラス（JIS C 1602）"
    K・J とも許容差は次のとおりで、いずれも「℃ の値」と「% の値」の大きい方を適用します。
    - クラス2（標準品）: ±2.5℃（333℃未満）、333℃以上は ±0.0075・|t|（= ±0.75 %）
    - クラス1（高精度品）: ±1.5℃（375℃未満）、375℃以上は ±0.004・|t|（= ±0.4 %）
    輸入品カタログで見る「±2.2℃／±1.1℃」は ASTM E230（旧 ANSI MC96.1）系の許容差で、
    JIS C 1602 のクラス2／クラス1（±2.5℃／±1.5℃）とは**値そのものが異なります**。
    仕様書がどちらの規格系で書かれているかを必ず確認します。

## Pt100 配線方式と誤差補正

### 2線式
ケーブル抵抗が直接誤差になる。例えばケーブル抵抗が1Ωなら約2.5℃の誤差。長距離配線では絶対に使わない。

### 3線式（現場標準）

```
[Pt100]──A線──[変換器]
       ──B線──
       ──C線──（A線と同材質・同長）
```

変換器内部でA線とC線の抵抗を差し引き補正。現場では最も多く使われる。

!!! warning "3線式の前提条件"
    A線とC線は**同一ケーブル内の同材質・同長の芯線**でなければ補正が機能しない。
    異なる長さや材質の線で接続すると補正が不完全になり誤差が残る。

### 4線式（高精度用）
定電流を2線で通電し、別の2線で電圧を計測。ケーブル抵抗の影響をほぼゼロにできる。ラボ・校正用途向け。

## 補償導線の種類と選定

熱電対の起電力は**冷接点（変換器入力端子）の温度**を基準とするため、冷接点から変換器まで熱電対と同じ特性の補償導線で接続する必要がある。

| 補償導線記号 | 対応熱電対 | 現行 JIS の識別色（＋/−） | 旧 JIS（1981年版）の識別色（＋/−・表面被覆） |
|------------|----------|------------------------|------------------------------------------|
| KX | K型（延長形） | 緑/白 | 赤/白・青（旧JIS） |
| JX | J型（延長形） | 黒/白 | 赤/白・黄（旧JIS） |
| TX | T型（延長形） | 茶/白 | 赤/白・茶（旧JIS） |
| KCB | K型（補償形） | 緑/白 | 赤/白・青（旧JIS。旧記号 VX） |

!!! warning "識別色は新旧 JIS で全く違う（現場は旧色が混在）"
    現行 JIS C 1610:2012 は IEC 60584-3 整合の色別で、**＋側心線と表面被覆が種類色
    （K=緑・J=黒・T=茶）、−側は白**です。2012年より前の旧 JIS 品は**＋赤／−白**
    （型式は表面被覆色で区別: K系=青・J=黄・T=茶）で、既設配線・在庫には旧色が多く残っています。
    さらに ANSI（米国）は K 型の**赤が「−（マイナス）」**に相当し、旧 JIS の赤=＋と逆です。
    輸入機器・輸入補償導線を国内配線に接続する際は、色だけで極性を判断せず、
    端子刻印やミリボルト値で必ず確認します。

!!! note "使用温度範囲は型式でなく「使用区分（絶縁体）」で決まる"
    JIS C 1610:2012 表3 の使用区分によります。
    - 一般用 G（ビニル系）: −20〜90℃（KCA・KCB などコンペンセーション形は 0〜90℃）
    - 耐熱用 H（ガラス系）: 0〜150℃（KCB・TX には適用なし）
    - 高耐熱用 S（ふっ素樹脂系）: −25〜200℃（TX は −25〜100℃。コンペンセーション形には適用なし）

!!! danger "補償導線の禁止事項 3選"

    **1. 逆接続**
    +/-を逆に繋ぐと測定値が基準温度の2倍のズレになる。
    配線色を必ず確認する（K型: 現行JIS品は緑=＋/白=−、旧JIS品は赤=＋/白=−。
    青は旧JISのK用**表面被覆**の色であり、−極の心線色ではない）。

    **2. 延長線の代用**
    補償導線の代わりに銅線を使うと冷接点補償ができず大きな誤差が生じる。
    「なぜか温度が高い/低い」トラブルの定番原因。

    **3. 途中での材質切り替え**
    補償導線をスプライスで銅線に切り替えた接続部が新たな冷接点となり誤差源になる。
    中継盤内でも補償導線を継続するか、冷接点補償機能付き端子台を使用する。

## 保護管の材質選定

| 材質 | 最高使用温度 | 耐薬品性 | 主な用途 |
|------|-----------|---------|---------|
| SUS304 | 900℃（酸化雰囲気） | 中 | 一般用途 |
| SUS316 | 900℃ | 塩化物やや弱い | 化学プロセス標準 |
| SUS316L | 900℃ | 溶接耐食性が高い | 配管溶接部近傍 |
| ハステロイC-276 | 1100℃ | 塩酸・硫酸・HF強 | 腐食性流体 |
| セラミック（アルミナ） | 1700℃ | 酸に弱い・アルカリ強 | 高温炉内 |

!!! tip "化学プラントでの選定基準"
    - 腐食性薬液（塩酸・フッ酸系）→ ハステロイC-276
    - 蒸気・一般液体 → SUS316
    - 高温炉内（600℃超）→ セラミック ＋ K型熱電対の組み合わせ

## よくあるミスと対処

!!! failure "補償導線の誤接続"
    **症状**: 温度が実際とかけ離れた値を示す（特に外気温の季節変動で変化する）
    **確認**: 変換器端子で補償導線の+/-極性と種類記号を確認する

!!! failure "延長部での温度補償漏れ"
    **症状**: 現場盤での中継端子から先を銅線に切り替えた箇所で誤差発生
    **対処**: 中継盤内での接続は補償導線を継続するか、冷接点補償機能付き端子台を使用する

!!! failure "3線式の1芯断線"
    **症状**: 指示値が急にフルスケールまたはゼロになる
    **確認**: 変換器側で3線の抵抗バランスを確認。1本断線すると抵抗値が急変する

## 根拠と適用上の注意

- **熱電対の規準熱起電力（起電力一覧表）**: NIST ITS-90 熱電対データベース（SRD 60）の規準表と **2026-07-30 に逐語照合**（K: 100℃=4.096 mV・500℃=20.644 mV／J: 5.269・27.393／T: 4.279／E: 6.319・37.005／R: 0.647・4.471）。JIS C 1602:2015・IEC 60584-1 の規準熱起電力も同じ ITS-90 参照関数に基づくが、JIS/IEC の原本そのものとは未照合。
- **熱電対の許容差クラス**: JIS C 1602:2015 表2（クラス1: 375℃未満 ±1.5℃・375℃以上 ±0.004・|t|／クラス2: 333℃未満 ±2.5℃・333℃以上 ±0.0075・|t|、いずれも下限 −40℃）。規格全文の転載サイトで 2026-07-30 に逐語確認（JSA 発行の原本は未照合）。±2.2℃／±1.1℃ は ASTM E230 系の値であり JIS の値ではない。
- **Pt100 の許容差クラス**: JIS C 1604:2013（クラスAA/A/B の許容差式。クラスAA・A は3線式または4線式とすることも同規格の規定）。複数のメーカー技術資料の一致で確認・原本未照合。IEC 60751 整合。
- **補償導線**: JIS C 1610:2012 表3（使用区分 G/H/S の使用温度範囲）・表9（種類の色別: ＋側=種類色・−側=白）・附属書JA（旧記号・旧色別の変遷。現行 KCB は 1995年版 KCC＝1981年版 VX）。転載サイトで 2026-07-30 に逐語確認（原本は未照合）。
- **2線式の誤差の目安（1Ω ≒ 2.5℃）**: Pt100 の 0℃ 付近の感度（約 0.39 Ω/℃）からの概算であり、規格の規定値ではない。
- **限界の明示**: 保護管材質の最高使用温度・耐薬品性はメーカー目安（規格値ではない）。比較表の「測定範囲」も素線径・保護管・使用環境に依存する実用目安であり、JIS の規準関数の定義範囲そのものではない。改訂で数値・表番号が変わり得るため、調達仕様に使う際は最新版の規格本文を確認すること。
