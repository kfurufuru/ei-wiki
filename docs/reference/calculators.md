# 計算ツール集

電気計装の現場でよく使う計算式を「式 + 数値例 + 判定基準」の形式でまとめた。

---

## 1. 電圧降下（三相 3 線式）

### 計算式

```text
e = √3 × I × (R cosθ + X sinθ) × L

電圧降下率 [%] = e / V0 × 100
```

| 変数 | 単位 | 説明 |
|------|------|------|
| e | V | 線間電圧降下 |
| I | A | 負荷電流 |
| R | Ω/km | 導体抵抗（20℃） |
| X | Ω/km | リアクタンス（0.07〜0.09 が多い） |
| cosθ | — | 力率（電動機は 0.8 が目安） |
| L | km | 片道ケーブル長 |
| V0 | V | **公称線間電圧**（200V または 400V）。**受電端電圧ではない** |

### 数値例

CV 14sq（R = 1.34 Ω/km、X = 0.083 Ω/km）、I = 30A、cosθ = 0.85、L = 80m

```text
sinθ = √(1 - 0.85²) = 0.527

e = 1.732 × 30 × (1.34 × 0.85 + 0.083 × 0.527) × 0.080
  = 1.732 × 30 × 1.183 × 0.080
  = 4.92 V

電圧降下率 = 4.92 / 200 × 100 = 2.5%
```

!!! note "導体抵抗 R = 1.34 Ω/km の出所"
    多心 CV・CVT 14 sq の **JIS C 3605 の最大導体抵抗（20 ℃）**です。[電圧降下計算](../04-sekkei/voltage-drop.md) の R 表と選定ツール（`docs/javascripts/cable-calc.js`）は**同じ値に統一済み**です（2026-08-02。下記「根拠」参照）。
    単心は 1.31 Ω/km と別値です。**精算では採用するケーブルのメーカーカタログ値**を使ってください。

### 判定基準

- 幹線 2% 以内、分岐 2% 以内、合計 4% 以内（内線規程の値として広く引用されるが**原本未照合**。下記「根拠」参照）

## 2. 短絡電流（%インピーダンス法）

### 計算式

```text
Is3 = Ib × 100 / %Z合計

Ib = Pb / (√3 × Vb)  [A]  ← 基準電流

%Z合計 = %Z系統 + %Z変圧器 + %Zケーブル（各々を基準容量に換算）
```

### 数値例

変圧器 1,000kVA、%Z = 5%、系統 %Z = 0.5%（1,000kVA 基準）、Vb = 200V

```text
Ib = 1,000,000 / (1.732 × 200) = 2,887 A

%Z合計 = 5.0 + 0.5 = 5.5%

Is3 = 2,887 × 100 / 5.5 = 52,490 A ≈ 52.5 kA
```

### 判定基準

- MCCB の定格遮断電流 ≥ Is3 であること
- 変圧器直近では 50kA 超になるため高遮断容量 MCCB または限流ヒューズを選定

## 3. Cv 値（制御弁の液体流量計算）

### 計算式

```text
Kv = Q / √(ΔP / SG)

Q   : 流量 [m³/h]
ΔP  : 差圧 [bar]（弁前後の圧力差。1 kgf/cm² ≒ 0.98 bar）
SG  : 比重（水 = 1.0）

Cv（US 単位系）に直す場合: Cv ≒ 1.156 × Kv（Kv = 0.865 × Cv）
```

!!! warning "Kv と Cv は単位系が違う別の係数です"
    上式は **Q を m³/h、ΔP を bar** で扱う**メトリック系の Kv** です。**Cv は US 単位系**（流量 US gal/min、差圧 psi）で定義されるため、**同じ式に m³/h と US gal/min を併記することはできません**。
    メーカーのカタログが Cv 表記か Kv 表記かを必ず確認してください。**取り違えると約 1.16 倍のずれ**が出ます。

### 数値例

流量 10 m³/h、ΔP = 1.0 bar、SG = 1.0（水）

```text
Kv = 10 / √(1.0 / 1.0) = 10 / 1.0 = 10.0

Cv 換算 = 1.156 × 10.0 ≒ 11.6
```

制御弁の選定時は計算値の 1.3〜1.5 倍の定格を持つバルブを選ぶ（50〜80% 開度で運転するため）。**カタログの表記（Cv か Kv か）と計算値の単位系を必ず揃えてから比較**してください。

### 判定基準

- 通常運転点での弁開度：50〜80% が適切
- 最小流量時の開度が 10% 以下になる場合はサイジングを見直す

## 4. 変圧器容量

### 計算式

```text
必要変圧器容量 [kVA] = 合成最大需要電力 [kW] / 総合力率

合成最大需要電力 = 設備容量合計 × 需要率 / 不等率
```

### 数値例

動力 150kW（需要率 0.65）+ 照明 10kW（需要率 0.90）+ 計装 5kW（需要率 0.85）

```text
最大需要電力合計 = 150 × 0.65 + 10 × 0.90 + 5 × 0.85
               = 97.5 + 9.0 + 4.25 = 110.75 kW

不等率 = 1.1（工場一般目安）
合成最大需要電力 = 110.75 / 1.1 = 100.7 kW

総合力率 = 0.85 と仮定
必要容量 = 100.7 / 0.85 = 118.5 kVA

将来余裕 20% 考慮 → 118.5 × 1.20 = 142 kVA → 150kVA を選定
```

### 判定基準

- 設計負荷が変圧器定格の 70〜80% に収まるよう選定
- 将来拡張を 15〜20% 見込む

## 5. 4-20mA ループ負荷抵抗

### 計算式

```text
最大ループ抵抗 [Ω] = (電源電圧 [V] - 最低動作電圧 [V]) / 最大出力電流 [A]

最低動作電圧 : 伝送器の最低必要電圧（一般的に 10〜12V DC）
最大出力電流: 20mA（フルスケール時）
```

### 数値例

電源電圧 24V、伝送器の最低動作電圧 12V

```text
最大ループ抵抗 = (24 - 12) / 0.020 = 600 Ω

ループ内に並ぶ抵抗（受信抵抗 + 配線抵抗 + バリア抵抗）の合計が 600Ω 以下であること。

例: 受信抵抗（DCS 入力）250Ω + 配線抵抗 50Ω + 安全バリア 300Ω = 600Ω → ギリギリOK
```

### 判定基準

- 合計ループ抵抗 ≤ 最大ループ抵抗
- HART 通信を使用する場合は受信抵抗を 250Ω 以上にする（HART 最低受信抵抗）

## 6. コンデンサ容量（力率改善）

### 計算式

```text
必要コンデンサ容量 [kvar] = P × (tanθ₁ - tanθ₂)

P     : 有効電力 [kW]
tanθ₁ : 改善前の力率 cosθ₁ から求める tanθ₁ = √(1/cos²θ₁ - 1)
tanθ₂ : 改善後の目標力率 cosθ₂ から求める tanθ₂ = √(1/cos²θ₂ - 1)
```

### 数値例

有効電力 100kW、現在の力率 0.7 → 目標力率 0.95

```text
tanθ₁ = √(1/0.7² - 1) = √(1/0.49 - 1) = √(1.04) = 1.020
tanθ₂ = √(1/0.95² - 1) = √(1/0.9025 - 1) = √(0.108) = 0.329

必要コンデンサ容量 = 100 × (1.020 - 0.329) = 69.1 kvar → 70kvar を選定
```

### 判定基準

- 目標力率：0.95 以上（電力会社の力率割引を受けるため）
- 高調波が大きい場合（インバータ多用）はコンデンサへの流入を確認。リアクトル付きコンデンサを使用する

### 残る差: リアクタンス X（未確定）

**R の統一だけでは、ページの手計算と選定ツールの結果は完全には一致しません。** X の値が揃っていないためです。

| | R（20 ℃） | X |
|---|---|---|
| 本ページ・[電圧降下計算](../04-sekkei/voltage-drop.md) | 1.34 Ω/km | **0.083 Ω/km** |
| 選定ツール `cable-calc.js` | 1.34 Ω/km | **0.09 Ω/km（全サイズ固定）** |

上の数値例の条件では e = 4.92 V（手計算）に対し 4.93 V（ツール）で、**差は約 0.3 %** です。R の不一致による差（約 3.6 %）は解消しましたが、この 0.3 % は残ります。

**X はどちらも実務慣行の代表値で、規格・メーカーカタログとの照合をしていません。** R と違い一次資料で確定していないため、片方に寄せる根拠がなく、現時点では差を明示するにとどめます。実際のリアクタンスはケーブル構成・サイズ・線心配置で変わるため、精算にはカタログ値を使ってください。

### 原本未照合（honest-hold）

- **内線規程（JEAC 8001）の 2 % / 2 % / 4 %**: 有償・原本未照合です。節番号・版年は挙げません（[電圧降下計算](../04-sekkei/voltage-drop.md) の根拠節と同じ扱い）
- **Cv / Kv の定義と換算係数 0.865（Cv = 1.156 × Kv）**: 弁のサイジング規格（IEC 60534 系）は有償・原本未照合です。本ページは単位系の違いを注意喚起する範囲にとどめ、**サイジング計算そのものの規格式（配管レデューサ係数・チョーク流れの判定など）は扱いません**
- **HART の最低受信抵抗 250 Ω**: HART 仕様書は未照合です

### 実務慣行（法令・規格の裏付けなし）

- リアクタンス **X = 0.07〜0.09 Ω/km**・電動機の力率 **0.8**・伝送器の最低動作電圧 **10〜12 V DC**
- 弁の定格は計算値の **1.3〜1.5 倍**・運転開度 **50〜80 %**・最小流量時 **10 %** 以下は見直し
- 変圧器は定格の **70〜80 %** に収める・将来拡張 **15〜20 %**・不等率 **1.1**
- 目標力率 **0.95 以上**（電力会社の力率割引の一般的な水準。個別の契約条件は供給約款によります）

### 限界の明示

- 数値例は**式の使い方を示すためのもの**で、特定の設備の設計値ではありません
- 電圧降下の式は送り端・受電端の**位相差を無視した簡略式**です
- 短絡電流の例は %Z を合計するだけの単純化で、電動機拠出・非対称分は含みません
