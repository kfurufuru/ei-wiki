# 受変電設備概論

## 30秒まとめ

化学プラントの受変電設備は「特高受電→6.6kV母線→各変圧器（6.6kV/440V）→負荷」が典型構成。主任技術者の選任・保安規程の届出・技術基準適合維持の義務を負うのは**設置者（事業者）**であり、選任された電気主任技術者は保安の**監督**を行う（電気事業法第43条）。単線結線図を読めることが電気管理業務の基本スキル。

---

## 化学プラントの典型的な受変電構成

```mermaid
flowchart TD
    A[電力会社 66kV/77kV 特高系統] --> B[屋外特高変電所\n66kV または 77kV 受電]
    B --> C[特高変圧器\n66kV→6.6kV]
    C --> D[6.6kV メイン母線\n二重母線または単母線]
    D --> E[6.6kV フィーダー盤群]
    E --> F1[変圧器 Tr-1\n6.6kV/440V]
    E --> F2[変圧器 Tr-2\n6.6kV/440V]
    E --> F3[高圧モーター\n6.6kV直接]
    F1 --> G1[低圧 MCC\n440V 動力盤]
    F2 --> G2[低圧 MCC\n440V 動力盤]
```

## 単線結線図の主要記号

| 記号 | 機器名 | 説明 |
|------|--------|------|
| VCB（○に V） | 真空遮断器 | 高圧回路の開閉・保護 |
| DS（─┤├─） | 断路器 | 停電確認後の電路開放（電流遮断不可） |
| CT（電路を貫く○） | 変流器 | 大電流を 5A 等に変換して計測・保護に使用 |
| PT（○を2つ重ねた変圧器記号） | 計器用変圧器（VT） | 高電圧を 110V 等に変換して計測・保護に使用 |
| ZCT（○に Z） | 零相変流器 | 地絡電流（零相電流）を検出 |
| LA（→） | 避雷器 | 雷サージ・開閉サージを吸収 |
| TR（○に波線） | 変圧器 | 電圧変換 |
| SC（□） | 進相コンデンサ | 力率改善 |

## 責任分界点

電力会社の設備と自家設備の境界。高圧受電では**構内第1柱の区分開閉器（PAS・UGS 等）の電源側接続点**とすることが多いが、実際の位置は電力会社との契約（供給約款・協議）で個別に定まるため、自社の受電契約書・単線結線図で確認する。

| 分界点より電源側 | 分界点より負荷側 |
|--------------|--------------|
| 電力会社の責任 | 自家設備の責任（電気主任技術者の管轄） |
| 電力会社が保守 | 自社が保守 |

## 電気事業法上の義務の帰属（設置者と主任技術者）

義務の多くは**設置者（事業者）**に課されており、電気主任技術者に課されるのは保安の**監督**の職務である。この帰属の区別は実務でも試験でも混同しやすい。

| 義務・職務 | 誰の義務か | 内容 |
|-----------|----------|------|
| 主任技術者の選任 | **設置者** | 事業用電気工作物を設置する者は、保安の監督をさせるため主任技術者免状の交付を受けている者のうちから主任技術者を選任しなければならない（第43条第1項）。選任・解任は遅滞なく届出（同条第3項）。高圧受電の自家用電気工作物は規模によらず選任が必要（500kW・2000kWは許可主任技術者や保安管理業務の外部委託といった別制度の区分であり、選任義務の有無を分ける閾値ではない） |
| 保安規程の制定・届出 | **設置者** | 工事・維持・運用に関する保安を確保するため保安規程を定め、使用開始前に主務大臣へ届出（第42条第1項）。変更時も遅滞なく届出（同条第2項）。設置者と従業者には遵守義務（同条第4項） |
| 技術基準適合維持 | **設置者** | 事業用電気工作物を主務省令で定める技術基準（電技）に適合するように維持する義務（第39条第1項） |
| 保安の監督 | **主任技術者** | 工事・維持・運用に関する保安の監督の職務を誠実に行う（第43条第4項）。工事・維持・運用に従事する者は、主任技術者の保安のための指示に従う義務（同条第5項） |
| 事故報告 | **設置者** | 感電等による死傷（死亡または入院）・電気火災・供給支障等の事故は、原則として電気工作物の設置の場所を管轄する**産業保安監督部長**へ報告（電気関係報告規則第3条）。対象事故の区分・速報と報告書の期限は [電気事故対応と報告](../09-hoantokei/jiko-taiou.md) が正典 |

## 需要率・不等率・負荷率

変圧器容量を選定・評価するときに使う指標。

| 指標 | 定義 | 用途 |
|------|------|------|
| 需要率 | 最大需要電力 / 設備容量の合計 | 設備合計から実際の最大需要を推定 |
| 不等率 | 各負荷の最大需要の合計 / 合計の最大需要 | 個別ピークが同時に来ないことを考慮（≥1.0） |
| 負荷率 | 平均需要電力 / 最大需要電力 | 設備の利用効率を示す |

### 計算例

設備容量合計：1000 kW、需要率：0.7、不等率：1.2 の場合

```
最大需要電力 = 1000 × 0.7 / 1.2 = 583 kW
```

変圧器容量はこの最大需要電力に将来余裕（20〜30%）を加算して選定する。

## 根拠

### 本ページが正典の範囲

- 化学プラント受変電の典型構成・単線結線図の読み方・需要率／不等率／負荷率の定義と使い方（概論としての導入）。

### 一次照合済みの条項号（e-Gov 法令 API・2026-08-06 照合)

- **電気事業法第43条**（主任技術者）: 第1項＝設置者の選任義務、第2項＝免状非保有者の許可選任、第3項＝選任・解任の届出、第4項＝主任技術者の保安監督の誠実義務、第5項＝従事者の指示遵守義務。
- **電気事業法第42条**（保安規程）: 第1項＝設置者が定め使用開始前に主務大臣へ届出、第2項＝変更の届出、第4項＝設置者・従業者の遵守義務。
- **電気事業法第39条**（維持）: 第1項＝設置者の技術基準適合維持義務。
- **電気関係報告規則第3条**（事故報告）: 自家用電気工作物の設置者の報告先は原則「電気工作物の設置の場所を管轄する産業保安監督部長」。感電等による死傷は「死亡又は病院若しくは診療所に入院した場合に限る」。
- いずれも e-Gov 法令 API（電気事業法＝昭和39年法律第170号／電気関係報告規則＝昭和40年通商産業省令第54号）の現行条文 XML から該当条を抽出し逐語確認した。

### 一次計算で検算済み

- 計算例: 最大需要電力 = 設備容量合計 1000 kW × 需要率 0.7 ÷ 不等率 1.2 = 583.3 → 583 kW（2026-08-06 再計算一致）。不等率 ≥ 1.0 の向き（個別最大の合計 ≥ 合成最大）も定義と整合。

### 是正の記録（2026-08-06）

- 30秒まとめの「電気主任技術者は電気事業法上の義務者」という**帰属の取り違え**を是正。選任・保安規程・維持・事故報告の義務者は設置者であり、主任技術者の職務は保安の監督（第43条第4項）。
- 「電気主任技術者の法的義務」と題した表が設置者の義務（選任・保安規程・維持・事故報告）と主任技術者の職務（保安の監督）を混在させていたため、「誰の義務か」列を設けて帰属を分離。
- 事故報告の報告先「経済産業省へ報告」を「管轄産業保安監督部長へ報告（電気関係報告規則第3条）」に是正（同条は報告先が大臣になる場合を別に定めるが、自家用の感電死傷・電気火災等の原則は監督部長）。
- 責任分界点の「キュービクル受電点のメーターボックスが分界点」という断定を撤回し、「区分開閉器の電源側接続点とすることが多いが契約で個別に定まる」に是正（分界点の位置は法令の一律の定めではなく需給契約事項）。
- CT と PT の図記号説明が同一（「○に矢印」）になっていた内部矛盾を修正。
- 構成図・単線結線図記号のその他の行・需要率／不等率／負荷率の定義は照合したがずれ無し。

### 原本未照合（honest-hold）

- 「500kW＝許可主任技術者、2000kW＝外部委託承認の区分」という運用値は電気事業法本文ではなく施行規則・告示・内規レベルの定めであり、本ページでは原本未照合。閾値の数値を根拠に使う場合は施行規則第52条・第53条等の現行条文を一次照合すること（本文では「選任義務の閾値ではない」という否定の限度でのみ使用しており、これは第43条第1項の逐語照合で裏づく）。

### 実務慣行（規格・法令の裏付けなし)

- 「特高受電→6.6kV→440V」の典型構成、変圧器容量の将来余裕 20〜30% は化学プラントの実務慣行であり、法令・規格の定めではない。
