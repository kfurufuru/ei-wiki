# 低圧配電

## 30秒まとめ

低圧配電設計の要点は「保護協調・電圧降下・回路分離」の3点。MCCBは遮断容量が系統短絡電流を上回ること、ELCBは保護目的で感度を使い分けること、幹線は需要率と電圧降下の両面で確認する。

---

## 分電盤の構成

```
受電点（高圧）
    │
  主幹 MCCB（または NFB）
    │
  ┌─┬─┬─┐
  │  │  │  │
分岐 MCCB × n
  │  │  │  │
電灯 動力 計装 ELCB保護回路
```

| 機器 | 役割 | 設置箇所 |
|------|------|---------|
| 主幹 MCCB | 全体の過電流・短絡保護、電源切離し | 盤受電口 |
| 分岐 MCCB | 回路ごとの保護と開閉 | 各回路 |
| ELCB（漏電遮断器） | 地絡電流検出 → 遮断 | 人体保護・火災保護回路 |
| サージ保護デバイス（SPD） | 雷サージからの保護 | 主幹一次側 |

## MCCB 選定

### 選定手順

1. **定格電流**：回路の最大電流以上かつ幹線との保護協調を確認
2. **遮断容量**：設置点の予想短絡電流（kA）を下回らないこと
3. **極数**：単相2線＝2P、単相3線＝3P、三相3線＝3P、三相4線＝4P
4. **フレームサイズ（AF）**：定格電流に対し過不足なく選定（将来増設代は次フレームサイズで検討）

### AF と AT（フレームサイズと定格電流）

MCCB の銘板・型式に出てくる「AF」「AT」は選定・更新の基本用語です。

| 用語 | 読み | 意味 |
|------|------|------|
| AT（アンペアトリップ） | Ampere Trip | **定格電流**。この値を超える電流が流れ続けると引き外し（トリップ）動作する |
| AF（アンペアフレーム） | Ampere Frame | **フレーム（外箱）の大きさの呼び**。そのフレームに搭載できる引き外し装置の最大定格電流 |

- 表記例：「100AF / 75AT」＝ 100A フレームに定格電流 75A の引き外し装置を搭載
- 関係は常に **AF ≥ AT**。同じ 100AF でも 50AT・75AT・100AT などの製品がある
- メーカー型式の数字はフレームを表すことが多い（例：三菱 NF125-SV は 125AF）

!!! tip "同じ AF なら外形が同じ＝盤改造なしで AT を変更できる"
    同一シリーズの MCCB は AF が同じなら外形・取付寸法が共通のため、負荷増設で定格電流を上げたいとき
    **ブレーカ交換だけで対応でき、盤の改造が不要**です。将来の増設が見込まれる回路は、
    AT に対して一回り大きい AF を選んでおくと更新が容易になります。
    ただし AF が大きいほど外形は大きく高価になるため、盤スペース・予算との兼ね合いで決めます。

!!! warning "AT は「電線の許容電流以下」が大原則"
    AT（定格電流）は **負荷電流以上、かつ電線の許容電流以下** で選定します。
    電線の許容電流より大きい AT を選ぶと、過負荷時に MCCB が動作する前に電線が過熱し、
    電線保護になりません（電動機回路は始動電流を考慮した特例があります）。
    「負荷が増えたから AT を上げる」ときは、必ず幹線・分岐電線のサイズも合わせて確認します。

!!! info "電験学習者向け"
    電験三種の法規では AF/AT という用語ではなく「**過電流遮断器の定格電流と電線の許容電流の関係**」
    （電技解釈 第148条・第149条）として出題されます。実務の AT 選定はこの規定の運用そのものです。

### 遮断容量早見表

| 系統電圧 | 設置箇所 | 最小遮断容量 |
|---------|---------|------------|
| 100/200V | トランス二次側直近 | 系統短絡電流以上（計算値による） |
| 200V | トランスから50m以内 | 25kA が目安（要計算確認） |
| 200V | 分岐端末 | 5〜10kA で足りる場合が多い |

!!! warning "遮断容量の確認は必須"
    変圧器容量増設後・系統変更後は既設 MCCB の遮断容量を再確認する。容量不足の場合、短絡事故で MCCB が吹き飛ぶリスクがある。

## ELCB の感度電流選定

| 感度電流 | 用途 | 位置づけ |
|---------|------|------|
| 15mA（高感度） | コンセント回路・携帯工具回路 | 人体保護。水気のある場所以外では「定格感度電流 15 mA 以下・動作時間 0.1 秒以下」の漏電遮断器の施設が接地工事省略の条件になる（電技解釈第29条第2項第五号） |
| 30mA（高感度） | 一般低圧回路の人体保護 | 実務標準（感度の数値を定める法令はない。下記 warning 参照） |
| 100mA | 機器保護（人体保護兼用） | 設備単体保護 |
| 200mA（中感度） | 幹線の火災保護 | 漏電火災防止（配線保護） |
| 500mA〜1A | 特殊幹線の火災保護 | 主幹・大容量回路 |

!!! warning "感度電流の数値を定める法令は無い"
    電技解釈第36条が定めるのは「金属製外箱を有する使用電圧 60 V 超の低圧の機械器具に接続する電路には地絡遮断装置を施設する」という義務（と適用除外）であり、**感度電流の数値は規定していません**。高感度形（30 mA 以下）・中感度形といった区分は漏電遮断器の製品規格（JIS C 8201-2-2 とされる）・内線規程によりますが、いずれも**原本未照合**です。感度・動作時間は人体保護（高感度・高速形）か火災保護（中感度）かの目的から選定します。

!!! tip "化学プラント留意点"
    腐食雰囲気や湿潤環境では絶縁劣化が早い。感度30mA の ELCB を標準とし、精密計装回路は漏電が誤動作につながる場合があるため専用トランス（絶縁トランス）を検討する。

## 幹線サイズ計算

### 手順

```
Step1: 需要電流 = 設備容量合計 × 需要率 ÷ (√3 × 電圧 × 力率)
Step2: 許容電流確認（電線の許容電流 ≥ 需要電流）
Step3: 電圧降下確認（幹線部分で 2%以内が目安）
Step4: 短絡電流確認（MCCBの遮断容量が短絡電流を上回ること）
```

### 需要率の目安

| 負荷種別 | 需要率の目安 |
|---------|------------|
| 工場動力（電動機群） | 0.6〜0.75 |
| 照明 | 0.85〜1.0 |
| 計装電源 | 0.8〜0.9 |
| 空調 | 0.7〜0.85 |

### 電圧降下計算（三相）

```
e = √3 × I × (R cosθ + X sinθ) × L

e   : 電圧降下 [V]
I   : 電流 [A]
R   : 導体抵抗 [Ω/km]
X   : リアクタンス [Ω/km]
cosθ: 力率
L   : 片道距離 [km]
```

許容値：幹線 2%以内、分岐 2%以内（合計 4%以内）。内線規程由来とされる実務値で、定義・計算式の正典は [電圧降下計算](../04-sekkei/voltage-drop.md)。

## 電灯・動力・計装回路の分離原則

| 原則 | 理由 |
|------|------|
| 動力回路と計装回路を別 MCCB・別トランスで分離 | モーター始動時の電圧変動が計装機器に影響しないため |
| 照明と動力コンセントを分離 | 動力のトリップが照明消灯につながらないため |
| UPS 給電回路は専用 MCCB | 瞬停時の自動切替を確実にするため |
| 非常用回路は専用系統 | 通常系統の事故が非常回路に波及しないため |

!!! info "計装回路の電源品質"
    DCS・PLC・伝送器の電源は電圧変動 ±10%以内、瞬停 20ms 以内が要求仕様となることが多い。ノイズフィルタまたは絶縁トランスの追加を標準化する。

## 根拠と適用上の注意

- **地絡遮断装置（ELCB）の施設義務**: 電気設備の技術基準の解釈（令和7年11月版）**第36条第1項**「金属製外箱を有する使用電圧が60Vを超える低圧の機械器具に接続する電路には、電路に地絡を生じたときに自動的に電路を遮断する装置を施設すること」。適用除外（簡易接触防護措置、乾燥した場所、対地電圧 150 V 以下で水気のある場所以外、二重絶縁構造、C 種・D 種接地の接地抵抗値 3Ω 以下 など）は同項第一号〜第八号。上位規定は電技省令**第15条**（地絡に対する保護対策）。**2026-08-01 に原典 PDF・e-Gov 法令 API で逐語照合**。
- **ELCB の感度電流（15/30/100 mA 等）**: 法令に数値規定はありません（本文 warning のとおり）。解釈の条文に登場する数値は**第29条第2項第五号**の「定格感度電流が15mA以下、動作時間が0.1秒以下」（水気のある場所以外での接地工事省略の条件）のみで、これは ELCB の選定基準ではなく接地省略の条件です。2026-08-01 に逐語照合。かつて本ページは 30 mA の根拠を「電技解釈・内線規程」としていましたが、電技解釈に 30 mA の規定はないため是正しました。高感度・中感度の区分は JIS C 8201-2-2 系の製品規格・内線規程によるとされますが**原本未照合**です。
- **AT ≤ 電線許容電流の原則・電動機回路の特例**: 電技解釈**第148条**（低圧幹線の施設）・**第149条**（低圧分岐回路等の施設）。定量計算は正典 [幹線サイズと過電流遮断器](../04-sekkei/feeder-breaker-sizing.md)・[分岐回路の施設](../04-sekkei/branch-circuit-sizing.md) を参照（両ページで原典逐語照合済み）。
- **電圧降下の許容値（幹線 2%・分岐 2%）**: 内線規程（JEAC 8001）由来とされる実務値で、**内線規程の原本は未照合**。正典は [電圧降下計算](../04-sekkei/voltage-drop.md)。
- **遮断容量の目安（25 kA・5〜10 kA）・需要率の目安・計装電源品質（±10%・瞬停 20 ms）**: いずれも実務目安で、**一次資料の裏付けはありません**。遮断容量は必ず設置点の短絡電流計算（[短絡電流計算](../04-sekkei/fault-current.md)）で確認してください。
