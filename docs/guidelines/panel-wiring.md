# 盤内配線作業要領

## 30秒まとめ

盤内配線は着手前の停電・検電・LOTO が最優先で、配線そのものより安全確認に手間をかける。配線後は結線図との照合・端子締付・絶縁抵抗の3点を確認してから通電する。

---

制御盤・分電盤・計装盤の内部配線作業（新設・増設・改造）の作業要領です。  
安全な配線施工と品質確保のための標準手順を定めます。

---

## 事前確認

!!! warning "作業開始前に必ず確認"
    - [ ] PTW（作業許可証）取得済み
    - [ ] 盤の電源が完全にOFFであることを確認（検電器使用）
    - [ ] 回路図・端子配列図・ケーブルリスト入手済み
    - [ ] 使用するケーブル・端子の仕様確認（耐圧・耐熱・難燃性）
    - [ ] 工具の絶縁被覆確認

### 必要な資格
- 低圧電気取扱特別教育修了（必須）
- 電気工事士（電源工事が含まれる場合。ただし**電気工事士法の適用有無・資格区分は電気工作物の区分で異なり**、大規模な自家用電気工作物の需要設備は同法の資格規制の対象外＝保安規程側で施工体制を定める。区分と規模の境界値の正典は [制御盤撤去ガイドライン 2-4節](seigyoban-tekkyo-guideline.md)）

### 必要な工具

| 工具 | 用途 |
|------|------|
| ワイヤストリッパ | 被覆剥き |
| 圧着ペンチ（適合サイズ） | 圧着端子取付 |
| ドライバ（絶縁柄付き） | 端子ネジ締め |
| トルクドライバ（推奨） | 規定トルク管理 |
| デジタルマルチメータ | 導通・絶縁確認 |
| 検電器 | 活電確認 |
| 電線チューブ・ワイヤマーカ | 配線識別 |

## 作業前の安全確認

### 検電手順

1. 検電器の動作確認（電源ON、既知の活電部で動作テスト）
2. 盤の主幹ブレーカを確認し、OFFであることを確認
3. 検電器で**主幹ブレーカ二次側（盤内全端子台）**を確認
4. 「停電中・作業中」の警告タグを盤扉・ブレーカに取り付ける

!!! danger "絶対に守ること"
    - 検電確認なしの盤内作業は禁止
    - 他の電源から盤内に電気が供給されている可能性を常に考慮すること
    - UPS・蓄電池回路は主幹OFFでも電圧が残る場合がある

---

## 配線作業手順

### STEP 1：ケーブル引き込み

1. ケーブルグランド（またはブッシング）のサイズを確認し取り付ける
    - 外径に合ったグランドを選定（防水・難燃性の確認）
    - 締め付けは規定トルクで実施（ケーブルへのダメージ防止）
2. ケーブルを引き込み、余長を適切に確保する
    - 端子台への接続分＋将来の接続変更分として100〜150mm余長を確保
3. ケーブルクランプでケーブルを固定する（引っ張りに対する機械的保護）

### STEP 2：電線端末処理

1. ケーブルシース（外装被覆）を剥く
    - 剥き長：端子台高さ＋余長で50〜80mm程度
    - シース剥きでコア絶縁を傷つけないこと
2. シールド付きケーブルの場合、シールド処理を行う
    - シールドをよじってドレン線（アース線）として整形する
    - 接地方法（片端/両端）をループ図・仕様書で確認
3. 芯線の被覆を剥く
    - 剥き長：端子台仕様に合わせる（棒端子使用時は棒端子長さに合わせる）
    - **剥き過ぎ禁止**（露出過大で短絡リスク）

### STEP 3：端子処理

#### 棒端子（フェルール端子）使用の場合（推奨）

1. 剥き長に合った棒端子を選定する（芯線太さ × 剥き長でサイズ確認）
2. 芯線を棒端子に挿入し、専用圧着ペンチで圧着する
3. 圧着後、軽く引っ張って抜けないことを確認する

#### 裸圧着端子使用の場合

1. 電線サイズに合ったYまたはO端子を選定する
2. 被覆ストリップ後、端子に挿入して圧着する
3. 圧着マーク（刻印）が均等に入っていることを確認

!!! warning "電線サイズと端子の適合"
    電線サイズに合わない端子の使用は接触不良・発熱の原因になる。  
    圧着ペンチのダイス選定も電線サイズに合わせること。

### STEP 4：電線識別（マーキング）

1. ワイヤマーカ（電線番号チューブ）を取り付ける
    - 端子台接続前に通しておく
    - 番号は回路図・ケーブルリストの番号と一致させる
2. マーカが読めるように向きを統一する（端子側から番号が読める方向）
3. 同一ループの電線は色分けに従う

| 回路 | 一般的な色分け |
|------|-------------|
| 4-20mA信号（＋） | 赤 |
| 4-20mA信号（−） | 黒 |
| DC24V電源（＋） | 赤 |
| DC24V電源（−/0V） | 青 |
| アース（接地） | 緑/黄緑 |
| AC制御電源 | 赤（L）/ 白（N） |

!!! note "色分けは実務慣行（法定ではない）"
    上表の色分けは業界・社内の実務慣行で、**電技解釈に電線の色を定める規定は無い**（[接地（低圧）](../02-teiatsu/grounding-lv.md) の根拠節で 2026-08-01 確認済み）。既設盤の色使いが異なる場合もあるため、必ず回路図・現物照合を優先する。緑系の電線を接地以外に使わないことは慣行として厳守する。

### STEP 5：端子台への接続

1. 端子台番号が回路図と一致していることを確認する
2. 端子ネジを緩め、棒端子（または裸端子）を挿入する
3. **規定トルクで締め付ける**（端子台メーカーの指定トルクが最優先。下記は指定が入手できない場合の一般目安）
    - M3端子：0.5〜0.8 N·m
    - M4端子：0.8〜1.2 N·m
    - M5端子：1.5〜2.0 N·m
    - 推奨：トルクドライバ使用
4. 接続後、電線を軽く引っ張って抜けないことを確認する

!!! warning "過大トルク禁止"
    締めすぎは端子台の割れ・ネジ頭舐めの原因になる。  
    特にフェニックスコンタクト等の細ピッチ端子は締めすぎ注意。

### STEP 6：配線の整形・固定

1. 配線束をケーブルタイ（インシュロック）で適切な間隔でまとめる
    - 間隔：150〜200mm程度
    - 締め付け強さ：電線が変形しない程度
2. 電線を盤内配線ダクトに収める
    - ダクト充填率：80%以下（施工上限の実務値。設計段階の目標 40% と分ける——正典は [盤設計](../04-sekkei/panel-design.md)）
    - 動力線と信号線は**別ダクトに収める**（ノイズ分離）
3. 余長は無理なく曲げてまとめる（曲げ半径：電線外径の5倍以上）

---

## 配線完了後の確認

### 導通確認

1. マルチメータをΩモードに設定
2. 回路図に従い、端子台の同一回路端子間の**導通（低抵抗）**を確認
3. 異なる回路間に**導通がないこと**（短絡なし）を確認

### 絶縁確認

1. 電源を入れる前に、DC500Vメガーで絶縁抵抗を測定する
2. 確認対象：各回路〜アース間
3. **基準値：10MΩ以上**（施工完了直後の実務受入基準。低い場合は配線を見直す）

!!! danger "電子機器を接続したまま 500V を印加しない"
    PLC・DCS・伝送器・電子式リレー・SPD などが接続された回路に 500V メガーをかけると**機器を破壊する**。測定前に電子機器側の端子を外すか、切り離せない回路は製造者指定の試験電圧・方法に従う（弱電機器は 250V メガー等。メガー電圧の使い分けの正典は [絶縁管理](../05-hozen/insulation-management.md)・[絶縁抵抗測定](../01-koatsu/insulation-test.md)）。

!!! note "10MΩ は法定値ではない"
    法定最低値は電技省令第58条の 0.1／0.2／0.4 MΩ（電圧区分別）で、10MΩ はそれに大きな余裕を持たせた**新設・改造直後の実務受入値**。使用中設備の実務管理値（設備種別で境界が異なる）と法定値の正典は [絶縁管理](../05-hozen/insulation-management.md)。

## チェックリスト（作業完了時）

- [ ] 全端子の接続完了・トルク確認
- [ ] 電線マーカの取り付け・番号一致確認
- [ ] シールド線の接地処理確認
- [ ] 導通確認完了（全回路）
- [ ] 絶縁抵抗確認完了（10MΩ以上）
- [ ] 警告タグの取り外し
- [ ] 盤扉・カバーの復旧
- [ ] 不要な端子カバーの取り付け
- [ ] 作業記録（配線変更図への反映）

## よくある不具合と対処

| 不具合 | 原因 | 対処 |
|--------|------|------|
| 接触不良・断線 | 端子締め付け不足・芯線折れ | 増し締め・端子交換 |
| 短絡 | 被覆剥き過ぎ・端子間隔不足 | 絶縁チューブ追加・再配線 |
| ノイズ混入 | 信号線と動力線の混在 | 配線ダクト分離 |
| 番号違い | 配線時の取り違え | 回路図との照合・是正 |

## 根拠

### 本ページが正典の範囲

盤内配線の**施工手順（端末処理・端子処理・整形固定）と盤内配線ダクトの施工上限 80%** は本ページが正典（[盤設計](../04-sekkei/panel-design.md) が設計目標 40% を持ち、施工上限は本ページに整合させている）。

### 是正の記録（2026-08-06）

- **電気工事士資格の一律要求を是正しました。** かつて「第2種電気工事士以上（電源工事が含まれる場合）」と一律に書いていましたが、電気工事士法の資格規制は電気工作物の区分で適用有無・資格種別が異なります。第2種は一般用電気工作物の区分であり、自家用の需要設備には別の区分（第一種等）が対応し、規模の大きい自家用の需要設備は同法の資格規制の対象外です。区分と規模の境界値は本ページには書かず、[制御盤撤去ガイドライン 2-4節](seigyoban-tekkyo-guideline.md)（電気工事士法第2条・第3条を 2026-08-01 に e-Gov 逐語照合済み）を正典とします。
- **500V メガー印加に対する電子機器保護の警告を追加しました。** 本ページは計装盤（PLC・伝送器を含む）を対象範囲に含むのに、電子機器を切り離さず 500V を印加する危険側の手順になっていたため、[絶縁管理](../05-hozen/insulation-management.md)（正典）の警告に合わせて是正しました。
- **絶縁抵抗 10MΩ の位置づけを明示しました。** 法定値と誤読される余地があったため、「施工完了直後の実務受入基準」であり法定最低値（電技省令第58条の 0.1／0.2／0.4 MΩ）とは別物であることを明記しました。使用中設備の判定境界は本ページに書かず正典参照とします（撤去済みの出所不明の独自判定表を再導入しません）。
- **電線色分けの出所を明示しました。** 色分け表は実務慣行であり、電技解釈に電線の色を定める規定は無いことを注記しました（[接地（低圧）](../02-teiatsu/grounding-lv.md) の根拠節で確認済み）。

### 実務慣行（規格・法令の裏付けなし）

- 端子締付トルクの目安（M3: 0.5〜0.8／M4: 0.8〜1.2／M5: 1.5〜2.0 N·m）——端子台メーカーの指定トルクが常に優先
- 余長 100〜150mm、シース剥き長 50〜80mm、ケーブルタイ間隔 150〜200mm、曲げ半径「電線外径の5倍以上」、ダクト充填率 80% 以下（施工上限）・40% 以下（設計目標）
- 電線色分け（4-20mA 赤/黒・DC24V 赤/青・接地 緑/黄緑 等）と、施工後の絶縁抵抗の受入基準 10MΩ 以上

### 原本未照合（honest-hold）

- 圧着端子・棒端子（フェルール）の圧着要領に関する JIS（JIS C 2805 等とされる）は原本未照合のため、本ページでは規格番号・条項を引用しません。圧着工具・端子はメーカーの適合表に従ってください
- 低圧電気取扱特別教育の根拠条文（安衛則第36条第四号）の照合は [特別教育・資格一覧](../10-safety/special-education.md) が正典で、本ページでは再照合していません
