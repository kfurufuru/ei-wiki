# ケーブルトレイ施工要領

## 30秒まとめ

ケーブルトレイ施工は「先に充填率とルートを確定し、後から曲げ半径で困らない」ことが要点。充填率はトレイ断面の目安内に収め、延線後は支持間隔・曲げ半径・接地の連続性を必ず確認する。

---

ケーブルトレイ（ラックトレイ・メッシュトレイ）の設置・ケーブル延線の施工要領です。  
新設工事・増設工事時の標準手順を定めます。

---

    - [ ] 工場所轄部門との工事調整完了

- 高所作業（2m以上）：特別教育修了
- 玉掛け・移動式クレーン（重量物搬入時）：各資格

## ケーブルトレイの種類と選定

| 種類 | 特徴 | 適用場所 |
|------|------|---------|
| ラダートレイ | 強度が高い・大径ケーブル向き | 動力ケーブルメインルート |
| メッシュトレイ | 軽量・通風性・信号線向き | 計装ケーブル・制御ケーブル |
| ソリッドボトムトレイ | 防塵・油散布環境向き | プロセス設備周辺 |
| コンジット（配管） | 単独ルート・防爆エリア | 防爆区域・露出部分 |

!!! info "動力線と信号線の分離"
    動力ケーブルと計装・制御信号線は**別のトレイに分離**して布設する。  
    同一トレイに収める場合は金属セパレータで仕切る。仕切りあり 150mm 以上などの離隔距離は**実務目安**（法令・規格が定めた値ではない）で、値の正典は [計装配線](../03-keiso/wiring.md) の離隔基準表。

## 施工手順

### STEP 1：ルート確認・位置出し

1. 施工図（ケーブルルート図）と現場を照合し、以下を確認する
    - 既設配管・ダクト・構造物との干渉
    - 他工事との取り合い（電気・計装・配管・空調）
    - 保守点検の通路確保（通路幅600mm以上を確保）
2. チョークラインで壁・天井に支持点の位置を墨出しする
    - 支持間隔：**1.5m以下**（安全側の実務値・社内標準）、重量物の場合は1.0m以下
3. 水準器で水平・垂直を確認しながら位置出し

### STEP 2：支持物（ブラケット・ハンガー）の取り付け

1. 取付位置にアンカー穴を開ける
    - コンクリート：振動ドリル使用、穴径はアンカー仕様に合わせる
    - 鉄骨：ドリルビットで穴開け後ボルト固定
2. アンカーボルトを打ち込み、規定トルクで締め付ける
3. ブラケット・ハンガーを取り付け、水平を確認する
4. 支持物の荷重強度が設計荷重（ケーブル重量＋トレイ重量）に対して十分であることを確認

!!! warning "アンカー強度の確認"
    アンカー選定は施工図の仕様に従う。独断でサイズを変えないこと。  
    不安な場合は電計チームリーダーに確認。

### STEP 3：トレイ本体の設置

1. トレイを支持物に乗せ、**ボルト・ナットで固定**する
    - 緩み止めワッシャ（スプリングワッシャ）を使用する
    - 規定トルクで締め付ける（M8ボルト：20〜25 N·m目安）
2. トレイ同士の接続部（継手）を取り付け、**ボルト固定**する
    - 継手はトレイと同材質・同メーカーを使用（強度確保）
3. 曲がり・T分岐部は専用の曲がり継手・T型継手を使用する
    - 無理な曲げ加工は強度低下・ケーブル損傷の原因
4. 全体の水平・垂直を再確認する

### STEP 4：接地ボンディング

1. トレイ接続部に**ボンディングジャンパ**を取り付ける
    - 継手のボルト締結だけでは電気的連続性が不十分な場合がある
    - 金属製トレイには接地（低圧回路の収容ではD種）を施す
2. トレイ系統の末端に接地線を接続する
3. 接地抵抗を測定し、基準値（D種：100Ω以下。0.5秒以内の自動遮断装置がある場合の500Ωへの緩和条件を含む詳細は [接地（低圧）](../02-teiatsu/grounding-lv.md) が正典）を満たすことを確認する

!!! info "アルミトレイの接地"
    アルミトレイと鉄部品を直接接触させると電食（電気化学腐食）が発生する。  
    異種金属間には絶縁材（スリーブワッシャ等）を挟むこと。

### STEP 5：ケーブル延線

1. 延線前にトレイ上・内側に**バリ・鋭利な突起がないことを確認**する
    - あればヤスリで除去し、保護テープを巻く
2. 大径ケーブルは延線用ローラを使用して引きずらないように延線する
3. ケーブルを延線しながら、**トレイ上で束ねすぎない**ように整列する
    - 多段積みにしない（発熱・許容電流低下）
    - 整列の敷設幅はトレイ内幅の80%以下が目安（後述の断面充填率とは別の実務目安）

#### 多段ラックの段配置

```text
上段ラック：動力ケーブル
中段ラック：制御ケーブル
下段ラック：計装・信号ケーブル（分離が難しい場合は金属セパレータで仕切る）
```

段の並び順を定めた法令・規格は無く、段配置の考え方の正典は [計装配線](../03-keiso/wiring.md)（本ページはそれに合わせる。詳細は下記「根拠」参照）。

4. ケーブルに**ケーブルタグ**を取り付ける
    - 両端（始点・終点）と中間（30m毎）に取り付ける
    - タグ番号はケーブルリストと一致させる

### STEP 6：ケーブル固定

1. ケーブルをケーブルタイで固定する
    - 固定間隔：水平部は**1.5m以下**、垂直部は**1.0m以下**
    - 締め付けでケーブルが変形しない程度（目安：余裕1mm程度）
2. 垂直部のケーブルは**ケーブルクリート**等で確実に支持する
    - ケーブルの自重でコネクタ・端子台に力がかかると接触不良の原因
3. 機器接続部付近は余長を適切に確保する
    - 引っ張りによる断線防止
    - 機器の微小な移動・振動への対応

### STEP 7：防火措置（延焼防止）

1. 防火区画（壁・床貫通部）を通過する場合は**防火措置**を施す
    - 防火パテ・防火スリーブ等を使用
    - 建築基準法・消防法に基づく施工
2. 貫通後は**防火区画図**に反映する

## トレイ充填率の計算

充填率が80%を超えると放熱不足による許容電流低下が生じる。**80% は施工上限の実務値であり、規格・法令の値ではない**（設計段階の目標は 50% 以下 → [電路設計](../04-sekkei/cable-route.md)）。

```text
充填率 (%) = (収容ケーブルの外径断面積の合計) ÷ (トレイの内幅 × 内高さ) × 100
```

- 分子は**各ケーブルの仕上外径から求めた円の断面積**（π/4 × 外径²）の合計。導体断面積（mm² 表記の公称サイズ）ではない
- 分母は**トレイの有効断面積（内幅 × 内高さ）**

例：トレイ内幅200mm、内高さ60mm、ケーブル外径断面積合計8,000mm²  
→ 充填率 = 8,000 ÷ (200 × 60) × 100 = 66.7%（施工上限80%以下でOK。新設の設計目標50%は超過しているため、設計段階ならトレイ幅の見直し対象）

!!! note "電技解釈の 20%／50% はケーブルトレイの値ではない"
    電気設備の技術基準の解釈 第162条第1項第二号が定める充填率（20% 以下、制御回路等のみは 50% 以下）は**低圧屋内配線の金属ダクト工事**に対する規定で、ケーブルトレイ（ラック）には適用されない（[電路設計](../04-sekkei/cable-route.md) の根拠節で原典照合済み）。

## よくある施工不良と対処

| 不具合 | 原因 | 対処 |
|--------|------|------|
| トレイの歪み・傾き | 支持間隔過大・固定不足 | 中間支持追加・ボルト増し締め |
| ケーブル損傷 | バリによる傷・無理な曲げ | バリ処理・ローラ使用 |
| 接地不良 | ボンディング未施工 | ジャンパ線追加 |
| 電食（腐食） | 異種金属接触 | 絶縁ワッシャ使用 |
| 過剰充填 | 設計変更未反映 | トレイ幅拡大または別ルート追加 |

## 根拠

### 本ページが正典の範囲

ケーブルトレイの**充填率（施工上限 80%）・支持間隔・曲げ半径の施工実務**は本ページが正典（[電路設計](../04-sekkei/cable-route.md) の正典参照表で指定済み）。設計段階の充填率目標（50%）は電路設計側が持つ。

### 是正の記録（2026-08-06）

- **段配置の上下が正典と真逆でした。** かつて本ページは「上段＝計装・信号線／下段＝動力ケーブル」と書いていましたが、段配置の正典 [計装配線](../03-keiso/wiring.md) は「上段＝動力／中段＝制御／下段＝計装信号」で、**同じ repo 内で真逆**でした（[電路設計](../04-sekkei/cable-route.md) が 2026-08-03 に段配置を計装配線へ一本化済み）。並び順を定めた法令・規格は無い（電技解釈第167条は離隔・隔壁・同一ダクト収容禁止のみ。計装配線の根拠節で原典照合済み）ため、本ページの独自の並びを撤回し正典に合わせました。
- **支持間隔 1.5m の「JIS基準」帰属を撤回しました。** 出所となる JIS 規格番号・条項を特定できず、repo 内にも一次照合済みの記述がありません。値そのものは安全側の実務値として維持し、帰属だけを是正しました。
- **充填率の分母・分子を明文化しました。** 「ケーブル断面積」が導体公称断面積（mm²）と誤読される余地があったため、分子＝仕上外径からの円断面積の合計、分母＝トレイ内幅×内高さ（有効断面積）と定義を明示しました。計算例（8,000 ÷ 12,000 = 66.7%）は 2026-08-06 に再計算して一致を確認しています。

### 実務慣行（規格・法令の裏付けなし）

- 充填率の施工上限 80%・設計目標 50%（いずれも実務値。規格上の統一値は無い）
- 支持間隔 1.5m 以下／重量物 1.0m 以下、ケーブルタイ固定間隔（水平 1.5m・垂直 1.0m）、通路幅 600mm、ケーブルタグの 30m 毎取付、M8 ボルトの締付トルク 20〜25 N·m、敷設幅はトレイ内幅の 80% 以下
- 動力線・信号線の離隔距離（仕切りあり 150mm 等）は [計装配線](../03-keiso/wiring.md) の実務目安を参照

### 原本未照合（honest-hold）

- **金属製トレイの接地を義務付ける電技解釈の条番号は本ページでは照合していません**（電技解釈は告示で e-Gov 法令 API の対象外）。接地抵抗値（D種 100Ω・500Ω 緩和）自体は [接地（低圧）](../02-teiatsu/grounding-lv.md) が第17条第4項を原典照合済み
- **内線規程（JEAC 8001）は有償で未照合**。トレイの支持間隔・充填率について同規程が数値を持つかは確認していません
- 防火区画貫通部の措置（建築基準法・消防法）の条項は本ページでは照合していません。工法は認定工法（防火パテ・防火スリーブ等）の施工要領に従ってください
