# 法定業務一覧

## 30秒まとめ

電気主任技術者の選任義務の根拠は電気事業法第43条。月次・年次の法定点検と記録保管、電気事故報告、保安規程の作成・変更届出、工事計画届出が主な法定業務。届出の要否は規模と工事内容で決まる。

---

## 電気主任技術者の法的根拠

**電気事業法第43条**: 事業用電気工作物を設置する者は、電気主任技術者を選任しなければならない。

```
自家用電気工作物:
  電圧600V超で受電する需要設備
  （当工場は特別高圧または高圧受電のため対象）
```

電気主任技術者は**保安監督**の責任者であり、設備の工事・維持・運用に関する保安の監督を行う。

> **保安監督とは**: 保安のために必要な指示を行う権限と責任を持つこと。現場作業の直接実施よりも「監督・指示」が本来の役割。

---

## 自家用電気工作物の保安監督義務

### 監督対象設備（当工場の場合）

| 設備種別 | 概要 |
|---------|------|
| 受変電設備 | 特高/高圧受電設備、主変圧器、遮断器（VCB等） |
| 配電設備 | 高圧配電盤、低圧幹線、分岐回路 |
| 電力用機器 | 高圧電動機（6kV等）、コンデンサ、リアクトル |
| 非常用電源 | 非常用発電機、UPS |
| 電気工作物に付属する計装設備 | 保護継電器、電力量計 |

### 保安監督の具体的な義務

1. 月次・年次の法定点検の実施・確認
2. 電気工作物の工事・維持・運用の監督
3. 異常・事故時の応急処置と報告
4. 保安規程の遵守・見直し
5. 従業員への保安教育の実施

## 月次・年次の法定点検と記録保管義務

### 月次点検（毎月実施）

| 点検項目 | 確認内容 |
|---------|---------|
| 外観点検 | 異音・異臭・変色・汚損・損傷の確認 |
| 測定記録 | 電圧・電流・電力の指示値確認 |
| 計器確認 | 電力量計の正常動作、保護継電器の表示確認 |
| 開閉器動作確認 | LBS・DS等の動作状態確認 |
| 接地線の確認 | 断線・腐食がないか |

**記録保管**: 月次点検記録は3年以上保管が一般的（**年限は保安規程で定める値**であって法定最低基準ではない。下記 warning 参照）

### 年次点検（停電を伴う精密点検）

| 点検項目 | 内容 | 実施頻度 |
|---------|------|---------|
| 絶縁抵抗測定 | 電路・機器の絶縁抵抗（MΩ測定） | 年1回以上 |
| 絶縁耐力試験 | 規定電圧での耐力確認（新設・大修繕後） | 工事後 |
| 保護継電器試験 | 動作電流・時間の整定値確認 | 年1〜3回（保安規程による） |
| 変圧器点検 | 絶縁油採取・試験、タップ確認 | 年1回以上 |
| 遮断器点検 | 動作確認、接触抵抗測定、操作回路確認 | 年1回以上 |
| 接地抵抗測定 | A種・B種・C種・D種各接地の抵抗値 | 年1回以上 |

!!! warning "記録の「保存年限」を定めているのは法令ではなく保安規程"
    自家用電気工作物について電気事業法施行規則 第50条**第3項**が求めているのは、保安規程に**第七号「保安についての記録に関すること」**と**第八号「法定自主検査又は使用前自己確認に係る実施体制及び記録の保存に関すること」**を定めることであって、**同条に保存年限の数値規定はありません**（2026-07-30 に e-Gov 現行条文で逐語照合）。
    したがって「◯年保管」は**自事業場の保安規程で定めた値**です。本ページ・[保安規程](hoan-kisoku.md) の年数は一般的な慣行値であり、法定最低基準ではありません。
    記録を作成・保存すること自体は保安規程の遵守義務（法第42条第2項）を通じて求められるため、**「記録を残さなくてよい」という意味ではない**点に注意してください。
    なお**事故報告**は電気関係報告規則に基づく別建ての手続きで、期限は [電気事故対応と報告](jiko-taiou.md) を参照。

## 電気事故報告の義務

電気事業法第106条（自家用電気工作物の設置者に対する報告徴収は第6項）・電気関係報告規則 第3条に基づき、条文が限定列挙する電気事故は報告義務がある。

自家用電気工作物の設置者の**提出先は原則として「電気工作物の設置の場所を管轄する産業保安監督部長」**であり、経済産業大臣ではありません（第3条第1項の表の報告先の欄）。経済産業大臣宛になるのは、報告先の異なる号に二重該当した場合などです。

### 報告が必要な事故の範囲

| 事故種別 | 報告要否 |
|---------|---------|
| 感電・電気工作物の破損等による死傷事故（**死亡または入院に限る**。第3条第1項第一号） | **要報告** |
| 電気火災（**工作物にあっては半焼以上に限る**。第二号） | **要報告** |
| 他の物件に損傷を与え、またはその機能を損なわせた事故（第三号） | **要報告** |
| 主要電気工作物（変圧器・遮断器等）の破損（第四号ヌ＝**電圧1万V以上の需要設備に限る**） | **要報告**（6.6 kV受電なら第四号としては対象外） |
| **電圧3,000V以上**の自家用電気工作物の破損等で電力会社側に供給支障を発生させた事故（第十二号） | **要報告** |
| 社会的に影響を及ぼした事故（第十四号＝包括条項） | **要報告** |
| 上記いずれの号にも該当しない構内事故（人身・火災・他物件損傷・供給支障なし） | **不要**（記録は残す） |

> **判断に迷ったら**: 所轄の産業保安監督部（関東では関東東北産業保安監督部）に事前確認することを推奨。報告基準の解釈を口頭確認しておくと事故時の対応が速い。

### 報告期限

| 報告種別 | 提出期限 |
|---------|---------|
| 速報 | 事故の発生を**知った時**から**24時間以内**、可能な限り速やかに（電話等） |
| 確報 | 事故の発生を**知った日**から起算して**30日以内**（様式第13の報告書） |

起算点は「発生」ではなく「**発生を知った時／知った日**」（電気関係報告規則 第3条第2項）。休日夜間に発生し翌朝に覚知したケースで判断を誤らないこと。

詳細な対応手順は [jiko-taiou.md](jiko-taiou.md) を参照。

## 保安規程の作成・変更届出

- 自家用電気工作物の設置者は**保安規程を作成**し、使用開始前に届出が必要（法第42条第1項。様式第四十一）
- **変更したときは、変更の大小を問わず遅滞なく届出が必要**（法第42条第2項。様式第四十二）

!!! warning "保安規程には工事計画届出のような「軽微なもの」の除外規定はありません"
    法第42条第2項は変更の大小による除外を置いていません。「軽微だから届出不要」は**工事計画届出**の話（法第48条第1項ただし書＋施行規則第65条第2項）であり、保安規程に流用すると届出漏れになります。判断基準は「軽微か否か」ではなく「**保安規程そのものが変わったか否か**」です。

詳細は [hoan-kisoku.md](hoan-kisoku.md) を参照。

## 工事計画届出が必要なケース

電気事業法第48条に基づき、主務省令で定める工事は事前に**届出**が必要。要否は電気事業法施行規則第65条および**同規則 別表第二**の設備区分・工事内容で判定する。

!!! warning "判定の入口は「受電電圧」であって「最大電力」ではない"
    需要設備の工事計画届出は、**受電電圧 10,000 V 以上**の需要設備であることが前提です（別表第二「需要設備」の欄）。
    したがって **6.6 kV 受電の一般的な高圧需要家は、需要設備としての工事計画届出の対象外**です。20 kV・30 kV・60 kV 等で受電している場合に対象になります。

### 届出が必要な主なケース（需要設備・鉱山保安法が適用されるものを除く）

| 区分 | 工事内容 | 届出要否 |
|---|---|---|
| 設置の工事 | **受電電圧 10,000 V 以上**の需要設備の設置 | **要届出** |
| 変更（遮断器） | 他の者が設置する電気工作物と接続するための遮断器（受電電圧 10,000 V 以上の需要設備に属するもの）で**電圧 10,000 V 以上**のものの設置・取替え、および20%以上の遮断電流変更を伴う改造 | **要届出** |
| 変更（その他の機器） | **電圧 10,000 V 以上**、かつ**容量 10,000 kVA 以上または出力 10,000 kW 以上**の機器（計器用変成器を除く）の設置・取替え、および20%以上の電圧・容量・出力変更を伴う改造 | **要届出** |
| 変更（電力貯蔵装置） | 受電電圧 10,000 V 以上の需要設備に属する**容量 80,000 kWh 以上**の電力貯蔵装置の設置、および20%以上の容量変更を伴う改造 | **要届出** |
| 変更（電線路） | **電圧 50,000 V 以上**の電線路の設置、電圧 100,000 V 以上の電線路の 1 km 以上の延長 ほか | **要届出** |
| 上記に該当しない変更 | — | **不要**（法第48条第1項の「軽微なもの」＝施行規則第65条第2項） |

!!! info "非常用発電機について"
    別表第二の**需要設備の欄に発電設備の行はありません**。構内の発電設備は「発電所」の区分で判定します（別表第二の発電所の欄。原動力の種類ごとに出力の閾値が異なる）。
    「出力○ kW 以上なら一律に届出」という単純な基準ではないため、原動力の種類・出力・設備構成を別表第二の該当項に当てて判定してください。

### 届出のタイミング

```text
工事計画届出の提出
    ↓
受理された日から 30 日を経過するまで着工不可（法第48条第2項）
  ※主務大臣が期間を短縮できる（法第48条第3項）。短縮の通知を受けた場合のみ、その日以後に着工できる
  ※審査に時間を要する場合は期間が延長されることがある（法第48条第5項）
    ↓
工事着工
    ↓
竣工検査（保安監督）
    ↓
使用前安全管理検査（大規模設備の場合）
    ↓
使用開始
```

!!! danger "届出なしで着工した場合"
    工事計画届出が必要な工事を届出なしで行った場合、または届出受理から30日を経過せずに着工した場合は電気事業法違反となります（法第48条第1項・第2項違反 → **法第120条第八号：30万円以下の罰金**）。
    なお、届出を受けて主務大臣が出した**計画変更・廃止命令に違反**して工事をした場合は、より重い**法第119条第十号：100万円以下の罰金**です。
    設備改造の計画段階で電気主任技術者が届出要否を確認することが重要。

### 根拠

- 電気事業法 第48条（工事計画の事前届出／受理から30日の待機／期間短縮／変更命令）
- 電気事業法施行規則 第65条（届出の対象。第2項が「軽微な変更」を定義）
- 電気事業法施行規則 別表第二「需要設備（鉱山保安法が適用されるものを除く。）」の欄
- 罰則：電気事業法 第120条第八号（第48条第1項・第2項違反）／第119条第十号（第48条第4項の命令違反）

いずれも **e-Gov 法令検索の現行条文で 2026-07-30 に逐語照合**（電気事業法＝昭和三十九年法律第百七十号、電気事業法施行規則＝平成七年通商産業省令第七十七号）。別表第二は改正で区分・数値が変わり得るため、実際の届出判断では最新版と所轄の産業保安監督部に確認すること。

### 根拠（工事計画届出以外）

- 電気事業法 第42条第1項（保安規程の作成・使用開始前の届出）／**第2項（変更したときは遅滞なく届出。変更の大小による除外規定なし）**
- 電気事業法 第43条第1項（主任技術者の選任。**規模による選任義務の閾値は無い**）／第3項（選任・解任の届出）／第4項（保安監督の職務の誠実な遂行）／第5項（従事者の指示遵守義務）
- 電気事業法施行規則 第50条第1項第二号・**第3項第一号〜第九号**（自家用電気工作物の保安規程の必須記載事項。年限の数値規定なし）
- 電気事業法施行規則 第51条第1項（様式第四十一＝保安規程届出書）／第2項（様式第四十二＝保安規程変更届出書）
- 電気事業法 第106条第6項（自家用電気工作物の設置者に対する報告徴収）
- 電気関係報告規則 第3条第1項（事故報告の対象＝第一号〜第十四号の限定列挙と報告先の欄）／第2項（速報24時間・確報30日、いずれも**「事故の発生を知つた時／知つた日」**起算、様式第十三）

いずれも **e-Gov 法令検索の現行条文で 2026-07-30 に逐語照合**（電気事業法＝昭和三十九年法律第百七十号、電気事業法施行規則＝平成七年通商産業省令第七十七号、電気関係報告規則＝昭和四十年通商産業省令第五十四号）。

**限界の明示**:

- 本ページ冒頭の「月次点検」「年次点検」の**項目・頻度は法定値ではありません**。施行規則第50条第3項第三号が求めているのは保安規程に巡視・点検・検査を定めることであり、頻度の数値は自事業場の保安規程で決まります。表の「年1回以上」等は一般的な慣行値です。
- 事故報告の各号の限定条件（入院、半焼以上、1万V、3,000V）と報告先は[電気事故対応と報告](jiko-taiou.md)に詳述。本ページの表は要約であり、実際の判定は原典の全表に当たること。
- 保安規程の必須記載事項は[保安規程の管理](hoan-kisoku.md)に第3項の全9号を掲載。第50条**第2項**の15号は電気事業者向けで自家用には適用されない。
