## 安全の基本原則

!!! danger "絶対厳守"
    - 作業許可書なしの電気作業は禁止
    - LOTO未実施での機器内作業は禁止
    - 検電未実施での接触作業は禁止

!!! info "このセクションの活用方法"
    - 新入メンバーの安全教育資料として使用可能
    - KY活動・ツールボックスミーティングの参考資料として活用
    - 変更管理（MOC）時のリスクアセスメントのチェックリストとして参照

## 関連法規・基準

| 法規・規格 | 主な内容 |
|-----------|---------|
| 労働安全衛生法 | 電気取扱特別教育・リスクアセスメント義務 |
| 労働安全衛生規則 第339条 | 停電作業を行なう場合の措置（施錠・表示・監視人／残留電荷の放電／高圧・特別高圧の検電と短絡接地。第2項で通電前の確認） |
| 労働安全衛生規則 第341条〜第347条 | 活線作業・活線近接作業（停電作業とは別の規定） |
| 電気事業法 | 自家用電気工作物の保安規程 |
| 社内保安規程 | 自工場独自の作業基準 |
