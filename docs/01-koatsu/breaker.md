# 遮断器・断路器

## 30秒まとめ

VCB（真空遮断器）は高圧回路の開閉・保護の主役。断路器は必ずVCBをオフにしてから操作する（鉄則）。開閉サージは変圧器やモーターを傷める原因となるためサージアブソーバが重要。

---

## VCB（真空遮断器）の動作原理

高真空中（10⁻⁴ Pa 以下）でアークを発生させ、電流ゼロ点で真空の高絶縁性により急速に消弧する。

| 特徴 | 内容 |
|------|------|
| 消弧方式 | 真空中の電流ゼロ点での急消弧 |
| 遮断能力 | 定格遮断電流の確認が必要（通常 12.5〜40 kA） |
| 維持管理 | 真空バルブの真空度点検が必要（定期的に） |
| 寿命の目安 | 機械的寿命（開閉回数）：10,000〜20,000 回程度（メーカー・機種による。メーカー仕様書が正） |
| サージ発生 | 截断電流によるサージ電圧が発生する |

---

## 開閉サージとサージアブソーバ

### 開閉サージの発生メカニズム

VCBは電流ゼロ点を待たずに電流を強制的に切る（截断＝チョッピング）性質があります。截断の瞬間、負荷側インダクタンス L に蓄えられた磁気エネルギー（½ L I_chop²）が回路のキャパシタンス C へ移り、L と C の共振によって過電圧が発生します。

截断電流 I_chop が流れている状態で電流が急に断たれると、そのエネルギーが C を充電し、過電圧のピーク値は次式で見積もります。

```
サージ電圧 V ≒ I_chop × √(L / C)
```

- I_chop：截断電流 [A]（VCBが電流ゼロ点前に切る電流。数 A 〜10 A 程度）
- √(L / C)：回路のサージインピーダンス Zₛ [Ω]
- 積 I_chop × Zₛ は [A]×[Ω] = [V] となり、次元的に電圧になります

系統電圧そのものに √(L/C) を乗じても電圧にはならない（√(L/C) は Ω のため）点に注意します。過電圧の駆動源はあくまで截断電流 I_chop です。

特に**始動中のモーターの遮断**や**無負荷変圧器の励磁電流の遮断**のような「高インダクタンス・小電流」の遮断条件では Zₛ＝√(L/C) が大きく、高いサージが発生しやすくなります（截断のほか、遮断後の再発弧が繰り返されることでもサージが重畳します）。

### サージアブソーバの設置

| 設置箇所 | 種類 | 目的 |
|---------|------|------|
| VCB 二次側（変圧器・モーター端子近傍） | RC サージアブソーバ | 開閉サージ吸収 |
| 特高変電所入口 | 避雷器（LA） | 雷サージ吸収 |
| 6.6kV フィーダー | 避雷器（LA） | 系統サージ吸収 |

## 断路器操作の鉄則

!!! danger "断路器の操作順序を絶対に守る"
    断路器（DS）はアーク消弧能力がほぼゼロ。電流が流れている状態で操作すると激しいアークが発生し、重大な事故につながる。

    **停電（開放）手順：**
    ```
    1. VCB を開く（電流を遮断）
    2. VCB が開路したことを確認（表示灯・機械的インジケータ）
    3. 断路器を開く
    ```

    **投入（充電）手順：**
    ```
    1. 断路器を閉じる
    2. 断路器が完全に閉じたことを確認
    3. VCB を閉じる
    ```

## 遮断容量の確認

遮断器の**定格遮断電流（kA）**が、設置点での**短絡電流（kA）**以上であること。

```text
設置点の短絡電流（kA） = 系統短絡容量（MVA） / (√3 × 系統の公称電圧〔線間・kV〕)
```

短絡容量（MVA）は √3 × 公称電圧 × 短絡電流 で定義されるため、割り戻す電圧は**系統の公称電圧**（6.6kV 系なら 6.6）を使います。遮断器の定格電圧（6.6kV 系用は 7.2kV）で割ると短絡電流を約 8% 小さく見積もってしまい、危険側になります。

**検算例**：系統短絡容量 250 MVA・6.6 kV 系の場合、250 / (√3 × 6.6) ≒ 21.9 kA → 定格遮断電流 25 kA 以上の遮断器を選定する。

!!! warning "変圧器増設時の再確認"
    変圧器の増設・並行運転を行うと系統の短絡電流が増加する。
    既設遮断器の遮断容量を超えていないかを再計算すること。

## 接点・真空バルブの点検項目

### 真空バルブの真空度点検

真空度が劣化すると遮断性能が低下する。点検は**ハイポット（高圧絶縁試験器）**で試験電圧をかけ、放電の有無で判定する。製造メーカーの試験手順に従う。

### 接点の摩耗確認

各開閉動作で接点は少しずつ摩耗する。接点の残存寿命は**接点ギャップ（ストローク）**の測定で確認する。許容値はメーカー仕様書に記載。

| 点検項目 | 点検周期 | 判定基準 |
|---------|---------|---------|
| 真空度 | 3〜5年ごと | メーカー基準値以上 |
| 接点摩耗量 | 3〜5年ごと | メーカー許容値以内 |
| 操作コイル電圧 | 年1回 | メーカー指定範囲（例：定格の 85〜110%。規格原本未照合の目安値、下記「根拠」参照） |
| 絶縁抵抗 | 年1回 | 5000V メガーで測定。高圧機器に法定の絶縁抵抗値は無く、前回比の急低下で判断する（[絶縁管理](../05-hozen/insulation-management.md) が正典） |

## 投入・解放のインターロック確認

| インターロック | 目的 |
|-------------|------|
| VCB 開路確認なしに DS 操作不可 | 断路器の誤操作防止 |
| 断路器閉路確認なしに VCB 投入不可 | 接続未確定での投入防止 |
| 母線 PT 電圧確認 | 停電確認なしの投入防止 |
| アース開路確認 | 接地状態での投入防止 |

インターロック回路の変更・バイパスは変更管理（MOC）手続きを経ること。絶対に無断でバイパスしない。

## 根拠

### 本ページが正典の範囲

**VCB・断路器の動作原理・開閉サージの機構・操作順序・点検項目**が本ページの正典範囲です。継電器の種類・整定は [保護継電器](relay.md)、上位・下位との時限協調は [保護協調](coordination.md)、絶縁抵抗の印加電圧・判定の考え方は [絶縁管理](../05-hozen/insulation-management.md)・[耐圧試験・絶縁診断](insulation-test.md) が正典で、本ページは数値を再記述しません。

### 一次計算で検算済み

- **短絡電流の式**: 短絡容量の定義 MVA = √3 × V(kV) × I(kA) を I について解いた形で、次元は MVA / (√3 × kV) = kA。検算例 250 / (√3 × 6.6) = 250 / 11.43 ≒ 21.9 kA を電卓検算しました（2026-08-05）
- **サージ電圧の式**: I_chop × √(L/C) は [A] × [Ω] = [V] で次元整合。系統電圧に √(L/C) を乗じる形は次元が合わない（[V]×[Ω] になる）ことも確認済み
- **定格電圧で割った場合の誤差**: 6.6 / 7.2 ≒ 0.917 → 短絡電流を約 8% 過小評価（危険側）

### 二次資料で一致を確認（原本未照合）

- **真空バルブの真空度 10⁻⁴ Pa 以下**、**截断（チョッピング）電流 数 A〜10 A 程度**、**定格遮断電流の系列 12.5〜40 kA**、**機械的寿命 10,000〜20,000 回**: いずれもメーカー技術資料・教科書レベルの二次資料で広く一致する値ですが、該当規格（JIS C 4603・JEC-2300 等）の原本は未照合のため、規格番号を根拠として引用しません

### 是正の記録（2026-08-05）

- **短絡電流式の分母**: 「定格電圧（kV）」と書いていましたが、短絡容量の定義電圧は**系統の公称電圧**（6.6kV 系なら 6.6）であり、遮断器の定格電圧（7.2kV）と取り違えると短絡電流を約 8% 小さく（危険側に）見積もるため、「系統の公称電圧（線間）」に是正し検算例を追記しました
- **開閉サージの最悪条件**: 「高インダクタンス負荷の起動・停止時」というあいまいな表現を、機序に沿って「始動中のモーターの遮断・無負荷変圧器の励磁電流の遮断（高インダクタンス・小電流の遮断条件）」に是正し、再発弧によるサージの重畳にも言及しました
- **frontmatter の description**: 本文に GCB（ガス遮断器）の記述が無いのに「VCB/GCB選定」と掲げていたため、GCB を削除しました
- **「耐用年数」行**: 内容は開閉回数（機械的寿命）であり見出しと不一致だったため「寿命の目安」に改め、メーカー仕様書が正である旨を明示しました

### 原本未照合（honest-hold）

- **操作コイル電圧の許容範囲（定格の 85〜110%）**: JEC-2300（交流遮断器）等の規格に操作電圧範囲の規定があるとされますが、原本未照合です。点検判定は**メーカー指定範囲を正**としてください
- **真空度点検の方法・周期**（ハイポット試験・3〜5年）と**接点摩耗の許容値**: メーカーの試験手順・仕様書の領域で、本ページでは規格・条文を特定していません

### 実務慣行（規格・法令の裏付けなし）

- 点検周期（真空度・接点摩耗 3〜5年、操作コイル電圧・絶縁抵抗 年1回）は保全計画上の目安であり、法定周期ではありません
- サージアブソーバの設置箇所の表（VCB 二次側・特高入口・フィーダー）は代表的な実務構成の例示です

### 限界の明示

- **短絡電流の式は概算（%インピーダンス法の簡易形）です。** 遮断器選定の確定計算は系統インピーダンスの詳細（電源・変圧器・ケーブル）に基づいて行い、変圧器増設時は必ず再計算してください
- 開閉サージの実際のピーク値は回路条件（ケーブル長・負荷特性・遮断器特性）に依存し、本ページの式は機構理解のための見積り式です
