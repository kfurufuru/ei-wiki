# リスクアセスメント

## 30秒まとめ

リスクアセスメントは対象によって「義務」と「努力義務」が分かれるため、まず自分の作業がどちらかを条文で確定する。化学物質のリスクアセスメントは義務であり、努力義務と取り違えないことが重要。

---

## 実施義務（義務と努力義務の区別）

リスクアセスメント（RA）は対象によって「義務」と「努力義務」が分かれます。化学プラントでは両者を取り違えないことが重要です。

| 対象 | 根拠条文 | 位置づけ |
|------|---------|---------|
| リスクアセスメント対象物（＝安衛法57条の2の通知対象物＋施行令第18条の表示対象物） | 労働安全衛生法**第57条の3** | **実施義務**（罰則の直接規定はないが法的義務） |
| 上記以外の化学物質、および機械・設備・作業等 | 労働安全衛生法第28条の2 | 努力義務 |

- **化学物質のRAは「努力義務」だけではありません。** 「リスクアセスメント対象物」（通知対象物・表示対象物）を製造・取り扱う場合は第57条の3により実施が義務です。
- 第57条の3で義務なのは**調査（RA）の実施**（第1項「調査しなければならない」）。調査結果に基づく**低減措置**は、法令が個別に義務づける措置を除き**努力義務**です（第2項「講ずるように努めなければならない」）。「RAをやれば足りる」でも「対策まで全部法的義務」でもない点に注意。
- 第28条の2のただし書により、**化学物質以外**（機械・設備・作業等）の調査の努力義務は「製造業その他厚生労働省令で定める業種」に限られます（安衛則第24条の11第2項）。化学工場は製造業なので対象です。
- 対象物質は自律的な化学物質管理への移行に伴い**大幅に拡大中**（数百物質規模から順次追加）。自社で扱う物質が対象かは最新のSDS・対象物リストで確認が必要です。
- RAの実施時期は「原材料等の新規採用・変更時」「作業方法・手順の新規採用・変更時」「危険性・有害性等に変化が生じ、又は生ずるおそれがあるとき」（化学物質は安衛則第34条の2の7第1項、機械・設備等は安衛則第24条の11第1項。後者は建設物の設置・移転・変更・解体時も含む）。
- 電気作業（停電作業・高所作業・高圧設備点検等）そのものは機械・設備側のRAであり第28条の2の努力義務ですが、化学工場では安全衛生管理の基本として実施します。

!!! warning "化学プラントでは化学物質RAが「義務」になるケースが多い"
    プロセス系の薬液・溶剤・触媒などの多くは「リスクアセスメント対象物」に該当します。この場合は第57条の3により**RA実施が義務**です。電気・計装作業でも、対象物を取り扱うエリアでの作業や、対象物に関わる設備変更を行う際は、化学物質RAの実施状況を確認してください。

!!! info "「努力義務」≠ やらなくていい"
    化学工場の電気作業は感電・アーク閃光・誤操作による重大災害リスクがある。努力義務のRAも「実施しないと罰則がある」かどうかで判断せず、「実施しないと自分と仲間が怪我をする」実務行為として捉える。

## リスク評価の手順

### ステップ1：危険源の特定

作業で接触する可能性のある危険源を全て洗い出す。

**電気作業での典型的な危険源**

| 危険源 | 具体例 | 結果 |
|--------|--------|------|
| 充電部への接触 | 開放した制御盤内の端子・バスバー | 感電・死亡 |
| アーク閃光（アークフラッシュ） | 高圧部の短絡・誤操作 | 重度熱傷・失明 |
| 誤操作・誤投入 | 停電中と思い込んだ回路への作業 | 感電・巻き込まれ |
| 高所からの転落 | 配電盤上部の作業 | 骨折・死亡 |
| 残留電荷 | インバータの平滑コンデンサ | 感電 |
| 高温部への接触 | 運転中の変圧器・ケーブル | 熱傷 |

### ステップ2：リスク評価

特定した危険源ごとに「影響度」と「発生頻度（可能性）」を評価する。

**リスクマトリクス**

|  | 影響度：軽微 | 影響度：中程度 | 影響度：重大 | 影響度：致命的 |
|--|------------|-------------|------------|-------------|
| **頻度：高い** | 低 | 中 | **高** | **最高** |
| **頻度：中程度** | 低 | 中 | 中〜高 | **高** |
| **頻度：低い** | 最低 | 低 | 中 | 中〜高 |
| **頻度：まれ** | 最低 | 最低 | 低 | 中 |

**判定の目安**

| リスクレベル | 対応 |
|-----------|------|
| 最高・高 | 作業を中止し、リスク低減措置なしに作業開始禁止 |
| 中 | リスク低減措置を実施してから作業開始 |
| 低・最低 | 通常の安全手順を守って作業可能 |

### ステップ3：リスク低減対策の検討

対策は以下の優先順位で検討する（高位の対策が優先）。

```
① 除去（危険源そのものをなくす）
   例：使わない動力回路を廃棄撤去

② 代替（危険の少ない方法に変える）
   例：高圧を低圧に降圧して対応

③ 工学的対策（隔離・インターロック等）
   例：開放時に電源が切れるインターロック設置

④ 管理的対策（手順・訓練・許可制度）
   例：LOTO手順の徹底・PTW制度

⑤ 保護具（PPE）
   例：絶縁手袋・顔面シールド（アーク対応）
```

### ステップ4：残留リスクの確認

対策実施後に残るリスクが許容可能かを再評価。許容できない場合は再度ステップ3へ。

## 電気作業の典型的な危険源と対策

| 危険源 | 主なリスク低減対策 |
|--------|----------------|
| 充電部への接触 | LOTO・検電・絶縁手袋・絶縁シートで充電部を養生 |
| アーク閃光 | 高圧部はアーク対応PPE（FR服・フェイスシールド）着用 |
| 誤操作・誤投入 | PTW制度・操作禁止タグ・LOTO |
| 残留電荷（コンデンサ） | 電源遮断後の放電確認（インバータの放電待機時間はメーカー取扱説明書の指示による。「5分以上」は実務目安であり規格値ではない） |
| 高所転落 | 足場・安全帯の使用・ヘルメット |

## KY（危険予知）活動との連携

KY活動は、その日の作業を始める前にチームで危険源を話し合う短時間の安全確認活動。リスクアセスメントの「現場版・簡易版」と位置づけられる。

### 電気作業でのKYシートの書き方

```
【作業内容】インバータ盤（MCC-101）内部の端子増し締め作業

どんな危険があるか？
① 充電中の端子に触れて感電する
② LOTO解除前に復電し通電する
③ 接続工具が落下して端子短絡・スパーク

どうすれば防げるか？
① 停電確認（検電器使用）・絶縁手袋着用
② 自分の個人錠を掛ける・全員が掛けるまで復電しない
③ 工具には落下防止ひもを取り付ける

今日の重点目標：「LOTO確認してから手を入れる！」
```

## 変更管理（MOC）でのリスクアセスメント

設備の変更（配線変更・回路追加・設定変更等）を行う場合は、**変更管理（Management of Change: MOC）プロセス**の中でリスクアセスメントを実施する。

### MOCで電気担当が確認すること

| 変更内容 | 電気リスクのチェックポイント |
|---------|--------------------------|
| 回路の追加・変更 | 過電流保護の整定値は適切か・幹線容量に余裕があるか |
| 制御システムの変更 | インターロックの変更影響・フェイルセーフの確認 |
| 電動機の換装 | 起動電流・制御回路の互換性 |
| 防爆エリアの変更 | 防爆グレードの適合性・点火源になるものがないか |
| 計装ループの変更 | ループ電源の容量・アース設計 |

!!! warning "「小さな変更」も必ずMOCへ"
    「ちょっとした配線変更」「設定値の変更」も波及リスクがある。特に制御系の変更はプロセス安全に直結するため、影響範囲を過小評価しないこと。

### 一次照合済みの条項号（e-Gov 法令 API・2026-08-06 照合）

| 条項 | 確認した内容 |
|---|---|
| 労働安全衛生法 第28条の2 第1項 | 危険性又は有害性等の調査と措置は「講ずるように**努めなければならない**」＝努力義務。対象から第57条第1項の政令で定める物・通知対象物によるものは**除かれる**（そちらは第57条の3へ）。ただし書で、化学物質等以外の調査は「製造業その他厚生労働省令で定める業種」に限定 |
| 同 第57条の3 第1項 | 第57条第1項の政令で定める物（表示対象物）及び通知対象物による危険性又は有害性等を「**調査しなければならない**」＝調査の実施義務 |
| 同 第57条の3 第2項 | 調査結果に基づく措置は、法令の規定による措置を講ずるほか「講ずるように**努めなければならない**」＝法定外の低減措置は努力義務 |
| 同 第119条・第120条 | 現行の罰則対象条文の列挙に**第57条の3は含まれない**ことを確認（本文の「罰則の直接規定はない」の根拠） |
| 労働安全衛生規則 第24条の11 | 第28条の2のRAの実施時期（建設物の設置等／設備・原材料等の新規採用・変更／作業方法・手順の新規採用・変更／危険有害性等の変化）と、ただし書の業種の定め |
| 同 第34条の2の7 第1項 | リスクアセスメント対象物のRAの実施時期（新規採用・変更／作業方法・手順の新規採用・変更／危険有害性等の変化） |

### 二次資料で一致を確認（原本未照合）

- リスク低減対策の優先順位（本文の①除去 ②代替 ③工学的対策 ④管理的対策 ⑤保護具）は、厚生労働省の両指針が定める「本質的対策（設計・計画段階の危険性除去・低減）→ 工学的対策 → 管理的対策 → 個人用保護具」の順序と整合することを二次資料水準で確認した。指針原文の逐語照合は未実施
- 「リスクアセスメント対象物は自律的な化学物質管理への移行で大幅拡大中」は厚生労働省の公表資料の趣旨と一致（対象物質の具体数は変動するため本ページには書かない）

### 是正の記録（2026-08-06）

- 「第57条の3により実施が義務」に**義務の射程**を追記 → 義務なのは調査（第1項）で、法定外の低減措置は努力義務（第2項）。条文の一部だけを見て「対策まで全部義務」と読む誤りを予防
- 第28条の2の努力義務に**ただし書の業種限定**（化学物質以外は製造業その他省令で定める業種に限る）を追記 → 適用範囲の取り違え防止
- RA実施時期を条文（安衛則第24条の11・第34条の2の7）の文言に揃え、根拠条項を明記
- 「インバータは電源OFF後**5分以上待機**」を単独の基準のように書いていた → メーカー取扱説明書の指示が正で、5分は実務目安であることを明示

### 実務慣行（規格・法令の裏付けなし）

- リスクマトリクスの区分（4×4）・判定の目安・KYシートの書式は実務フレームであり、法令・規格が様式を定めたものではない
- インバータ残留電荷の放電待機時間はメーカー取扱説明書が正（「5分以上」は実務目安）

### 限界の明示

- 自社で扱う物質がリスクアセスメント対象物に該当するかは、最新のSDS・厚生労働省の対象物質リストで都度確認すること（本ページは物質リストを持たない）
- 罰則について確認したのは「第57条の3が第119条・第120条の列挙にない」ことまで。関連する他の義務（ラベル表示・SDS交付・ばく露低減措置等）には別途罰則・義務規定があり得る
