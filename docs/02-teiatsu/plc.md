# PLC 基礎

## 30秒まとめ

PLC の核心は「I/O 割付の正確な管理」と「プログラムバックアップ」。変更時は MOC（変更管理）手続きを経ること。化学プラントでは PLC プログラムの無断変更が重大事故につながるため、変更記録とテスト手順が必須。

---

## PLC の構成

```mermaid
flowchart LR
    subgraph PLC本体
        CPU[CPU モジュール\n演算・制御]
        PSU[電源モジュール\nDC24V 供給]
        DI[DI モジュール\nデジタル入力]
        DO[DO モジュール\nデジタル出力]
        AI[AI モジュール\nアナログ入力\n4-20mA / 1-5V]
        AO[AO モジュール\nアナログ出力]
        COM[通信モジュール\nCC-Link / EtherNet]
    end

    SENSOR[センサー・スイッチ] --> DI
    DI --> CPU
    CPU --> DO
    DO --> ACTUATOR[MC・電磁弁・表示灯]
    AI --> CPU
    CPU --> AO
    AO --> CTRL[制御弁・インバータ]
```

| モジュール | 主な仕様確認ポイント |
|-----------|------------------|
| CPU | スキャンタイム・プログラムメモリ容量・バッテリー有無 |
| DI | 入力電圧（DC24V/AC100V）・点数・応答時間 |
| DO | 出力形式（リレー/トランジスタ/トライアック）・定格電流 |
| AI | 分解能（12bit/16bit）・入力範囲・チャンネル数 |
| AO | 出力範囲（4-20mA/0-10V）・分解能 |

## I/O 割付の考え方

### 物理番号とソフトアドレスの対応

```text
物理的な配線（フィールド側）
    └─ DI モジュール スロット 2、チャンネル 3
         └─ ソフトアドレス X023（三菱 MELSEC の例）
              └─ ラダープログラム内で使用
```

### 割付設計の原則

| 原則 | 内容 |
|------|------|
| 機能別グルーピング | 同一ユニット・系統の I/O を連番で集める |
| 予備点確保 | 各モジュールに 20% 以上の予備点を確保 |
| 安全入力は専用モジュール | 安全 PLC 使用の場合は安全 I/O と通常 I/O を分離 |
| アナログとデジタル分離 | ノイズ干渉を防ぐため物理的に離して配置 |

## ラダー基本命令

| 命令 | 三菱 | 安川 | 機能 |
|------|------|------|------|
| 常開接点読み込み | LD X0 | LD I0.00 | 接点 ON で導通 |
| 常閉接点読み込み | LDI X1 | LDNOT I0.01 | 接点 OFF で導通 |
| コイル出力 | OUT Y0 | OUT Q0.00 | コイル制御 |
| AND 接続 | AND X2 | AND I0.02 | 直列接続 |
| AND ブロック結合 | ANB | ANDNOT | ブロック直列 |
| OR 接続 | OR X3 | OR I0.03 | 並列接続 |
| OR ブロック結合 | ORB | — | ブロック並列 |
| タイマ | OUT T0 K50 | TIM T0 #50 | 5.0秒タイマ |
| カウンタ | OUT C0 K10 | CNT C0 #10 | 10カウント |

## 主要通信プロトコル

| プロトコル | 特徴 | 主な用途 |
|-----------|------|---------|
| CC-Link IE Field | 1Gbps 光/電気、三菱標準 | 三菱 PLC 間・リモート I/O |
| PROFIBUS-DP | 12Mbps、IEC 標準、欧州系に多い | 計装機器との接続 |
| EtherNet/IP | 汎用 Ethernet ベース | 上位システム（SCADA/DCS）連携 |
| MODBUS RTU | シンプル、低速（115kbps） | 計装機器との簡易接続 |
| HART（デジタル重畳） | 4-20mA にデジタル重畳 | 伝送器の設定・診断 |

## プログラムバックアップとバッテリー交換

### バックアップ手順

1. プログラミングツール（GX Works / Sysmac Studio 等）でオンライン接続
2. PLC からプログラムを PC に読み出し（アップロード）
3. プロジェクトファイルを日付付きフォルダに保存（バージョン管理）
4. 重要設備はサーバーにも保管

!!! warning "バッテリーアラームは即対応（本ページが交換期限の正典）"
    バッテリーアラームが出たら **1 週間以内**に交換する。バッテリー切れはプログラム消失・設定パラメータ消失につながる。交換前に必ずバックアップを取る。
    **無通電で保持できる猶予時間は機種で異なる**ため、交換可否（通電のまま抜けるか）と猶予時間を機種マニュアルで確認すること。

### バッテリー交換サイクル目安

!!! warning "下表は 2026-08-03 時点の例示。選定・交換計画の根拠に使わない"
    製品シリーズ名と周期は**数年で変わります**。実機の交換周期は**その機種の取扱説明書**が唯一の正です（feedback-rules R10）。

| 機種・タイプ | 推奨交換周期 |
|------------|------------|
| 三菱 Q シリーズ | 5 年または電圧低下アラーム時 |
| 三菱 iQ-R シリーズ | 5 年（リチウム電池） |
| 安川 MP シリーズ | 5 年 |
| オムロン NJ/NX | スーパーキャパシタ方式（交換不要機種もあり） |

## 化学プラント固有：変更管理（MOC）手順

!!! danger "PLC プログラムの無断変更禁止"
    化学プラントでは PLC プログラムの変更が設備の安全機能に直結する。MOC（Management of Change）手続きなしの変更は厳禁。

### MOC ステップ

```mermaid
flowchart TD
    A[変更要求書の起票] --> B[技術評価\nリスクアセスメント]
    B --> C[承認（電気担当・安全担当）]
    C --> D[変更前バックアップ]
    D --> E[オフライン環境でテスト]
    E --> F[本番適用（停止時間調整）]
    F --> G[動作確認テスト]
    G --> H[変更記録の更新\n図面・仕様書への反映]
```

- 変更記録：日付・変更者・変更内容・確認者を記録
- 現物図面への反映：ラダー変更後は展開接続図・フロー図も更新
- 現地確認：変更後の実機で入出力動作を点対点で確認

## 根拠

### バッテリー交換期限のページ間不一致を解消（2026-08-03 是正）

本ページは「アラーム後 **1 週間以内**」、[PLC/DCS トラブル](../06-trouble/plc-dcs.md) は「**1〜2 週間以内**」と食い違っていました。トラブル側は「機種別の交換周期目安は本ページを参照」と書いており、**本ページを正典とする関係が既にできていた**ため、トラブル側を本ページの値に合わせました（R6）。

**猶予時間（無通電で保持できる時間）は機種で異なります。** 期限の数値より、**交換可否と猶予時間を機種マニュアルで確認する**ことのほうが本質です。

### 製品シリーズ名の扱い（R10）

バッテリー交換周期の表・プログラミングツール名（GX Works / Sysmac Studio 等）・アドレス表記の例（X023）は、いずれも**時点の例示**です。[メーカー選定](../04-sekkei/vendor-selection.md) で立てた方針と同じく、**時点を明示したうえで「選定・交換計画の根拠に使わない」旨の警告**を置き、実機は取扱説明書によることとしました。

### 実務慣行（規格・法令の裏付けなし）

- **予備点を各モジュールに 20 % 以上**確保する、機能別に I/O を連番でグルーピングする、アナログとデジタルを物理的に離す、といった割付設計の原則
- バックアップを日付付きフォルダで版管理し、重要設備はサーバーにも保管する運用
- MOC のステップ（起票 → 技術評価 → 承認 → 変更前バックアップ → オフラインテスト → 本番適用 → 動作確認 → 記録更新）

### 原本未照合（honest-hold）

- **ラダー命令の記号・アドレス体系はメーカーごとに異なります。** 本ページの表記は代表例で、IEC 61131-3 等の規格原本は本 Wiki では照合していません
- **通信プロトコル（CC-Link・EtherCAT・PROFINET 等）の仕様書も未照合**です。対応可否・設定値は機器の取説によってください
- **安全 PLC（セーフティ PLC）の要求事項**は機能安全の領域で、本ページでは扱いません。SIL・プルーフテストは [機能安全（SIS/SIL）](../03-keiso/sis-sil.md) が正典です

### 限界の明示

- **PLC プログラムの変更は MOC の対象**です。本ページの手順を根拠に MOC を省略しないでください
- **バッテリー交換は通電のまま行う機種があり、電源を切るとプログラムが消えます。** 必ず機種マニュアルで手順を確認してから作業してください
- 本ページは PLC の**基礎と実務**を扱います。故障時の切り分けは [PLC/DCS トラブル](../06-trouble/plc-dcs.md) が正典です
