# 調節計・記録計

## 30秒まとめ

DCS に組み込まれていない単独ループに使う単体調節計と、プロセス値の履歴を記録するペーパーレスレコーダ。設定項目が多く見落としがちな「アラームリミット」「出力リミット」「通信設定」を重点的に確認する。

---

## 単体調節計の主要設定項目

| 設定項目 | 略称 | 内容 | 典型値 |
|---------|------|------|--------|
| 入力種別 | INPUT TYPE | 4-20mA / Pt100 / K型 など | — |
| 入力スケール 下限 | IN LOW | PV の下限値 | 0.0 |
| 入力スケール 上限 | IN HIGH | PV の上限値 | 100.0 |
| 設定値 | SP | 目標値 | プロセスによる |
| 出力下限 | OUT LOW | MV の下限リミット（%） | 0.0 |
| 出力上限 | OUT HIGH | MV の上限リミット（%） | 100.0 |
| 比例帯 | PB | 比例帯（%）。100/Kp | 50〜200% |
| 積分時間 | TI | 積分時間 | 0.5〜5 min 相当 |
| 微分時間 | TD | 微分時間 | 0〜1 min 相当 |
| 警報上限 | ALM HI | 上限警報値 | — |
| 警報下限 | ALM LO | 下限警報値 | — |
| 動作方向 | ACT / DIR など（機種依存） | 逆動作（PV 上昇→出力減）/ 正動作（PV 上昇→出力増） | ループ全体で決める（下記 danger） |
| フェールセーフ | FAIL SAFE | 入力断線時の出力（0%/100%/保持） | プロセスによる |

!!! danger "動作方向（正動作/逆動作）の取り違えは正帰還＝暴走になる"
    **逆動作（Reverse）= PV が上がると出力を下げる**（蒸気弁で加熱する温度制御が典型）。
    **正動作（Direct）= PV が上がると出力を上げる**（冷却水弁で冷やす温度制御が典型）。
    取り違えると偏差を打ち消す代わりに**拡大する向き**へ出力が動き、出力は 0% か 100% に張り付きます。
    向きは調節計単体では決まらず、**制御弁の作動形・フェールポジション（FC/FO）まで含めたループ全体**で決めます
    （[制御弁](control-valve.md)参照）。設定・改造後の最初の投入では、まず MANUAL で出力を少し動かして
    PV が動く向きを確認してから AUTO に切り替えてください。
    ※メニュー名称・表記（RA/DA 等）は機種により異なるため、当該機器の取扱説明書で定義を確認すること。

!!! warning "出力リミットの設定を忘れない"
    調節計の出力リミットを適切に設定しないと、スタートアップ時に出力が100%まで行って
    弁を急開させる可能性がある。スタートアップロジックと合わせて出力上限を設定する。

!!! danger "TI / TD の単位は機種依存。取扱説明書で確認する"
    積分時間・微分時間の既定単位は**秒**と**分**のどちらもあり、積分側を「1分あたりの繰返し回数（repeats/min）」で
    与える機器もある。取り違えると整定値が 60 倍・1/60 倍ずれ、ハンチングや制御不能の直接原因になる。
    上表の典型値は「分に換算した場合の桁感」であり、単位そのものは当該機器の取扱説明書で確認すること（本Wikiでは未照合）。
    考え方は [PID制御](pid.md) を参照。

## ペーパーレスレコーダの設定

### チャンネル設定

| 設定項目 | 内容 |
|---------|------|
| 入力種別 | 4-20mA / Pt100 / 熱電対 / DI（接点） |
| スケール | 表示・記録の範囲（下限〜上限） |
| 単位 | 表示単位（℃ / kPa / m³/h 等） |
| サンプリング周期 | 記録間隔（最短値・最長値は機種による） |
| アラーム | 上上限・上限・下限・下下限の各設定 |
| フィルタ | ノイズ除去フィルタ時定数 |

### アラーム設定の推奨構成

| アラーム種別 | 設定の考え方 |
|-----------|-----------|
| 上上限 (HH) | プロセス安全上限。インターロックと連動 |
| 上限 (H) | 操業管理上限。DCS / 調節計へ通知 |
| 下限 (L) | 操業管理下限。DCS / 調節計へ通知 |
| 下下限 (LL) | プロセス安全下限。インターロックと連動 |

## データ抽出とトレンド確認

### SDカード / USBによるデータ取り出し

```
1. 記録計のメニューから「データ保存」を実行
2. SDカードまたは USB メモリにCSV形式で保存
3. PC上で専用ソフト（またはExcel）で開いてトレンドを確認
4. 異常発生時刻付近のデータを抽出して原因解析に使用
```

!!! tip "定期データバックアップ"
    ペーパーレスレコーダの内部メモリ容量は機種によって異なる（数週間〜1年）。
    内部メモリが満杯になると古いデータが上書きされる機種がある。
    トラブル解析のためにも月次・四半期でのデータバックアップを運用ルール化する。

## RS-485 / Modbus 通信設定

単体調節計をDCSや上位システムに接続する場合に使用。

### Modbus RTU 設定チェックリスト

| 設定項目 | 内容 | 注意点 |
|---------|------|--------|
| スレーブアドレス | 1〜247（重複禁止。0 はブロードキャスト用で個別機器に割り当てない） | 同一バス上で重複すると通信不能 |
| ボーレート | 9600 / 19200 / 38400 bps | 全機器で統一すること |
| データビット | 8 bit | RTU モードは 8 bit（ASCII モードは 7 bit） |
| パリティ | Even（既定）/ Odd / None | 全機器で統一すること |
| ストップビット | パリティ有り＝1／**パリティ無し＝2** | パリティ無しで 1 に設定すると繋がらない |
| 終端抵抗 | バス両端のみ 120Ω | バス中間の機器に付けない |

!!! danger "「パリティ無し」を選ぶときはストップビットを 2 にする（2026-07-30 照合）"
    MODBUS over serial line 仕様書 V1.02 は RTU の 1 文字を **11 bit**（スタート1・データ8・パリティ1・ストップ1）と定め、
    「Even parity is required, other modes ( odd parity, no parity ) may also be used」「The default parity mode must be Even parity」
    としたうえで、**"the use of no parity requires 2 stop bits"** と明記している。
    パリティ無しはパリティビットの1 bitをストップビットで埋めて 11 bit を保つ、という約束である。
    「None + ストップビット1」で設定して繋がらない事例はこれが原因のことが多い。

!!! warning "RS-485 の終端抵抗"
    RS-485 バスは両端の機器のみに終端抵抗を付ける。
    中間の機器にも付けると終端が並列に入ってバスの負荷が重くなり、信号振幅が落ちて通信エラーが多発する。
    調節計に終端抵抗スイッチが内蔵されているものは ON/OFF を確認する。

    仕様書上の終端は「150Ω（0.5 W）でもよく、バイアス（線路の偏極）を行う場合は 1 nF の直列コンデンサ付き 120Ω（0.25 W）がより良い選択」とされている。
    実務では機器内蔵の 120Ω を両端で有効化する形が一般的だが、機器がバイアスを必要とするかどうかは各機器の仕様書に記載を確認すること。

## よくあるトラブル

!!! failure "電源投入時に出力が暴れる"
    原因：ウォームアップ中の入力値不安定 / 積分ワインドアップ
    対処：電源投入後のウォームアップ時間（30秒〜2分）を待ってから AUTO に切り替える。
    スタートアップ時はまず MANUAL で安定させてから AUTO へ移行する。

!!! failure "Modbus 通信が繋がらない"
    確認順序：
    1. スレーブアドレスの重複確認
    2. ボーレート・パリティ・ストップビットの統一確認（**パリティ無しならストップビット 2**）
    3. 終端抵抗の設定確認（両端のみ）
    4. A/B 線の結線順確認（機器によって A+ / B- の定義が逆の場合あり）

## 根拠

### 本ページが正典の範囲

- **調節計の動作方向（正動作/逆動作）の定義は本ページが正典**です（正動作 = PV 上昇→出力増／逆動作 = PV 上昇→出力減。本 Wiki 内の初出）。この定義は計装分野で流通する一般定義と一致することを複数の二次資料で確認しましたが、特定の規格原本は照合していないため、条項番号は引きません。機種のメニュー名（ACT・DIR・RA/DA 等）と定義の向きは必ず当該機器の取扱説明書で確認してください。

### 一次照合済み（MODBUS over serial line 仕様書 V1.02。2026-07-30 照合）

- パリティ無しはストップビット 2（"the use of no parity requires 2 stop bits"）・既定パリティは Even・RTU の 1 文字 11 bit・終端 150Ω（0.5 W）または 1 nF 直列コンデンサ付き 120Ω（0.25 W）は、本文 danger／warning 注記のとおり仕様書本文で照合済みです。

### 二次資料で一致を確認（原本未照合）

- スレーブアドレス 1〜247・0 はブロードキャスト、という割当は同仕様書の規定として流通する値と一致することを確認しましたが、本弾（2026-08-06）ではアドレス規定の該当箇所を原本で再照合していません。

### 是正の記録（2026-08-06）

- **動作方向の設定項目が欠落**: 主要設定項目表に動作方向（正動作/逆動作）がなく、取り違えが正帰還（出力の張り付き）に直結する危険側の欠落だったため、行と danger 注記を追加しました。
- **サンプリング周期「125ms〜60min」**: 特定機種の仕様値とみられる数値を機種共通の範囲のように書いていましたが、出所を特定できないため「最短値・最長値は機種による」に改めました。

### 実務慣行（規格・法令の裏付けなし）

- PB 50〜200%・TI 0.5〜5 min・TD 0〜1 min の典型値、ウォームアップ 30 秒〜2 分、HH/H/L/LL のアラーム構成、月次・四半期のデータバックアップ運用は実務慣行の目安であり、規格・法令が定めた値ではありません。

### 原本未照合（honest-hold）

- **TI / TD の単位（秒／分／repeats per min）**は本文 danger 注記のとおり未照合です。当該機器の取扱説明書が正です。
- 設定項目の略称（INPUT TYPE・SP・ALM HI 等）は代表例で、特定機種の取扱説明書とは照合していません。
