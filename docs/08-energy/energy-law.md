# 省エネ法対応

## 30秒まとめ

省エネ法の正式名称は「エネルギーの使用の合理化及び非化石エネルギーへの転換等に関する法律」。一定規模以上の事業者にはエネルギー管理者の選任、定期報告書・中長期計画書の提出、エネルギーの計量が義務づけられる。

---

## 法律の概要

**正式名称**: エネルギーの使用の合理化及び非化石エネルギーへの転換等に関する法律（Act on the Rational Use of Energy and the Shift to Non-fossil Energy）（通称：省エネ法）

エネルギー資源の有効利用と温暖化対策を目的とし、工場・事業場でのエネルギー使用の合理化を義務付ける。
主管は**経済産業省**（資源エネルギー庁）。

!!! note "2023年4月の改称"
    2022年（令和4年）改正・2023年4月施行により、旧「エネルギーの使用の合理化等に関する法律」から現名称へ改称されました。従来の化石エネルギー使用合理化に加え、**非化石エネルギーへの転換**が新たに法の対象に加わっています。

> **化学プラントでの当てはめ**: 電気・蒸気・燃料の年間使用量が基準を超える事業者は**特定事業者**に該当します。自事業場が該当するかは、原油換算エネルギー使用量の実績で判定してください。

### 2022年改正（2023年4月施行）の主な追加事項

- **非化石エネルギーへの転換に関する目標・計画**: 特定事業者は、太陽光・風力・水素・アンモニア等の非化石エネルギー（Non-fossil Energy）への転換に関する中長期計画の作成と、非化石エネルギー使用状況の定期報告が求められます。
- **電気需要の最適化（デマンドレスポンス, Demand Response）の評価**: 従来の「電気需要の平準化」に代わる評価軸として、再生可能エネルギーの出力変動に合わせて需要をシフトする取組（上げDR・下げDR）が評価対象になりました。系統の需給ひっ迫時の需要抑制や再エネ余剰時の需要創出が、省エネの取組実績として認められます。

## 特定事業者・特定連鎖化事業者の定義

| 区分 | 基準 | 義務 |
|------|------|------|
| **特定事業者** | 工場等のエネルギー使用量が年間**原油換算1,500kL以上** | エネルギー管理統括者・管理企画推進者の選任、定期報告・中長期計画の提出 |
| **第一種エネルギー管理指定工場** | 工場単体で**原油換算3,000kL以上** | エネルギー管理士の選任（電気・熱それぞれ） |
| **第二種エネルギー管理指定工場** | 工場単体で**原油換算1,500kL以上3,000kL未満** | エネルギー管理員の選任 |

!!! danger "原油換算の 0.0258 は「GJ → kL」の係数。kWh に直接掛けない"
    **0.0258 kL は熱量 1 GJ に対する原油換算値**です（施行規則第4条）。電力量に直接掛けると桁を1つ落とします。
    正しくは**まず電力量を熱量に換算してから**原油換算します。

```text
買電（他人から供給された電気）の場合:
  1,000 kWh = 8.64 GJ        （施行規則 第4条第3項第二号）
  1 GJ      = 原油 0.0258 kL （同項）

  → 1 kWh ≒ 0.00864 GJ × 0.0258 = 0.000223 kL ≒ 0.223 L
  → 1,500 kL 相当の電力量 ≒ 1,500 ÷ 0.000223 ≒ 約 6.7 GWh

自家発電等（第4条第3項第一号）は 1,000 kWh = 3.60 GJ で換算する
```

**電気だけで見れば年間およそ 6.7 GWh** が 1,500 kL に相当します（実際は蒸気・燃料を合算して判定）。

## エネルギー管理士の選任義務と職務

### 選任要件

- **第一種指定工場**は電気担当・熱担当それぞれ1名以上のエネルギー管理士を選任
- 選任・解任は**経済産業大臣への届出**が必要（法第11条第2項）。この権限は施行令第32条第1項で**経済産業局長に委任**されており、**実際の提出先は所轄の経済産業局**です
- 兼任の可否は運用によります（下記「根拠」参照）

!!! warning "提出先は経済産業局。産業保安監督部ではありません"
    **産業保安監督部は電気事業法系の機関**（主任技術者の選任届・事故報告などの窓口）で、省エネ法の窓口ではありません。省エネ法施行令の全文に「産業保安監督部」は現れません（2026-08-03 に e-Gov 現行条文で確認）。
    定期報告書の提出先（経済産業局）と同じ系統です。混同すると届出先を誤ります。

### 主な職務

1. エネルギーの使用方法の改善・監視
2. 設備・装置の維持・管理
3. エネルギー管理に関する記録の作成・保管
4. 省エネに関する計画・目標の策定への参画
5. 定期報告書への署名（工場長との連名）

> **注意**: エネルギー管理士は「エネルギーの合理化」の監督者であり、電気主任技術者（保安監督）とは役割が異なる。兼任は資格さえあれば可能。

## 定期報告書と中長期計画書の提出

### 定期報告書

| 項目 | 内容 |
|------|------|
| 提出期限 | 毎年**7月末日** |
| 提出先 | 経済産業局（中部・近畿・関東等、所轄地域による） |
| 内容 | 前年度のエネルギー使用量・原単位・設備情報・省エネ実施状況 |
| 提出方法 | 省エネ法電子報告システム（ESIMS）経由 |

!!! warning "提出遅延・虚偽報告のペナルティは 50 万円以下の罰金"
    定期報告（法第16条第1項）の**不提出・虚偽報告は 50 万円以下の罰金**（法第175条第3号）。両罰規定（法第177条）で法人にも**同額**が科されます（法人加重はありません）。
    **100 万円以下の罰金は別の条文**（法第174条＝エネルギー管理者等の選任義務違反・命令違反）の金額です。取り違えないでください（2026-08-03 に e-Gov 現行条文で照合）。

### 中長期計画書

| 項目 | 内容 |
|------|------|
| 提出周期 | 定期報告と同じく毎年7月末（内容は5年先の計画） |
| 内容 | 省エネ投資計画・目標原単位・主要設備の更新計画 |
| 求められる目標 | 判断基準（告示）の目標＝エネルギー消費原単位または電気需要最適化評価原単位を**中長期的にみて年平均1パーセント以上低減**（「努めるものとする」＝努力目標。単年度未達が直ちに違反となるものではない） |

## 電気・熱のエネルギー計量義務

エネルギー使用量の**計量・記録**を求めているのは、法第5条第1項に基づく判断の基準となるべき事項
（平成21年3月31日 経済産業省告示第66号「工場等におけるエネルギーの使用の合理化に関する事業者の判断の基準」）です。
設備区分ごとに**管理標準**を定めたうえで、定期的に計測し、その結果を記録することが求められます。

!!! note "「省エネ法第9条」ではありません（2026-07-30 照合）"
    計量・記録の根拠としてこの条番号を挙げるのは誤りです。
    現行の省エネ法第9条が定めているのは**エネルギー管理企画推進者の選任**です（e-Gov 現行条文で確認）。

### 計量対象

- **電気**: 受電点の電力量（kWh）、主要設備の分岐電力量
- **燃料（重油・ガス等）**: 積算流量計または仕入れ伝票
- **蒸気**: 積算流量計（kg/h → GJ換算）

### 実務上のポイント

- 電力会社との**取引又は証明**に使う計量器（受電点の電力量計など）は、計量法第16条により検定に合格した特定計量器を使用する。社内の管理用サブメーターは取引・証明に使わない限り検定の対象外だが、校正・精度管理は必要
- データはPIヒストリアン等に自動収集→月次集計→定期報告書に転記
- 計量器の故障・異常時は代替計量の記録を残す

## ベンチマーク制度の概要

業種別に設定された**省エネ基準（ベンチマーク）**を達成することが求められる制度。

| 項目 | 内容 |
|------|------|
| 対象業種 | 化学工業（エチレン・アンモニア等の主要製品別） |
| 指標 | 製品1tあたりのエネルギー消費量（原油換算） |
| 目標水準 | 業界上位10%相当のエネルギー効率 |
| 未達時 | 勧告・命令・公表（罰則あり） |

> **化学工場の特徴**: 製品が多品種にわたるため、ベンチマーク対象製品を特定し、その生産に紐づくエネルギーを分離計量することが重要。

## 根拠

### 一次照合済み（e-Gov 現行条文・2026-08-03）

| 条項 | 内容 |
|---|---|
| 法 **第11条第2項**・**第12条第3項** | エネルギー管理者・管理員の選任／解任は**経済産業大臣へ届出** |
| 施行令 **第32条第1項** | 上記の大臣の権限を**経済産業局長に委任**（＝実際の提出先は所轄の経済産業局） |
| 施行令 **第2条第1項** | 特定事業者の指定基準＝原油換算 **1,500 kL**／年 |
| 施行規則 **第4条第3項第一号** | 自家発電等の電気は **1,000 kWh = 3.60 GJ** |
| 施行規則 **第4条第3項第二号** | 上記以外（買電）の電気は **1,000 kWh = 8.64 GJ** |
| 施行規則 **第4条** | 熱量 **1 GJ = 原油 0.0258 kL** |
| 法 **第175条第3号** | 定期報告（第16条第1項）の不提出・虚偽報告＝**50万円以下の罰金** |
| 法 **第177条** | 両罰規定。法人にも**各本条の罰金刑**（＝同額） |
| 法 **第174条** | **100万円以下の罰金**。選任義務違反・命令違反であって定期報告の罰則ではない |
| 法 **第178条第1号** | 選任の届出をしない／虚偽届出＝**20万円以下の過料**（罰金ではない） |

### 是正した3件（2026-08-03）

| 項目 | かつての記述 | 是正後 |
|---|---|---|
| 原油換算 | 電力 **1 kWh = 0.0258 L**、約 **58 GWh** で 1,500 kL 相当 | **0.0258 は GJ → kL の係数**。買電は 1,000 kWh = 8.64 GJ を経由して **1 kWh ≒ 0.223 L**、1,500 kL ≒ **約 6.7 GWh** |
| 選任届の提出先 | 経済産業大臣（**地方産業保安監督部**） | 経済産業大臣（**施行令第32条第1項で経済産業局長に委任**） |
| 定期報告の罰則 | **100万円**以下の罰金 | **50万円**以下の罰金（法第175条第3号）。100万円は第174条 |

**原油換算の誤りは約10倍過大**でした。「58 GWh 使っていないから特定事業者ではない」と判断すると、**該当するのに届出をしない**ことになります。原因は**単位の取り違え**（GJ あたりの係数を kWh に直接掛けた）です。

**提出先の誤りは内部矛盾でもありました。** 同じページの定期報告書の提出先は「経済産業局」と正しく書かれており、選任届だけが産業保安監督部になっていました。

なお、電気の熱量換算値には**昼間買電 9.97 GJ／夜間 9.28 GJ という旧値**が広く流通していますが、**現行の施行規則にこの区分はありません**（現行条文に該当数値は 0 件）。旧値で計算しても 1 kWh ≒ 0.257 L・1,500 kL ≒ 5.8 GWh で、いずれにせよ「58 GWh」にはなりません。

### 実務慣行・未照合（honest-hold）

- **エネルギー管理士の兼任範囲**（「工場内に限り認められる」としていた記述）は本 Wiki では条文照合していません。兼任の可否は選任区分と運用によるため、記述を弱めています
- **定期報告書の提出期限（毎年7月末日）・ESIMS の運用**は資源エネルギー庁の手引きによりますが、**手引き本文は未照合**です。様式・期限は毎年の手引きで確認してください
- **ベンチマーク制度の対象業種・目標水準（業界上位10%相当）**も未照合です。対象製品の特定と分離計量の要否は手引き・所轄に確認してください
- **2022年改正の施行時期（2023年4月）**は流通している記述に従っており、原典での確認はしていません

### 限界の明示

- **本ページの数値だけで該当判定・届出要否を決めないでください。** 原油換算は電気・燃料・蒸気を合算して行い、係数は改正され得ます
- **計量・記録の根拠は法第5条第1項に基づく判断基準（告示第66号）**であって「省エネ法第9条」ではありません（第9条はエネルギー管理企画推進者の選任）。本文の note のとおりです
- 電気主任技術者（電気事業法・保安監督）とエネルギー管理士（省エネ法・合理化）は**別制度**です。[法定業務一覧](../09-hoantokei/legal-duties.md) と混同しないでください
