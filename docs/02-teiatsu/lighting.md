# 照明・コンセント

## 30秒まとめ

化学プラントの照明で最重要は「防爆エリアの区分に合った照明器具を選ぶ」こと。LED 化は突入電流・高調波に注意が必要。非常照明は消防法と建築基準法の両方を確認する。

---

## 防爆照明の選定

### 危険場所区分と防爆構造

| 危険場所区分 | 定義 | 推奨防爆構造 |
|------------|------|------------|
| Zone 0 | 爆発性ガス雰囲気が常時存在 | Ex ia（本質安全）のみ |
| Zone 1 | 爆発性ガス雰囲気が断続的に生じる可能性 | Ex d（耐圧）、Ex e（安全増） |
| Zone 2 | 爆発性ガス雰囲気が生じる可能性が低い | Ex n（非点火型）、Ex d、Ex e |
| Zone 21/22 | 爆発性粉塵雰囲気 | Ex t（粉塵防爆型） |

!!! warning "非点火防爆構造（Ex n）は Zone 2 専用。Zone 1 には使えない"
    「ユーザーのための工場防爆設備ガイド（平成24年11月）」表1-7「電気機器の防爆構造の選定の原則」では、非点火防爆構造（**nA・nC・nR・nL**）は
    **特別危険箇所＝×／第一類危険箇所（Zone 1）＝×／第二類危険箇所（Zone 2）＝○** と明記されています（国際整合防爆指針・工場電気設備防爆指針2006 のいずれの欄でも同じ）。
    Ex n は「正常運転中は発火源となるアーク・火花を生じない」ことに依拠する構造で、**異常時の防護を前提としていない**ため、爆発性雰囲気が断続的に生じる Zone 1 では使えません。

    なお**安全増防爆構造（Ex e）は準拠指針によって適用範囲が異なります**。国際整合防爆指針によるものは第一類危険箇所で使用できますが、旧・構造規格によるものは第二類危険箇所に限定されます。機器の準拠指針を銘板で確認してください。

    （2026-07-30 に同ガイド原典PDFで逐語照合）

### 温度クラスの確認

使用する爆発性ガスの**発火温度より低い**最高表面温度の温度クラスを選定する。

| 温度クラス | 最高表面温度 | 対応ガス例 |
|-----------|------------|---------|
| T1 | 450℃ | アセチレン以外の多くのガス |
| T2 | 300℃ | エチレン、エチルエーテル |
| T3 | 200℃ | ガソリン、ヘキサン |
| T4 | 135℃ | アセトアルデヒド |
| T5 | 100℃ | （該当する代表ガスは少ない。発火温度 100〜135℃ のガスが対象） |
| T6 | 85℃ | **二硫化炭素（CS₂・発火温度 90℃・グループ IIC）** |

!!! danger "二硫化炭素は T5 ではなく T6"
    CS₂ の**発火温度は 90℃**です（工場防爆設備ガイドの物性表で確認）。T5 機器の**最高表面温度は 100℃**なので、**T5 の機器では CS₂ が着火します**。CS₂ を扱う区域には **T6（85℃）** の機器が必要です。
    温度クラスは「ガスの発火温度 > 機器の最高表面温度」を満たすように選ぶ、という関係で覚えてください。
    （2026-07-30 に原典PDFで逐語照合。同表で CS₂ は 発火温度90℃・爆発等級3・グループIIC・**T6** と分類）

!!! warning "ガスグループの確認も必須"
    グループ I（炭鉱）、グループ II（一般工業）、グループ IIC（水素・アセチレン）でガス記号が異なる。化学プラントは IIC 対応品が必要な場合がある。

## 非常照明の設置基準

### 誘導灯（消防法系）と非常用照明（建築基準法系）

| 種類 | 根拠法 | 設置場所 | 非常電源・予備電源の容量 |
|------|-------|---------|--------------|
| 誘導灯（避難口・通路） | 消防法系（消防法施行規則 第28条の3） | 避難口の上部又は直近、廊下・通路の曲り角など | 20 分間（大規模防火対象物の特定の避難口等では 60 分間） |
| 非常用照明装置 | 建築基準法系（施行令 第126条の4・第126条の5） | 特殊建築物の居室・避難経路の廊下等 | 30 分間（告示による。原本未照合） |

### 照度・設置位置の基準

- 非常用照明：**床面 1 lx 以上**（施行令第126条の5 第一号イ。直接照明とし、予備電源を設けること＝同号ハ）。**蛍光灯・LED では告示の構造方法により 2 lx 以上**とされる（告示原本未照合）ため、「1 lx あればよい」と読まない
- 誘導灯：設置位置は「避難口の上部又はその直近の避難上有効な箇所」（規則第28条の3 第3項第一号）。大きさは表示面の縦寸法で A/B/C 級に区分され、級と表示シンボルの有無で**有効範囲（歩行距離）**が決まる（同条第1項・第2項）

## LED 化の注意点

| 注意事項 | 内容 | 対策 |
|---------|------|------|
| 突入電流 | 電源投入時に定格の 10〜30 倍の電流が瞬間的に流れる | MCCB の型式選定（高速遮断型は誤動作しやすい）→ 遅延特性型を選ぶ |
| 高調波電流 | スイッチング電源から高調波が発生 | 高調波対策型 LED を選ぶ（PF ≥ 0.9）または高調波フィルタ |
| 調光時の干渉 | 位相制御調光との相性が悪い機種がある | PWM 調光対応 LED を使用、または調光方式の変更 |
| 防爆器具の代替 | LED への更新は防爆認証の再確認が必要 | 同等 Ex 認証取得済み LED 防爆灯に交換 |
| 温度特性 | 高温環境（60℃ 超）では LED 素子が早期劣化 | 高温対応型を選定、放熱設計を確認 |

!!! tip "MCCB への影響"
    多数の LED を一回路にまとめると突入電流が累積し、通常起動でも MCCB が誤動作することがある。1 回路あたり LED 照明台数を制限するか、突入電流許容値の大きい MCCB に変更する。

## コンセント容量選定と回路分け

### 容量選定

| 用途 | 推奨定格電流 | 備考 |
|------|------------|------|
| 一般コンセント（事務・照明） | 15A / 100V | ELCB 保護（30mA）付き回路 |
| 工事用・点検用コンセント | 20A / 200V | 接地付 2P+E、ELCB 保護 |
| インバータ・溶接機 | 専用回路 | 大容量負荷は専用回路・専用 MCCB |

### 回路分け原則

| 原則 | 内容 |
|------|------|
| 計装機器との分離 | 作業用コンセントと計装電源は別回路 |
| ELCB 保護 | コンセント回路には 30mA ELCB を設置 |
| 防爆エリアのコンセント | Ex 認証付きコンセント（防爆型）を使用 |
| 最大接続台数 | 1 回路（15A）に常時 6A 以上の機器を複数接続しない |

## 根拠

### 本ページが正典の範囲

誘導灯・非常用照明の法令帰属とバックアップ時間・照度は本ページが正典です（[UPS・非常電源](ups.md)・[設計標準](../04-sekkei/standards.md) は本ページを参照）。防爆構造の選定原則は本ページと [防爆](../03-keiso/explosion-proof.md) で整合を取っており、危険場所区分の定義は同ページも参照してください。

### 一次照合済みの条項号（e-Gov 法令 API 照合）

- **誘導灯の非常電源 20 分間（60 分間の例外を含む）**: 消防法施行規則（昭和36年自治省令第6号）**第28条の3 第4項第十号**「非常電源は、直交変換装置を有しない蓄電池設備によるものとし、その容量を誘導灯を有効に二十分間（消防庁長官が定める要件に該当する防火対象物の…避難口…に設けるものにあつては、六十分間）作動できる容量…以上とする」。2026-08-06 に e-Gov 法令 API で逐語照合
- **誘導灯の設置位置**: 同 **第28条の3 第3項第一号**「避難口誘導灯は、…避難口の上部又はその直近の避難上有効な箇所に設けること」。同日逐語照合
- **誘導灯の大きさと有効範囲**: 同 **第28条の3 第1項**（表示面の縦寸法による A/B/C 級の区分）・**第2項**（級・シンボル有無ごとの歩行距離、および D＝kh 式）。同日逐語照合
- **非常用照明の床面 1 lx 以上・直接照明・予備電源**: 建築基準法施行令（昭和25年政令第338号）**第126条の5 第一号イ**「照明は、直接照明とし、床面において一ルクス以上の照度を確保することができるものとすること」・**同号ハ**「予備電源を設けること」。同日逐語照合

### 二次資料で一致を確認（原本未照合）

- **非常用照明の予備電源「30 分間」**と**蛍光灯・LED の 2 lx 以上**は、施行令から委任された**告示（構造方法を定める件）**の内容とされます。告示は e-Gov 法令 API の対象外で**原本未照合**のため、告示番号は引用しません
- 防爆構造の選定原則・温度クラス表は「ユーザーのための工場防爆設備ガイド」原典 PDF で 2026-07-30 に逐語照合済み（本文の各注記のとおり。今回の照合範囲外）

### 是正の記録（2026-08-06）

- **「誘導灯：設置高さ 2.5m 以上（床面から）」を撤回**: 規則第28条の3 に設置高さの数値規定はありません（設置位置は「避難口の上部又はその直近」、細目は「通行の障害とならないように」）。条文に無い数値を法基準のように書いていたため、条文の実際の規定（設置位置・級区分・有効範囲）に置き換えました
- **「LED 式は JIS 基準による」という照度の JIS 帰属を撤回**: 非常用照明の照度の法定根拠は建築基準法施行令と告示であり、JIS への帰属は確認できませんでした。原本未照合の規格名を権威づけに使わない方針により削除
- **「30 分以上（LED 式）」の限定を撤回**: 予備電源 30 分間は光源種別によらない要求（告示由来・原本未照合）で、LED 式に限る記述は誤りです
- **見出し「消防法（誘導灯・非常用照明）」を是正**: 表の中身は消防法系（誘導灯）と建築基準法系（非常用照明）の両方で、見出しが非常用照明まで消防法に帰属させていました

### 実務慣行（規格・法令の裏付けなし）

- LED 突入電流「定格の 10〜30 倍」・高調波対策の PF ≥ 0.9・コンセント容量の推奨値（15A/100V・20A/200V）・1 回路あたりの接続制限は実務目安です
- ELCB 30mA は広く用いられる感度電流ですが、本ページでは条文根拠を引用しません（接地・漏電保護の正典は [接地（低圧）](grounding-lv.md)・[低圧配電](distribution.md)）

### 限界の明示

- 誘導灯・非常用照明の**設置義務の有無**（どの建物・どの部分に要るか）は防火対象物の用途・規模で決まり、本ページは網羅していません。所轄消防・建築主事との協議および設計事務所の法規チェックを正としてください
- 60 分間となる「消防庁長官が定める要件」の具体的範囲（告示）は未照合です
