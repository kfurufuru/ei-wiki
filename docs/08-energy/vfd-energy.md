# インバータ省エネ計算

## 30秒まとめ

管路の摩擦抵抗が支配的なポンプ・ファンでは消費電力が回転数のほぼ3乗に比例して減るため、絞り弁制御からインバータ制御への切替は大きな省エネ効果を生む。ただし**静圧（実揚程）が支配的な系では3乗則は成立しない**。導入前に実流量の変動幅と静圧の割合を確認し、常時全開運転なら効果が出ない点に注意。

---

## インバータ導入の省エネ効果

### 回転数の3乗則（ポンプ・ファンの相似則）

**管路の摩擦抵抗が支配的な系**では、ポンプ・ファンの消費電力は**回転数のほぼ3乗に比例**する（流体機械の相似則。流量は回転数の1乗、全揚程（圧力）は2乗、軸動力は3乗に比例）。静圧（実揚程・背圧）が支配的な系では成り立たない（下記 warning 参照）。

```
P₂/P₁ = (N₂/N₁)³

P₁ : 定格運転時の消費電力
P₂ : 回転数 N₂ 時の消費電力
N₁ : 定格回転数
N₂ : 変更後の回転数
```

この式が意味すること：回転数を少し下げるだけで、消費電力は急激に減少する。

!!! warning "3乗則が成り立つのは管路抵抗が支配的な系だけ"
    3乗則は「回転数を下げると運転点が相似に移動する」＝**全揚程が流量の2乗に比例する管路抵抗（摩擦損失）だけの系**が前提。
    タンクへの汲み上げ・ボイラ給水など**静圧（実揚程・背圧）が支配的な系では、回転数を下げても静圧分の動力は減らず、3乗則どおりには下がらない**（回転数を下げすぎると静圧に負けて流量ゼロになる）。
    この場合の省エネ量は、ポンプ性能曲線と実際の系統抵抗曲線から運転点を求めて評価する。

| 回転数比 N₂/N₁ | 消費電力比 P₂/P₁ | 節減率 |
|---------------|----------------|-------|
| 100%（定格）   | 100%           | 0%    |
| 90%           | 72.9%          | 27%   |
| 80%           | 51.2%          | **49%** |
| 70%           | 34.3%          | 66%   |
| 60%           | 21.6%          | 78%   |
| 50%           | 12.5%          | 88%   |

## 省エネ量計算式と計算例

### 計算式

```
年間節電量（kWh/年）= P₁ × (1 - (N₂/N₁)³) × 稼働時間（h/年）× インバータ効率補正

投資回収年数 = 設備費（円）÷ 年間節電額（円/年）
年間節電額（円/年）= 年間節電量（kWh/年）× 電力単価（円/kWh）
```

### 計算例

**条件**:
- 対象設備: 冷却水循環ポンプ（モーター定格: 75kW、稼働: 8,000h/年）
- 現状: 定格運転（75kW × 実負荷率80% = 実消費60kW）、流量は弁で絞り調整
- 変更後: インバータ導入、回転数を定格の80%で運転（流量同等確保）
- 電力単価: 15円/kWh（計算手順を示すための**仮置きの例**。試算時は自社の請求書の実額単価に置き換える）
- インバータ設備費: 200万円

**計算**:

```
現状の消費電力: P₁ = 60 kW
80%回転時の消費電力: P₂ = 60 × (0.8)³ = 60 × 0.512 = 30.7 kW

年間節電量 = (60 - 30.7) × 8,000 = 234,400 kWh/年
年間節電額 = 234,400 × 15円 = 3,516,000円/年 ≈ 352万円/年

単純回収年数 = 200万円 ÷ 352万円/年 ≈ 0.57年（約7か月）
```

> この例では約7か月で回収完了。ポンプ・ファンへのインバータ導入はROIが非常に高い案件が多い。

!!! warning "この計算例は理想条件の概算"
    絞り運転中の実消費電力（60kW）を基準に3乗則を当てはめた**理想条件の概算**であり、次の理由で実際の節電量はこれより小さくなるのが普通。稟議には保守側の値を使い、導入後に実測で検証する。

    - 静圧（実揚程・背圧）がある系では3乗則どおりに下がらない（前節の適用条件）
    - 「回転数80%で流量同等」が成り立つかは系統抵抗曲線による（現状の弁の絞り量で変わる）
    - インバータの変換損失・低速時のモーター効率低下の分が差し引かれる（次節の補正）

## 投資回収計算（簡易式）

稟議資料や上司への説明に使える**シンプルな計算シート**：

```
【インバータ省エネ簡易試算】

① モーター定格出力: ______ kW
② 現在の実負荷率: ______ %
③ 現在の実消費電力: ①×② = ______ kW
④ 目標回転数比: ______ %
⑤ 省エネ後の消費電力: ③×(④)³ = ______ kW
⑥ 節電量: ③-⑤ = ______ kW
⑦ 年間稼働時間: ______ h/年
⑧ 年間節電量: ⑥×⑦ = ______ kWh/年
⑨ 電力単価（請求書の実額）: ______ 円/kWh
⑩ 年間節電額: ⑧×⑨ = ______ 円/年
⑪ 設備費: ______ 円
⑫ 単純回収年数: ⑪÷⑩ = ______ 年
```

!!! note "インバータ自身の損失"
    インバータには変換損失（定格付近で3〜5%程度）があるため、実際の節電量は計算値より若干小さくなる。
    計算値に0.95〜0.97を乗じて保守的に見積もることを推奨。

## 絞り弁制御からインバータ制御への切替効果

### なぜ弁制御は無駄なのか

絞り弁（バルブ）でポンプ流量を制御する場合、ポンプ自体は**定格に近い電力を消費し続ける**。
余剰エネルギーはバルブの圧損（熱）として捨てられているだけ。

```
弁制御: ポンプ（高電力） → バルブ（圧損で捨てる） → 必要流量
VFD制御: ポンプ（低電力で適切な回転数） → 必要流量
```

### 効果が大きい設備の特徴

- **長時間連続稼働**（年間4,000h以上）
- **大型モーター**（22kW以上）
- **流量が変動する**（常に100%流量不要）
- **現在バルブで絞っている**（バルブ開度50%未満が常態）

### 効果が小さい・向かない設備

- 常に定格流量が必要な設備（絞る機会がない）
- 短時間の間欠運転設備（インバータの減速効果が出ない）
- 実揚程（静圧）が支配的な揚水ポンプ（位置エネルギー分は節減できない＝3乗則が成立しない）

## 導入前に確認すること

### 1. 既設モーターの電流値・負荷特性

インバータ対応モーター（絶縁強化品）でない場合、インバータの PWM スイッチングによる**急峻なサージ電圧（マイクロサージ）**が巻線絶縁を劣化させる可能性がある。ケーブルが長いほどモーター端子でのサージ電圧は高くなり、特に 400V 級で顕著。

| 確認項目 | 内容 |
|---------|------|
| モーター銘板の絶縁クラス | F種以上推奨（E種は要メーカー確認） |
| 現在の電流値（運転中） | 定格比でどの程度か把握 |
| モーター年齢 | 15年以上は更新を検討 |
| 既設ケーブル長 | 長い場合（特に400V級）はモーター端サージ電圧抑制フィルタ・出力リアクトルの追加を検討（要否の閾値はインバータメーカーの技術資料で確認） |

### 2. プロセス側の確認

| 確認項目 | 内容 |
|---------|------|
| 最低流量の確認 | キャビテーション防止の最低回転数があるか |
| 背圧・静圧の確認 | 静圧（実揚程）の割合が大きい場合は3乗則が成立せず省エネ効果が小さくなる |
| 圧力・流量の制御方式 | PID制御をインバータ速度にカスケードするか |
| 製造課との合意 | 流量変動がプロセスに影響しないか |

### 3. 電気側の確認

| 確認項目 | 内容 |
|---------|------|
| 高調波対策 | 直列リアクトル（AC/DCリアクトル）の設置要否（→[高調波対策](../01-koatsu/harmonics.md)で流出電流計算とガイドライン判定を確認） |
| 盤内スペース | インバータの寸法・発熱 |
| 通信インターフェース | MODBUSなどでのリモート制御対応 |
| 接地 | インバータは高周波漏れ電流対策で接地強化が必要な場合あり |

## 実績データの取り方

### 電力量計による測定

- インバータ設置後、入力側に**電力量計（パルス出力）**を追加して直接計測
- 設置前後で同一条件（外気温・負荷）で比較し省エネ量を確定

### PIヒストリアン活用

```
PIヒストリアン活用例:

タグ: AI-PUMP-001_KW（インバータ入力電力）
      AI-PUMP-001_FREQ（インバータ出力周波数）
      FI-PUMP-001（ポンプ流量）

トレンド比較:
  改修前期間（例: 2025年10月）の月平均電力
  vs
  改修後期間（例: 2026年10月）の月平均電力
  → 差分が省エネ量
```

!!! tip "同一季節で比較する"
    夏・冬で負荷条件が異なるため、省エネ効果の検証は**同一季節の前年比較**が基本。
    改修前にベースラインデータを必ず保存しておく。

## 根拠

### 本ページが正典の範囲

VFD（インバータ）導入による**省エネ効果の計算**（3乗則の適用と回収試算）は本ページが正典です。高調波の限度値・流出電流計算は [高調波対策](../01-koatsu/harmonics.md)、契約電力の決まり方は [デマンド管理](demand-management.md)、省エネ法の管理義務は [省エネ法対応](energy-law.md) が正典です。

### 一次計算で検算済み

流体機械の相似則（流量∝N、全揚程∝N²、軸動力∝N³）は物理の定義から導けるもので、表・グラフ・計算例をすべて再計算して確認しました（2026-08-05）。

| 項目 | 検算 |
|---|---|
| 3乗則の表 | 0.9³ = 0.729、0.8³ = 0.512、0.7³ = 0.343、0.6³ = 0.216、0.5³ = 0.125。表・SVG の6点と一致 |
| 計算例の P₂ | 60 × 0.8³ = 60 × 0.512 = 30.72 ≈ 30.7 kW |
| 年間節電量 | (60 − 30.7) × 8,000 = 29.3 × 8,000 = 234,400 kWh/年（P₂ を 30.7 に丸めてから計算。丸めずに計算すると 234,240 kWh/年で差は 0.1% 未満） |
| 年間節電額・回収 | 234,400 × 15円 = 3,516,000円/年。200万円 ÷ 351.6万円/年 = 0.569年 ≈ 6.8か月（約7か月） |

### 是正の記録（2026-08-05）

- **3乗則の適用条件を明示**: 「消費電力は回転数の3乗に比例する」を無条件に書いていましたが、これは**管路抵抗（摩擦損失）が支配的な系だけ**で成り立ちます。静圧（実揚程・背圧）が支配的な系では成立しないことを、本文・30秒まとめ・SVG の title・figcaption に追記しました
- **モーター絶縁劣化の機序の誤り**: 「インバータの高調波によりモーター絶縁が劣化」と書いていましたが、絶縁を脅かすのは PWM スイッチングによる**急峻なサージ電圧（マイクロサージ）**です（ケーブルが長いほどモーター端子電圧が高くなり、400V 級で顕著）。機序を是正しました
- **出所不明の製品名を削除**: サージ対策として挙げていた「サージ吸収器（デュ・ハック等）」の製品名は実在を確認できなかったため削除し、一般名称（モーター端サージ電圧抑制フィルタ・出力リアクトル）に置き換えました。「50m超」という一律の閾値もメーカー基準で確認するよう改めました
- **簡易試算シートの番号の混同**: ②（実負荷率%）を後段で実消費電力（kW）の意味でも使っていたため、実消費電力を③として採番し直しました
- **変換損失の数値の不整合**: 「変換損失2〜5%」と「0.95〜0.97を乗じる」が整合しないため、損失を「定格付近で3〜5%程度」に揃えました
- **計算例の性格を明示**: 絞り運転中の実測電力に3乗則を当てる概算は理想条件であり、実際の節電量はこれより小さくなるのが普通であることを警告として追加しました

### 実務慣行（規格・法令の裏付けなし）

- **電力単価 15円/kWh・設備費 200万円**は計算手順を示すための仮置きの例です。試算時は自社の請求書の実額単価とメーカー見積に置き換えてください
- 「効果が大きい設備」の目安（年間4,000h以上・22kW以上・バルブ開度50%未満）、絶縁クラス F 種以上推奨、モーター15年で更新検討、変換損失3〜5%・補正係数0.95〜0.97は、いずれも経験的な実務の目安であり、規格・法令の要求ではありません

### 原本未照合（honest-hold）

- **サージ電圧対策の要否判定の閾値**（ケーブル長・電圧クラスごとの基準）はインバータメーカーの技術資料が根拠であり、本 Wiki では原本を特定していません。機種選定時にメーカー資料で確認してください
- **インバータ対応モーター（絶縁強化品）の規格上の定義**（JEM 規格等での位置づけ）は未照合です

### 限界の明示

- 本ページの試算はすべて**単純回収年数**です（割引率・金利・保守費を考慮しません）
- 3乗則にはインバータ損失・低速域でのモーター効率低下・最低回転数制約（キャビテーション防止）を含んでいません。導入判断は概算、効果確定は導入後の実測（前節「実績データの取り方」）で行ってください
