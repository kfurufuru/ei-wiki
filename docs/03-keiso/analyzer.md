# 分析計

## 30秒まとめ

分析計はセンサが消耗品であり定期校正・電極交換が前提。サンプリングシステムの詰まりが計測値の異常原因になることが多い。防爆エリアの設置では必ず Ex 認証を確認する。

---

## pH計

### 電極の構造と原理
pH計はガラス電極（測定極）と比較電極（参照極）の電位差を計測する。

```
ガラス電極：ガラス薄膜の両側のH+濃度差に応じた電位が発生
比較電極：一定の基準電位を発生（塩化銀/塩化カリウム溶液）
計測電位差（mV）→ pH値に換算（Nernst式：59.16 mV/pH（25℃時））
```

### 2点校正手順

校正は少なくとも**2種類の標準緩衝液**を使う。

```
1. センサを純水でリンス
2. pH 7.00 緩衝液に浸漬 → ゼロ点調整（Zero Calibration）
3. pH 4.00（酸性側）または pH 9.18（アルカリ側）緩衝液に浸漬
   → スパン調整（Span Calibration）
4. スロープ値を確認（95〜105% が正常。95% 未満は劣化兆候＝洗浄・再校正を検討。
   それでも 90% 以下なら交換 → 下表「電極の寿命と管理」）
5. 校正結果を記録（日時・標準液ロット番号・スロープ値）
```

!!! note "校正器に入力するのは標準液の「ラベル値」"
    上記の pH 7.00・4.00・9.18 は市販標準液の代表的な公称値です。製品により公称値は異なり
    （中性りん酸塩系は 6.86 表記など）、温度でも変わります。校正時に入力する値は
    **使用する標準液のラベルに記載された、測定温度での値**にしてください。

!!! warning "温度補償の確認"
    pH の Nernst 勾配は温度によって変化する（25℃：59.16 mV/pH、0℃：54.20 mV/pH）。
    温度補償機能（自動：ATC 内蔵型）が有効になっていることを確認する。

### 電極の寿命と管理

| 指標 | 正常範囲 | 要交換の目安 |
|------|---------|-----------|
| スロープ | 95〜105% | 90% 以下 |
| ゼロ点 | ±20 mV | ±30 mV 超 |
| 応答時間 | 30秒以内 | 2分以上 |

## 導電率計

### 用途
- **純水の監視**（0.1〜10 μS/cm 程度）：精製水設備の水質管理。超純水は 0.1 μS/cm を下回るため、さらに低い専用レンジと温度補償が必要
- **塩分濃度・塩化物管理**（0.1〜200 mS/cm）：冷却水・廃水処理
- **濃度換算**：既知の相関式がある液体（NaCl・H₂SO₄等）は濃度に換算可能

### 測定原理
- **2電極式**：低コスト。電極汚染に弱い。低導電率向け
- **4電極式**：電極汚染の影響を低減。中〜高導電率向け
- **誘導型（トロイダル式）**：電極がプロセス液に直接触れない。腐食性・スラリーに最適

## 可燃性ガス検知器

### 接触燃焼式の原理
触媒（白金・パラジウム）を塗布した検知素子を高温に保ち、可燃性ガスが触媒上で燃焼する際の温度上昇（抵抗変化）を検出する。

| 項目 | 代表例（機種・適用規格により異なる） |
|------|------|
| 測定範囲 | 0〜100% LEL（爆発下限界） |
| 精度 | ±5% LEL 程度 |
| 応答時間 | T90 で数十秒程度 |
| 校正ガス | 既知濃度の標準ガス（イソブタン・メタン等） |

!!! danger "触媒被毒"
    シリコン化合物・鉛・硫黄化合物は触媒を被毒させ感度を低下させる。
    シリコン系消火剤・シリコン系滑剤が周辺で使用されている場合は定期的に感度確認を行う。
    被毒した検知器は感度が低下しても正常動作しているように見えるため危険。

## 有毒ガス検知器

### 電気化学式の原理
被測定ガスが電解液中の電極で酸化・還元反応を起こし、反応電流がガス濃度に比例する。

| 対象ガス | 測定範囲 | 警報設定例 |
|---------|---------|----------|
| NH₃（アンモニア） | 0〜100 ppm | 1段：25 ppm / 2段：50 ppm |
| H₂S（硫化水素） | 0〜50 ppm | 1段：5 ppm / 2段：10 ppm |
| Cl₂（塩素） | 0〜10 ppm | 1段：0.5 ppm / 2段：1 ppm |
| CO（一酸化炭素） | 0〜100 ppm | 1段：25 ppm / 2段：50 ppm |

!!! danger "上表の警報値をそのまま流用しない"
    警報設定値は法定値ではありません。事業所ごとに、対象物質の**管理濃度**（作業環境評価基準）・**許容濃度**（日本産業衛生学会等）・
    検知器の設置位置・換気条件・退避に要する時間を踏まえたリスクアセスメントで決めるものです。
    上表はあくまで設定の桁感を示す一例で、本Wikiでは個々の数値を一次資料と照合していません（honest-hold）。
    自事業所の値は、適用される規則（特定化学物質障害予防規則等）と社内基準で確認してください。

!!! note "定期交換が必要"
    電気化学式センサは電解液が消耗するため**寿命が1〜2年**。
    製造日から管理して計画交換すること。使いきりのため修理不可。

## サンプリングシステムの詰まり対策

```mermaid
flowchart LR
    A[プロセス配管] --> B[サンプル弁]
    B --> C[フィルタ/セパレータ]
    C --> D[流量計]
    D --> E[分析計センサ]
    E --> F[排出ライン]
```

| 詰まり発生箇所 | 原因 | 対策 |
|------------|------|------|
| フィルタ | 固形物・スケール堆積 | 定期洗浄・差圧監視 |
| サンプル弁 | 結晶・重合物の析出 | スチームトレース・加温 |
| 流量計 | ゲル状物の付着 | 洗浄ラインの設置 |
| 導管 | 液体の凝固・凝縮 | 保温・トレース |

## 防爆エリアでの設置注意

!!! danger "Ex 認証の確認は必須"
    危険区域に設置する分析計は以下を確認すること：

    1. **Ex 認証マーク**（TIIS、ATEX、IECEx）が機器に明記されていること
    2. **ガスグループ**（IIA/IIB/IIC）が対象可燃性ガスに適合していること
    3. **温度クラス**（T1〜T6）に対応する**最高表面温度**が、対象ガスの**発火温度より低い**こと（温度クラスは温度そのものではなく、最高表面温度の等級。対応表は[防爆照明](../02-teiatsu/lighting.md)が正典）
    4. サンプリング系の配管・継手にも区域対応の材料を使用すること

## 根拠

### 本ページが正典の範囲

- **pH 電極の寿命・スロープ判定の閾値は本ページが正典**です（スロープ 95〜105% 正常／95% 未満は劣化兆候／洗浄・再校正でも 90% 以下なら交換、ゼロ点 ±20 mV、応答 30 秒以内）。[分析計トラブル](../06-trouble/analyzer.md)側の判定値は本表の再掲で、2026-08-06 に両ページの一致を確認しました。改訂するときは本ページを先に更新してください。

### 一次計算で検算済み

- **Nernst 勾配 59.16 mV/pH（25 ℃）・54.20 mV/pH（0 ℃）**: (ln10)RT/F を R = 8.314 J/(mol·K)・F = 96485 C/mol・T = 298.15 K／273.15 K で再計算し、本文の両値と一致（2026-08-06 検算）。

### 是正の記録（2026-08-06）

- **校正手順の閾値の内部不整合**: 手順4が「95% 未満は電極劣化」とだけ書いており、同ページの電極寿命表（要交換は 90% 以下）・[分析計トラブル](../06-trouble/analyzer.md)の「95% 未満は劣化兆候、洗浄・再校正でも 90% 以下なら交換」と読み方がずれていました。3箇所を同じ2段判定（95% 未満=劣化兆候／90% 以下=交換）に統一しました。
- **frontmatter description の「DO・濃度計」**: 本ページに溶存酸素（DO）計の節は存在しません。実際の構成（pH計・導電率計・ガス検知器）に合わせて書き換えました。
- **導電率計の「純水・超純水の監視（0.1〜10 μS/cm）」**: 超純水の導電率は 0.1 μS/cm を下回るため、このレンジ表記では超純水を測れません。純水と超純水を分けて記載しました。
- **可燃性ガス検知器の性能表**: 精度 ±5% LEL・T90 ≤ 30 秒を機種共通の仕様のように断定していましたが、出典規格を一次確認できていないため「代表例（機種・適用規格により異なる）」に改めました。

### 実務慣行（規格・法令の裏付けなし）

- 電極寿命表の判定値（スロープ・ゼロ点・応答時間）、電気化学式センサの寿命 1〜2 年、導電率計のレンジ区分・方式の使い分け、サンプリング詰まり対策は、メーカー資料・実務慣行の目安であり法定値・規格値ではありません。確定値は自工場の点検基準書・メーカー取扱説明書が正です。
- 標準緩衝液の pH 7.00・4.00・9.18 は市販標準液の代表的な公称値です。校正に使う値は使用する標準液のラベル値が正です。

### 原本未照合（honest-hold）

- **可燃性ガス検知器の性能値（測定範囲 0〜100% LEL・精度 ±5% LEL・T90）が規格（JIS 等）の要求値かどうかは確認できていません**（該当規格の原本未入手）。機種の取扱説明書・検定条件を正としてください。なお「LEL の 25% 未満」という作業時管理値の例は[モータートラブル](../06-trouble/motor.md)にあるとおり法定の統一値ではありません。
- **有毒ガスの警報設定例**は本文の danger 注記のとおり一次照合していません（設定はリスクアセスメントで決める）。

### 限界の明示

- 防爆の温度クラスとガスグループの対応表は[防爆照明](../02-teiatsu/lighting.md)、防爆構造の考え方は[防爆・本安](explosion-proof.md)が正典です。本ページは確認項目の列挙にとどめています。
