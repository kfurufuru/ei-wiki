# 電圧降下計算

## 30秒まとめ

電圧降下の許容値は幹線 2% + 分岐 2% = 合計 4% 以内。電動機の始動電流（定格の 5〜8 倍）での電圧降下も別途確認し、他の設備への影響がないか確認する。太線化で電圧降下を解消するか、MCCB の位置を変えて配線を短縮するかを比較する。

---

## 三相電圧降下計算式

### 基本式（三相 3 線式）

```
e = √3 × I × (R cosθ + X sinθ) × L

e     : 線間電圧降下 [V]
I     : 電流 [A]
R     : 導体抵抗 [Ω/km]（ケーブルカタログ値、20℃ 基準）
X     : 誘導リアクタンス [Ω/km]（通常 0.07〜0.09 Ω/km）
cosθ  : 負荷力率
sinθ  : √(1 - cos²θ)
L     : 片道ケーブル長 [km]
```

### 電圧降下率

```
電圧降下率 [%] = e / V0 × 100

V0 : 基準とする公称線間電圧（本Wikiは公称電圧を分母とする）[V]
例: 200V 系統なら V0 = 200V

受電端電圧が要る場合は Vr = V0 - e として別に求める
（送り端電圧と受電端電圧は別の量。分母をどちらにするかで率の値が変わる）
```

### 計算例

**条件：** 三相 200V、負荷電流 50A、力率 0.85、CV 14sq（R = 1.34 Ω/km、X = 0.083 Ω/km）、片道 100m

```
sinθ = √(1 - 0.85²) = 0.527

e = √3 × 50 × (1.34 × 0.85 + 0.083 × 0.527) × 0.100
e = 1.732 × 50 × (1.139 + 0.044) × 0.100
e = 1.732 × 50 × 1.183 × 0.100
e = 10.2 V

電圧降下率 = 10.2 / 200 × 100 = 5.12%  → 許容値 4% 超 → 太線化が必要
```

---

## 許容値の目安

| 区分 | 許容電圧降下率 | 根拠 |
|------|-------------|------|
| 幹線（受電点〜分電盤） | 2% 以内 | 内線規程 JEAC8001 |
| 分岐（分電盤〜負荷） | 2% 以内 | 内線規程 JEAC8001 |
| 幹線 + 分岐（合計） | 4% 以内 | 上記合算 |
| 電動機始動時（瞬時） | 10〜15% 以内（他機器への影響で判断） | 実務慣行値（規格根拠の裏付けなし。下記「根拠と適用上の注意」参照） |

---

## 電動機始動時の電圧降下確認

電動機の始動時には定格電流の 5〜8 倍の電流が流れ、その間は電圧降下が急増する。

```
始動時電流 Is = In × Ks

In : 定格電流 [A]
Ks : 始動電流倍率（直入れ: 5〜8、Y-Δ: 1.7〜2.7）

始動時電圧降下 es = √3 × Is × (R cosθs + X sinθs) × L
cosθs : 始動時力率（電動機始動時: 0.3〜0.4 が目安）
```

**確認すべき事項：**

1. 始動時電圧降下により、他の電動機の運転が止まらないか（電圧 85% 以下でトリップする機器あり）
2. 計装機器・DCS の電源電圧が許容範囲内（±10%）に収まるか

## 太線化判断の基準

```mermaid
flowchart TD
    A[電圧降下率 計算] --> B{降下率 ≤ 4%?}
    B -- Yes --> C[合格]
    B -- No --> D[対策を検討]
    D --> E{ケーブル長を短縮できる?\n分電盤の位置変更等}
    E -- Yes --> F[レイアウト変更で解決]
    E -- No --> G[断面積を大きくする\n次の標準サイズに変更]
    G --> A
```

### 断面積アップと電流の関係

太線化は電圧降下を改善するが、許容電流も増える副次効果がある。反面、ケーブルコスト・重量・曲げやすさが悪化する。断面積を 1 ランク上げて再計算し、基準を満たす最小断面積を選ぶ。

| 2 sq | 9.42 |
| 3.5 sq | 5.30 |
| 5.5 sq | 3.40 |
| 8 sq | 2.36 |

## 根拠と適用上の注意

- **幹線 2%・分岐 2%（合計 4%）**：民間自主規格である**内線規程（JEAC 8001）**の規定値として広く引用される値です。法令（電気事業法・電技省令）が電圧降下率を直接規定しているわけではありません。複数の二次資料で 2026-07-30 に一致確認しましたが、**内線規程の原本は未照合**のため、本ページには節番号・版年を記載しません。
- 内線規程には「電気使用場所内の変圧器から供給される場合は幹線 3 % 以下にできる」「こう長が 60 m を超える場合の緩和（こう長区分に応じ許容値を拡大）」の規定があるとされます（同じく二次資料ベース・**原本未照合**）。本ページは最も厳しい 2% + 2% を設計基準として採用しています。緩和を適用する場合は最新版の内線規程本体で必ず確認してください。
- **電動機始動時の 10〜15%**：実務慣行値です。かつて本ページは根拠を「JEM 規格」と記載していましたが、該当する JEM 規格番号を一次確認できなかったため削除しました（2026-07-30）。実際の許容値は接続機器側の制約（電磁接触器の保持電圧、不足電圧継電器の整定、DCS・計装電源の許容変動 ±10% など）から個別に決めます。
- **計算式**：e = √3・I・(R cosθ + X sinθ)・L は送り端・受電端の電圧位相差を無視した**簡略式**です（通常の低圧配線の精度としては十分。内線規程系の簡略式も同じ近似に立ちます）。本ページの計算例の算術は 2026-07-30 に再計算で検算済みです。
- **導体抵抗 R（2026-08-02 に確定）**：上表は **JIS C 3605 が定める最大導体抵抗（20 ℃）**です。JIS 原本は有償のため未照合ですが、**同規格を関連規格として明記したメーカーカタログ3社で全サイズを照合し、一致を確認**しました（出典は下表）。かつて本ページは 14 sq を 1.32 Ω/km、選定ツールは 1.37 Ω/km としており、**どちらも3社のいずれとも一致しない出所不明の値**だったため、両方を規格値に統一しました。

    | 照合先 | 対象 | 備考 |
    |---|---|---|
    | [フジクラ・ダイヤケーブル 600V CV カタログ](https://www.fujikura-dia.co.jp/pdf/catalog/catalog-600V-CV.pdf) | 単心／2 心／3 心／4 心 | 「関連規格 JIS C 3605」「最大導体抵抗（20℃）」と明記 |
    | [矢崎エナジーシステム 物品仕様書 YESS 3131-2E1S（600V CV）](https://densen.yazaki-group.com/app/files/2021/05/spec_001.pdf) | 1〜4 心 | 付表「導体抵抗（20℃）」 |
    | [古河電工産業電線 600V CV 構造表](https://www.wirecable-sales.com/pdf/924.pdf) | 単心／2〜4 心 | 「最大導体抵抗（Ω/km）20℃」 |

    - **8 sq のみ3社が割れます**：フジクラ・古河は 2.36（導体構成 7/1.2）、矢崎は 2.34（円形圧縮）。**導体構成が違えば規格値も変わる**ため、2社一致かつ保守側の **2.36** を採用しました。他の全サイズは3社完全一致です。
    - **多心と単心は別の値です**：上表は多心（2/3/4 心）の値で、[CVT（600V CVT 仕様書）](https://www.yazaki-group.com/file/600V-CVT_%E4%BB%95%E6%A7%98%E6%9B%B8.pdf)も同値です。単心はより線の撚り込みが無いぶん約 2 % 低く、14 sq で 1.31 Ω/km です。
    - **20 ℃ の値である点に注意**：実際の運転温度では抵抗が上がります（銅の温度係数は約 0.00393 /K。CV の最高許容温度 90 ℃ では 20 ℃ 値の約 1.28 倍）。厳密な検討では運転温度での値を使ってください。

- **リアクタンス X**：本ページの計算例で使う X = 0.083 Ω/km は**実務慣行の代表値**で、規格・カタログとの照合はしていません（選定ツールは X = 0.09 Ω/km 固定）。**R と違い出所を確定できていない**ため、精算にはケーブルのカタログ値を使ってください。許容電流は [低圧ケーブル](../02-teiatsu/lv-cable.md) を参照してください。
- **始動電流倍率 5〜8 倍・始動時力率 0.3〜0.4**：一般的な誘導電動機の目安値で、機種・メーカーにより異なります。正確には銘板・データシートの拘束電流値を用いてください。
