# 校正

## 30秒まとめ

計装器の校正は「ゼロトリム → スパン調整 → 中間点確認」の順で行う。校正機器は JCSS 校正済みの標準器を使い、トレーサビリティを確保する。校正周期は「プロセス重要度 × 過去のドリフト実績」で決める。

---

## 伝送器の校正手順（圧力伝送器の例）

### 準備

- 校正機器：デッドウェイトテスター（圧力標準）またはデジタル圧力計（JCSS 校正済み）
- ループキャリブレーター（4-20mA の入出力を測定）
- 作業許可証（PTW）の取得
- DCS 側の校正モード設定（手動保持またはアラーム抑制）

### 手順書形式

```text
1. 伝送器の電源確認（24VDC ループ電源）
2. プロセスを隔離（ルートバルブ閉・ベントバルブでゼロ点確認）
3. ゼロ点確認
   - 入力：大気圧（0 Pa）
   - 出力確認：4.000mA であること（4mA = ゼロ）
   - ずれがある場合：HART ハンドヘルドで ZERO TRIM を実行
4. スパン確認
   - 入力：規定の最大圧力（例：500kPa）
   - 出力確認：20.000mA であること（20mA = スパン）
   - ずれがある場合：SPAN TRIM を実行
5. 中間点確認（任意）
   - 入力：フルスケールの 25%, 50%, 75% で出力確認
   - 各点で誤差 ± 0.5% 以内
6. DCS 指示値との確認
   - 伝送器出力 mA と DCS の表示値（工業単位）が一致すること
7. 校正記録の作成（機器番号・校正日・Before/After 値・担当者）
```

!!! warning "校正中のプロセス影響に注意"
    校正のためにプロセスを隔離する際、プロセス値が DCS で「固定値（ホールド）」になっていることを確認する。誤ってアラームが発報すると不要な操業停止につながる。

## 校正に必要な機器一覧

精度欄は**誤差の上限**（この値より誤差が小さいこと）を示します。数値は実務の目安で、規格が定めた値ではありません。

| 機器 | 用途 | 必要精度（誤差の上限） |
|------|------|---------|
| デッドウェイトテスター | 圧力の一次標準 | 0.05 % 以内 |
| デジタル圧力計 | 現場校正用圧力標準 | 0.1 % 以内（JCSS 標章付き証明書のあるもの） |
| 温浴槽（オイルバス・砂浴） | 温度伝送器・熱電対の校正 | ±0.1 ℃ 以内 |
| 基準抵抗温度計（PT100） | 温度標準器 | JCSS 標章付き証明書のあるもの |
| ループキャリブレーター | 4-20mA 信号の送出・測定 | 分解能 0.01 mA 以下 |
| HART ハンドヘルドコミュニケーター | HART 機器のパラメータ設定・校正 | — |
| 電圧標準（標準電池または基準電圧源） | 電圧計・電位差計の校正 | 0.01 % 以内 |

!!! tip "被校正器より一桁良い標準器を選ぶ"
    標準器の誤差は被校正器の許容誤差に対して十分小さい必要があります。実務では「被校正器の許容誤差の 1/3〜1/10」を選定の目安にします（これも慣行であり、規格の規定値ではありません）。

## トレーサビリティの確保

計量法が定める校正の連鎖は次の構造です（条番号は計量法。詳細は下記「根拠」参照）。

```text
国際単位系（SI）
    │
特定標準器等（第134条：経済産業大臣が指定する国家標準）
    │  特定標準器による校正等
    │  （第135条：経済産業大臣・日本電気計器検定所・指定校正機関が行う）
登録事業者＝JCSS 事業者の標準器（第143条：経済産業大臣の登録）
    │  「連鎖して段階的に」校正（第143条第2項第一号）
工場内の標準器（JCSS 標章付き証明書）
    │
現場の伝送器・測定器
```

!!! warning "NITE は連鎖の一段ではない"
    NITE（独立行政法人製品評価技術基盤機構）を「BIPM の下・JCSS の上」に置いた連鎖図が出回りますが、**計量法上、標準の連鎖の頂点は経済産業大臣が指定する特定標準器（第134条）**です。NITE は計量法では立入検査等を行う機関として規定されています（第149条第2項）。

**JCSS 標章付き証明書の確認ポイント：**

- 校正事業者名・登録番号
- 測定範囲・**不確かさ**（拡張不確かさと包含係数 k）
- **校正日**（有効期限ではありません。下記「根拠」参照）
- トレーサビリティ連鎖の記載

## 校正周期の根拠

| 根拠 | 内容 |
|------|------|
| プロセス重要度 | A ランク設備（安全系・品質保証）は 1 年以内 |
| 過去のドリフト実績 | 前回校正時のずれ量から劣化速度を推定 |
| メーカー推奨 | 機器仕様書の推奨周期を参考 |
| 安全計装（SIF）の要求 | プルーフテスト周期は PFDavg の目標から逆算する。[機能安全（SIS/SIL）](../03-keiso/sis-sil.md) が正典 |

!!! warning "計量法の定期検査は工程管理用の伝送器には及ばない"
    計量法第19条第1項の定期検査は、政令で定める**特定計量器**を「**取引又は証明**における法定計量単位による計量に使用する者」が受けるものです。工程管理用の伝送器はこれに当たらず、校正周期の法的根拠にはなりません（**受渡計量**に使う計量器は別途この対象になり得ます）。

**実務的な目安（規格・法令の規定値ではありません）：**

| 機器種別 | 標準周期 |
|---------|---------|
| 安全計装用伝送器（SIF 構成機器） | 1 年以内が多い（周期の根拠は PFDavg 計算。下記「根拠」参照） |
| プロセス管理用伝送器 | 1〜2 年 |
| 補助的な伝送器 | 2〜5 年（ドリフト実績で見直し） |

## ループ校正（現場伝送器〜DCS 表示まで一括確認）

単体の伝送器校正だけでなく、ループ全体（現場機器〜変換器〜DCS 表示）を確認するループ校正が推奨される。

```text
確認ポイント:
[現場伝送器] → [ジャンクションボックス] → [DCS アナログ入力] → [DCS 表示値]
     ↑ 標準入力印加                                                    ↑ DCS 表示確認

確認項目:
- 標準入力 0% → DCS 表示 0% に対応するか
- 標準入力 100% → DCS 表示 100% に対応するか
- アラーム設定点（例：80%）で警報が発報するか
- ケーブル断線で NAMUR NE 43 の故障信号レベルによる断線検出が動作するか
  （閾値の数値は 計装基礎 が正典）
```

## 根拠

### トレーサビリティ連鎖から NITE を外しました（2026-08-03 是正）

かつて本ページの連鎖図は「BIPM（国際度量衡局）→ NITE（製品評価技術基盤機構）→ JCSS 認定校正機関」としていましたが、**計量法にこの構造はありません**。e-Gov の計量法（平成4年法律第51号）現行条文を **2026-08-03 に逐語照合**しました。

| 条 | 内容（逐語ではなく要旨） |
|---|---|
| 第134条 | 経済産業大臣が**特定標準器**（国家標準となる計量器）を指定する |
| 第135条第1項 | **特定標準器による校正等**は、経済産業大臣・日本電気計器検定所・指定校正機関が行う |
| 第143条第1項 | 校正等の事業者は**経済産業大臣に申請して登録**を受けられる（＝JCSS 登録事業者） |
| 第143条第2項第一号 | 登録要件は、特定標準器による校正等をされた計量器に「**連鎖して段階的に**」校正された計量器を用いること |
| 第144条第1項 | 登録事業者は、経済産業省令で定める事項を記載し**標章を付した証明書**を交付できる |

**NITE（法文上は「独立行政法人製品評価技術基盤機構」）が計量法本則に現れるのは第149条第2項**（提出命令に関し、大臣が研究所または機構に検査を行わせた場合）で、標準の連鎖の一段としてではありません。「研究所」は国立研究開発法人産業技術総合研究所を指します（第122条第2項第二号の定義）。

### 「校正有効期限（通常 1 年）」を「校正日」に是正

計量法**第144条第1項が定めるのは証明書の交付**であり、記載事項は経済産業省令に委任されています。**法律の条文に校正証明書の有効期限を定める規定はありません**。有効期間の定めがあるのは基準器検査証印（第104条第2項）で、これは基準器検査という別制度です。

したがって「証書に書かれた有効期限が切れたら使えない」ではなく、**次の校正までの間隔は使用者が決めて管理する事項**です。1 年はその管理でよく採られる値にすぎません。

### IEC 61511 の「1 年要求」という帰属を撤回

かつて本ページは安全計装用伝送器の周期を「1 年以内（IEC 61511 要求）」としていましたが、**IEC 61511 の原本を本 Wiki では入手・照合していません**。プルーフテスト周期は本来 PFDavg ≈ (λDU × T) / 2 の関係から目標 PFDavg を満たすように決めるもので、周期の根拠は規格の固定値ではなく検証計算です（[機能安全（SIS/SIL）](../03-keiso/sis-sil.md) が正典）。

### 精度欄の「以上」を「以内」に是正

校正機器一覧の必要精度を「0.05 % 以上」等と書いていましたが、精度（誤差）は**小さいほど良い**ため、要求は上限で書くのが正しい表現です。「0.05 % 以上」は「誤差が 0.05 % より大きくてよい」と読め、意味が逆になります。「以内」に統一し、列見出しにも誤差の上限であることを明記しました。

### 実務慣行（規格・法令の裏付けなし）

- 校正周期 1 年 / 1〜2 年 / 2〜5 年の区分、A/B/C ランクとの対応
- 中間点確認の誤差 ± 0.5 % 以内、標準器を被校正器の許容誤差の 1/3〜1/10 に選ぶ考え方
- ゼロトリム → スパントリム → 中間点確認という順序
- 校正記録の記載項目（機器番号・校正日・Before/After・担当者）

### 原本未照合（honest-hold）

- **計量法施行令・施行規則（証明書の記載事項、定期検査の対象となる特定計量器の指定）は未照合**です。本ページは法律の条文までを根拠にしています
- **IEC 61511・ISO/IEC 17025 は有償規格で未照合**。第143条第2項第二号がいう「国際標準化機構及び国際電気標準会議が定めた校正を行う機関に関する基準」は条文の文言どおりに引用しており、具体の規格番号は本 Wiki では特定していません
- **高圧ガス保安法側の定期自主検査・保安検査が計装機器の校正周期を直接定めるか**は未照合のため、校正周期の根拠表から外しました

### 限界の明示

- 本ページは圧力伝送器を例にした一般手順です。**実際の校正手順・判定値は機器の取扱説明書と社内の校正基準書**によってください
- 校正の可否・バイパスの扱いは運転部門との調整事項です（[他部門調整ノウハウ](coordination.md)）
