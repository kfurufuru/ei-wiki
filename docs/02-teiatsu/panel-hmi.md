# 操作盤・表示灯

## 30秒まとめ

操作ボタンと表示灯の色は JIS / IEC 規格で決まっている。非常停止は赤（キノコ型）、起動は白または緑が基本。HMI 画面はアラームを画面上部・左側に配置し、重要情報が埋もれない設計にする。防爆エリアの操作機器は Ex 認証品を使用する。

---

## 操作ボタン配色規格

| 操作 | 色 | 規格の規定 |
|------|----|-----------|
| 起動・始動 | 白が最適（灰・黒・緑も可） | JIS C 0448:1997 6.1.3 は白・灰・黒のうち「最も適切な色は白」。JIS B 9960-1:2019 10.2.1 は白・灰・黒・緑が望ましく白が一番よい。**赤を用いてはならない** |
| 停止 | 黒が最適（灰・白も可） | JIS B 9960-1:2019 10.2.1（黒が一番よい）。**緑は停止に使用禁止**。赤は許容されるが非常用操作機器の近くでは推奨されない |
| 非常停止 | 赤（キノコ型ヘッド）＋黄色背景プレート | JIS B 9960-1:2019 10.2.1（赤＋黄背景の組合せは非常操作機器専用）。機器の製品規格は IEC 60947-5-5（機械的ラッチ付き非常停止機器） |
| リセット | 青・白・灰・黒のいずれか | JIS B 9960-1:2019 10.2.1 |
| 異常時の介入（自動サイクルの中断など） | 黄 | JIS B 9960-1:2019 10.2.1（黄は異常状態用に確保） |

!!! info "色より先に、非常停止は「機能」の要件を満たすこと（無償の一次資料あり）"
    上表の色は有償の JIS に依る記述で**原本未照合**です（下記「根拠」）。一方、**非常停止装置に求められる機能**は、厚生労働省の[機械の包括的な安全基準に関する指針](https://www.mhlw.go.jp/content/11300000/001408310.pdf)（労働安全衛生法第28条の2第1項に基づく調査の指針）**別表第4「付加保護方策の方法」1** に無償で公開されており、2026-09-19 に原典 PDF で照合しました。

    | # | 指針 別表第4-1 の要件 |
    |---|---|
    | (1) | **明瞭に視認**でき、かつ**直ちに操作可能な位置**に、必要な個数設けられていること |
    | (2) | 操作されたとき、機械の**すべての運転モードで他の機能よりも優先**して実行され、リスクの増加を生じることなく、**可能な限り速やかに**停止できること |
    | (3) | **解除されるまで停止命令を維持**すること |
    | (4) | **定められた解除操作が行われたときに限り**、解除が可能であること |
    | (5) | **解除されても、それにより直ちに再起動することがない**こと |

    **色と形状が正しくても (3)〜(5) を満たさなければ非常停止にはなりません。** 手を離すと復帰してしまう押しボタンや、解除操作と同時に再起動する回路は、赤いキノコ型でも要件を外します。盤の受入時は配色と併せてここを確認してください（機械的ラッチと復帰の要件は [制御回路](control-circuit.md) が正典です）。

    同指針 別表第4 は**色については規定していません**（2026-09-19 に全文検索で確認）。色の根拠は上表のとおり JIS 側にあります。

!!! warning "「起動=白」は現行規格にすでにある規定（緑は許容）"
    「起動ボタンは白」は現行の JIS C 0448:1997 の 6.1.3 にすでにある規定です（望ましい色は白・灰・黒で、最も適切なのは白。緑はこの項の望ましい色に入っていません）。機械の電気装置では JIS B 9960-1:2019（IEC 60204-1:2016 対応）10.2.1 が白・灰・黒・緑を許容しつつ「白が一番よい」とし、起動への赤の使用を禁じています。緑の起動ボタンは表示灯の緑（正常・運転中）と紛れやすいため、新設では白を第一候補にし、既設設備との統一性を優先する場合は現場の基準に合わせます。なお、かつて本ページが根拠としていた「JIS C 0448:2011」という版は存在しません（JSA カタログでは 1997 年制定版が現行。下記「根拠」参照）。

## 表示灯の色規格（JIS C 0448 / IEC 60073）

| 色 | 意味 | 典型的な用途 |
|----|------|------------|
| 赤 | 危険・警告・停止 | 異常・故障・非常停止動作中 |
| 黄（アンバー） | 注意・警戒 | 警告（軽度の異常）・予備加熱中 |
| 緑 | 正常・安全 | 運転中・電源 ON・弁開 |
| 青 | 強制・特定状態 | 遠隔モード中・手動選択中 |
| 白 | 電源・一般状態 | 電源投入中・その他 |

```text
典型的な表示灯配置（ポンプ操作盤）:
[電源 白] [運転中 緑] [停止中 白] [異常 赤点滅] [遠隔 青]
```

!!! note "「停止中=赤」の現場慣行と規格の割当は別物"
    上表の規格上の意味では、赤の表示灯は「危険・異常」であり、単なる停止状態への赤の使用は本来の割当ではありません。一方、国内の受変電盤などには「入=赤・切=緑」（通電中=危険の意）という逆向きの慣行も広く残っています（この慣行の規格根拠番号は未確認）。同一現場に両方の流儀が混在すると誤認のもとになるため、盤の凡例（レジェンド）を必ず確認し、新設では規格の割当に揃えます。

## タッチパネル HMI 画面設計のポイント

### 優先度別配置原則

| 優先度 | 情報種別 | 推奨配置 |
|--------|---------|---------|
| 最高 | アラーム・異常 | 画面上部または常時表示エリア |
| 高 | 主要プロセス値（温度・圧力・流量） | 画面中央・大きな数値で表示 |
| 中 | 弁・機器の開閉状態 | プロセスフローに沿って配置 |
| 低 | 設定値・パラメータ | サブ画面に移動 |

### 設計チェックポイント

| 項目 | 基準 |
|------|------|
| 数値の視認性 | 最小文字サイズ 14pt 以上（現場の明るさを考慮） |
| 色だけで状態を区別しない | 色覚異常者への配慮：形・記号も使う |
| タッチターゲットサイズ | 最小 10mm × 10mm（作業用手袋着用を考慮） |
| アラームの優先付け | 設備重要度 A/B/C に連動したアラームレベル設定 |
| 操作確認ダイアログ | 重要操作（起動・停止）は確認ポップアップを挿入 |

## IP 等級の選定

| 設置環境 | 推奨 IP 等級 | 根拠 |
|---------|------------|------|
| 屋内・乾燥 | IP42 以上 | 異物・水滴の侵入防止 |
| 屋外（雨ざらし） | IP65 以上 | 粉塵完全遮断・水噴流 |
| 腐食雰囲気（化学プラント） | IP55〜IP65 | SUS 製エンクロージャ推奨 |
| 洗浄あり（食品・薬品） | IP66〜IP69K | 高圧洗浄水への耐水 |
| 水没可能性 | IP67〜IP68 | 水中浸漬 |

IP 表記の読み方：`IP X Y`

- X（第 1 特性数字）: 固体異物・粉塵に対する保護（0〜6）
- Y（第 2 特性数字）: 水に対する保護（0〜9）
- 「IP69K」の「K」付き表記は IEC/JIS の IP コード体系ではなく、自動車分野の規格（ISO 20653）由来とされる表記です（海外製機器のカタログで見かける。原本未照合）

IP コードの規格番号は 2026 年に JIS C 0920 → JIS C 60529 へ移行し、高温高圧水噴流に対する IPX9 が追加されました。経緯と新旧番号の読み替えは [電気計装工事で押さえるJIS規格](../03-keiso/jis-standards.md) を参照してください。

## 化学プラント固有：防爆エリアの操作機器

!!! danger "防爆エリアでは Ex 認証品を使用"
    危険場所（Zone 0/1/2、グループ II）に設置する操作機器・表示灯は防爆認証（Ex 認証）品を使用すること。認証なし機器の設置は法令違反（電技解釈第 176 条・労働安全衛生規則第 280 条等。法令の委任関係は [規格・法規](../04-sekkei/standards.md) を参照）。

| 防爆構造 | 記号 | 特徴 | 適用 Zone |
|---------|------|------|----------|
| 耐圧防爆 | Ex d | 爆発を盤内に封じ込める | Zone 1, 2 |
| 安全増防爆 | Ex e | スパーク・高温部なし | Zone 1, 2 |
| 本質安全防爆 | Ex ia/ib | エネルギー制限 | ia: Zone 0/1/2、ib: Zone 1/2 |
| 粉塵防爆 | Ex t | 粉塵爆発環境 | Zone 21, 22 |

**機器選定時の確認事項：**

1. 危険場所の区分（Zone 0/1/2）と温度クラス（T1〜T6）を確認
2. 機器の Ex 認証証書（ATEX / JIS C 60079）を入手
3. 設置後は「危険場所設置記録」に登録
4. メンテナンス時は Ex 認証品と同等品でのみ交換

## セキュリティで見るところ

!!! note "盤を開けたときに見るもの"
    - **空きLANポート**に何か刺さっていないか
    - 用途不明の**USBメモリ・LANケーブル**、**後付けの無線AP・モバイルルータ・変換器**
    - 見つけても**その場で抜かないこと**。現に制御に使われていれば停止・誤動作します。写真を撮って用途を確認してから処置します

    → 7場面の全体は [制御セキュリティの現場チェック](../10-safety/ot-security.md) を参照してください。

## 根拠と適用上の注意

- **押しボタンの色**: JIS C 0448:1997「表示装置（表示部）及び操作機器（操作部）のための色及び補助手段に関する規準」（IEC 60073:1991 対応）6.1.3（始動／オンは白・灰・黒が好ましく、最も適切な色は白）と、JIS B 9960-1:2019「機械類の安全性－機械の電気装置－第1部」（IEC 60204-1:2016 対応）10.2.1（起動=白・灰・黒・緑が望ましく白が一番よい・赤禁止／停止=黒・灰・白が望ましく黒が一番よい・緑禁止・赤は許容だが非常用操作機器の近くでは非推奨／非常停止=赤＋背後は黄・この組合せは非常操作機器専用／リセット=青・白・灰・黒／黄は異常状態用）。いずれも**原本未照合・二次資料のみ**です（2026-08-01 の確認は非公式な全文転載サイトによるもので、出典として扱いません。条項番号・文言は JSA 発行の原本で確認してから引用してください）。
- **「JIS C 0448:2011」の是正**: かつて本ページは起動=白の根拠を「JIS C 0448:2011」としていましたが、**この版年は存在しません**。JSA カタログ（2026-08-01 確認）では JIS C 0448 は 1997-11-20 制定・2023-10-20 確認が現行で、2011 年版はありません。起動=白の規定は 1997 年版 6.1.3 に最初からあるものです。
- **表示灯の色の意味**: JIS C 0448:1997 表4（安全関連: 赤=危険・黄=注意・緑=安全・青=強制・白/灰/黒=特定の意味なし）・表5（工程状態: 赤=非常・黄=異常・緑=正常）。**原本未照合・二次資料のみ**（表番号は原本で未確認。以前の確認は非公式な全文転載サイトによるもので、出典として扱いません）。
- **非常停止機器**: IEC 60947-5-5（機械的ラッチ付き非常停止機器）は規格番号・主題を二次資料で確認したのみで、原本未照合です。本文に同規格の個別数値は書いていません。
- **防爆の Zone 適用**: 防爆構造と Zone の対応の正典は [防爆](../03-keiso/explosion-proof.md)（ia=Zone 0/1/2・ib=Zone 1/2 の区別を含む）。法令の委任関係（消防法→危険物政令→電気工作物に係る法令、電技解釈第 176 条・安衛則第 280 条）の正典は [規格・法規](../04-sekkei/standards.md)。
- **限界の明示**: HMI 画面設計の数値（文字サイズ 14pt・タッチターゲット 10 mm 角など）と IP 等級選定表は規格の規定値ではなく設計目安です。「IP69K」の由来（ISO 20653）は二次資料によるもので原本未照合。「入=赤・切=緑」の受変電盤慣行は広く知られた実務慣行であり、規格根拠番号は未確認です。調達仕様・安全設計に使う際は最新版の規格本文を確認してください。
- **非常停止の機能要件**: 厚生労働省「機械の包括的な安全基準に関する指針」別表第4「付加保護方策の方法」1 の (1)〜(5)。[原典 PDF](https://www.mhlw.go.jp/content/11300000/001408310.pdf) で **2026-09-19 に逐語照合**しました。同指針は労働安全衛生法第28条の2第1項に基づく危険性等の調査の指針であり、**無償で公開されています**。**同別表は色については規定していません**（同日に全文検索で確認）。配色の根拠は上表のとおり有償の JIS 側にあり、原本未照合のままです

照合日: 2026-09-19（非常停止の機能要件を厚労省指針の原典 PDF で照合。配色の JIS〔C 0448・B 9960-1〕は有償・原本未照合のまま変わらず）。
