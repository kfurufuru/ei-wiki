# 定期点検

## 30秒まとめ

高圧設備の年次点検は、電気事業法第42条第1項に基づき自事業場で定める**保安規程**により実施する（「年1回」の頻度・点検項目は法定値ではなく保安規程で決まる。詳細は下記「根拠」）。低圧・計装は月次の外観・動作確認が基本。点検結果は数値で記録し「前回比」でトレンド管理することが早期異常検出の鍵。

---

## 高圧設備の年次点検項目（停電時）

| 点検項目 | 方法 | 判定基準 |
|---------|------|---------|
| 絶縁抵抗測定（変圧器・ケーブル） | 5000V メガー（高圧 6.6kV 機器） | 判定は絶対値でなくトレンド管理（前回比の急低下に注意）。基準は[絶縁管理](insulation-management.md)を参照 |
| VCB 動作試験 | 操作機構の投入・開放動作確認 | 正常動作、動作時間は仕様値以内 |
| VCB 接触抵抗測定 | マイクロオームメーター | 初期値から 50% 以上増加で要検討 |
| DS（断路器）目視確認 | 接触部の変色・損傷確認 | 変色・溶損なし |
| 保護継電器動作試験 | 継電器試験器での注入試験 | 設定値どおりに動作 |
| 変圧器絶縁油劣化確認 | 絶縁油採取・試験 | 絶縁破壊電圧 30kV 以上 |
| 接地抵抗測定 | 接地抵抗計 | A 種: 10Ω以下、D 種: 100Ω以下 <!-- lint-ok: 20260710-dshu-setchi-10ohm A種10Ω・D種100Ωの正しい対照 --> |
| 端子の増し締め | トルクレンチ | 規定トルクで締め付け確認 |
| 盤内清掃 | ブロワー・ウエス | 粉塵・異物なし |

## 高圧設備の年次点検項目（活線時）

| 点検項目 | 方法 | 判定基準 |
|---------|------|---------|
| 負荷電流測定 | クランプメーター | 定格電流の 80% 以下 |
| 温度測定（接続部） | 放射温度計・熱電対 | 外気温 + 40℃ 以下（目安） |
| 異音・異臭確認 | 聴診器・嗅覚 | 異常音・焦げ臭なし |
| 計器類の指示確認 | 目視 | 電圧計・電流計の指示が正常範囲 |

!!! warning "活線作業は電気主任技術者の監督下で実施"
    高圧活線での作業は感電・フラッシュオーバーのリスクがある。絶縁保護具（絶縁手袋・絶縁長靴・絶縁工具）を着用し、必ず 2 名以上で作業する。

## 低圧・計装の月次点検項目

| 点検項目 | 確認内容 | 記録方法 |
|---------|---------|---------|
| 制御盤・MCC 外観 | 異音・異臭・過熱・警報ランプ | 目視確認記録 |
| 負荷電流確認 | クランプメーターで主回路電流測定 | 数値記録（トレンド管理） |
| UPS 状態確認 | 充電電圧・バッテリー警報 | UPS 表示値を記録 |
| 計装機器ゼロ確認 | 主要伝送器の指示値確認 | DCS 値と現場指示値の比較 |
| 接続箱外観 | 水の侵入・腐食・シールの状態 | 目視確認記録 |
| 回転機（電動機）運転確認 | 電流・振動・温度の測定 | 数値記録 |

## 定期修理時の重点点検項目

| 作業 | 内容 | 頻度 |
|------|------|------|
| 計装全校正 | ゼロ・スパン校正、ループ校正 | T/A ごと（1〜5 年） |
| 制御弁分解点検 | パッキン・シート・プラグの交換 | T/A ごと |
| リレー・サーマル交換 | 動作回数・年数による計画交換 | T/A ごと |
| PLC バッテリー確認 | 電圧確認・必要に応じ交換 | T/A ごと |
| 安全計装（SIS）機能テスト | 緊急遮断弁の動作テスト（プルーフテスト） | T/A ごとが実務慣行。周期そのものは SIL 計算のプルーフテスト周期で決まる（[SIS・SIL](../03-keiso/sis-sil.md)） |

---

## 点検結果の判定基準

| 判定 | 基準 | 対応 |
|------|------|------|
| 良 | 前回値との差が ±10% 以内かつ基準値以内 | 次回点検まで経過観察 |
| 要注意 | 前回値から 10〜50% 変化、または基準値の 50〜80% | 短縮点検（3〜6 ヶ月以内に再測定） |
| 要修理 | 基準値を超えた、または前回値から 50% 以上変化 | 早急に対処・計画修理 |

## 高圧ガス保安法の自主検査記録の書き方

### 記録に必要な項目

| 項目 | 記載内容 |
|------|---------|
| 検査対象設備 | 設備名・設備番号・設置場所 |
| 検査年月日 | 実施日時 |
| 検査実施者・監督者 | 実施者の氏名と、検査の実施について**監督を行った保安係員**（特定高圧ガス消費者では取扱主任者）の氏名。監督者の氏名は法定記載事項（一般高圧ガス保安規則 第83条第5項第四号） |
| 検査方法 | 使用した測定器・試験方法 |
| 検査結果 | 測定値・合否判定 |
| 指摘事項 | 異常があった場合の内容と対処方法 |
| 確認者 | 保安担当責任者の署名 |

法定の記載事項は上表のうち「検査をしたガス設備」「設備ごとの検査の方法・結果」「検査年月日」「監督を行った保安係員等の氏名」の4つ（一般高圧ガス保安規則 第83条第5項）。指摘事項・確認者サインの欄は記録の実効性を高めるための社内上乗せです。

**保存期間**: 高圧ガス保安法第35条の2は検査記録の作成・**保存**を義務付けていますが、**保存期間の数値は法にも一般高圧ガス保安規則にもありません**。何年保存するかは保安規程・社内規定で定めます（帳簿の異常時記録の保存期間〔記載の日から10年間＝一般則第95条〕と揃える運用が実務的な目安）。

## 根拠

### 法令に基づく事項（e-Gov 現行条文で 2026-08-01 に逐語照合）

- **年次点検の法的位置づけ**: 電気事業法（昭和39年法律第170号）**第42条第1項**が保安規程の作成・届出・遵守を義務付け、電気事業法施行規則**第50条第3項**が保安規程に定めるべき事項として巡視・点検・検査を挙げています。**電気事業法に「年次点検」「年1回」を直接定める条文はありません**——頻度・項目は自事業場の保安規程で決まります（保安規程の制度と点検頻度の性格は [保安規程の管理](../09-hoantokei/hoan-kisoku.md)・[法定義務一覧](../09-hoantokei/legal-duties.md) が正典）。かつて本ページは「年次点検は電気事業法に基づく義務」と直接帰属で書いていましたが、法定なのは保安規程の作成・遵守であり点検頻度は保安規程で定める事項のため、2026-08-01 に是正しました。
- **高圧ガスの定期自主検査**: 高圧ガス保安法（昭和26年法律第204号）**第35条の2**が定期自主検査の実施と検査記録の作成・保存を義務付け、一般高圧ガス保安規則（昭和41年通商産業省令第53号）**第83条**が、頻度（**第3項: 1年に1回以上**。経済産業大臣が定める設備・施設は別に定める期間）、監督体制（**第4項: 選任した保安係員**〔特定高圧ガス消費者は取扱主任者〕に監督を行わせる）、記録の法定記載事項（**第5項**: 検査をしたガス設備・設備ごとの検査の方法及び結果・検査年月日・監督を行った保安係員等の氏名）を定めています。電磁的方法による保存も認められます（第83条の2）。
- **検査記録の保存期間は法定されていない**: かつて本ページは「保存期間：10 年以上（高圧ガス保安法施行規則による）」としていましたが、**「高圧ガス保安法施行規則」という名称の省令は存在せず**（同法の下位省令は一般高圧ガス保安規則等）、法第35条の2にも一般則第83条にも保存期間の数値はないため、2026-08-01 に是正しました。「10年」は**帳簿**の保存期間（法第60条第1項→一般則第95条: 製造施設に異常があった場合の記録は記載の日から10年間。正典は [トラブルシューティングの基本](../06-trouble/basics.md) の根拠節）との混同とみられます。

### 実務慣行・メーカー目安（法定・規格値ではない）

- 年次・月次の点検項目表そのもの、負荷電流「定格の 80 % 以下」、接続部温度「外気温 + 40 ℃ 以下」、VCB 接触抵抗「初期値から 50 % 増で要検討」、判定基準表（前回比 ±10 % 等）、T/A 周期（1〜5 年）は、いずれも実務慣行・メーカー整備基準の目安であり、法令・JIS の規定値ではありません。
- 絶縁油の「絶縁破壊電圧 30 kV 以上」は保守判定の実務目安です。試験方法・判定値とも規格原本との照合は行っていません（honest hold）。
- 6.6 kV 機器への「5000 V メガー」は実務慣行の選定です。絶縁抵抗計の電圧選定と判定は [絶縁管理](insulation-management.md) が正典です。

### 照合の限界

- 高圧ガスの下位規則は施設区分で異なります。本ページで照合したのは**一般高圧ガス保安規則のみ**で、適用規則が異なる施設（液化石油ガス・冷凍等）では頻度・記載事項が異なり得ます。自社の適用規則と保安規程で確認してください。
