# 圧力計測

## 30秒まとめ

圧力の種類（ゲージ/絶対/差圧/封圧）を正確に区別することが選定の出発点。ダイヤフラム式が現場標準。高粘度・スラリー・腐食性・高温プロセスにはダイヤフラムシール付きが必須。

---

## 圧力の種類と定義

| 種別 | 定義 | 単位表記 | 用途例 |
|------|------|---------|--------|
| ゲージ圧 | 大気圧を基準（大気圧=0） | MPaG / kPaG | 配管内圧力・タンク圧 |
| 絶対圧 | 完全真空を基準（真空=0） | MPaA / kPaA | 真空系・蒸気圧 |
| 差圧 | 2点間の圧力差 | MPaD / kPaD | 流量計・液位計測 |
| 封圧（シールドゲージ圧） | 基準室を封止した固定基準（大気圧変動に追従しない） | — | 高圧レンジ等で大気圧変動の影響を避けたい用途 |

なお、**ダイヤフラムシール（リモートシール）は圧力の種別ではなく接液部の方式**です（下記「ダイヤフラムシールが必要な条件」参照）。「封圧＝ダイヤフラムシール付き」ではありません。

!!! tip "ゲージ圧と絶対圧の換算"
    絶対圧 = ゲージ圧 + 大気圧。標準大気圧は 101.325 kPa（= 0.101325 MPa）の定義値で、実際の大気圧は天候・標高で変動します。
    例：ゲージ圧0.5 MPaG ≒ 絶対圧0.601 MPaA（0.5 + 0.101325 = 0.601325）

---

## ダイヤフラム式伝送器の選定

### 測定範囲の選び方
- 定常運転圧力がスパンの**30〜80%**に入るよう選定する
- 過圧条件（スタートアップ・異常時）を考慮してオーバーレンジ保護を確認する

### 材質選定

| プロセス流体 | ダイヤフラム材質 | 備考 |
|------------|---------------|------|
| 一般液体・水蒸気 | SUS316L | 標準選定 |
| 塩素・塩酸 | ハステロイC-276 | — |
| フッ酸・強酸化性 | タンタル | — |
| 海水・塩水 | ハステロイC-276 | — |
| 高温蒸気（200℃超） | SUS316L＋ダイヤフラムシール | — |

### プロセス接続形式

| 形式 | 特徴 | 用途 |
|------|------|------|
| ねじ込み接続（1/2 NPT等） | 汎用・低コスト | 一般配管 |
| フランジ（JIS 10K/20K等） | 高圧・大口径対応 | 蒸気・高圧系 |
| フラッシュダイヤフラム | 詰まり防止 | スラリー・高粘度 |

---

## ダイヤフラムシールが必要な条件

以下のいずれかに該当する場合はダイヤフラムシール（キャピラリー型）付きを選定する。

| 条件 | 理由 |
|------|------|
| 高粘度流体（スラリー・ペースト） | 導圧管が詰まる |
| 腐食性流体（酸・アルカリ） | 伝送器ダイヤフラムが腐食 |
| 高温流体（120℃超の目安） | 伝送器本体の接液部・封入液の耐熱上限を超える（シール＋キャピラリーで高温部から距離を取る） |
| 固形物が混入する流体 | 導圧管に固形物が堆積する |
| 凝固・結晶化しやすい流体 | 導圧管が閉塞する |

!!! warning "ダイヤフラムシールの注意点"
    キャピラリー内にはシリコンオイルまたはフッ素系オイルが封入されている。
    オイルの熱膨張がゼロ点ドリフトの原因になるため、長い導管は避ける。
    キャピラリー長の目安：片側 3 m 程度まで（応答遅れ・温度影響とのトレードオフ。上限はメーカー・封入液で異なる）。

## ゼロ点調整手順（ゼロトリム）

!!! note "実施タイミング"
    設置後・修理後・定期点検時に実施する。現場でのゼロトリムは設備停止不要で実施できる場合が多い。

```text
手順:
1. 大気開放またはゼロ点基準圧力を印加（弁操作で実施）
2. ループキャリブレータ（または HART コミュニケータ）を接続
3. "Zero Trim" または "Lower Trim" コマンドを実行
4. 4.000 mA になることを確認（レンジ下限値 LRV = 0 のゲージ圧レンジの場合）
5. 実施記録（実施日・実施者・調整量）を残す
```

!!! danger "絶対圧伝送器を大気開放でゼロトリムしない"
    絶対圧伝送器の大気開放時の正しい指示は「ゼロ」ではなく大気圧（約 101 kPa abs）です。
    ここで Zero Trim を実行すると約 0.1 MPa 分ずれた誤校正になります。
    絶対圧のロワートリムは基準真空または基準圧力発生器で行ってください。

## 過圧保護

### スナッバー（Snubber、脈動吸収）
導圧管の途中に取り付けるオリフィス状の絞り。急激な圧力パルス（ウォーターハンマー・ポンプ脈動）から伝送器を保護する。

- 液体系：ピストン型スナッバー（脈動吸収）

### サイフォン（Siphon、サイホン管／ピッグテール）
蒸気系で使う U 字またはコイル状の管。管内に凝縮水（結露水）を溜めてウォーターシールを形成し、
高温の蒸気が伝送器のダイヤフラムに直接触れないよう保護する。脈動吸収のスナッバーとは目的が異なる別部品です。

- 蒸気系：サイフォン（ピッグテール）で凝縮水シールを形成し、伝送器を高温から保護

### オーバーレンジ保護
伝送器カタログの「オーバーレンジ保護圧力」を確認し、プロセス最大圧力がこれを超えないこと。超える場合は上位レンジに変更するか安全弁を設置する。

!!! danger "3弁マニホールドの弁操作順序（片側過圧に注意）"
    差圧伝送器に片側だけ圧力がかかる（片弁操作）と過差圧状態になり、ダイヤフラムを破損します。均圧弁（イコライザ）が開いている間は両室が短絡してダイヤフラムに差圧がかからない＝過差圧保護になるため、「均圧弁を閉じてから低圧側を開く」ことが鉄則です。

    運転投入（通液開始）手順:

    1. 初期状態を確認します（高圧側・低圧側の遮断弁は閉、均圧弁は開）。
    2. 高圧側遮断弁を開きます（均圧弁が開いているため差圧はゼロ、両室に均等に圧力がかかります）。
    3. 均圧弁を閉じます。
    4. 低圧側遮断弁を開きます（運転状態）。

    停止（取り外し）手順は逆順です: 低圧側遮断弁を閉 → 均圧弁を開 → 高圧側遮断弁を閉。

## 根拠

### 本ページが正典の範囲

- 圧力の種別（ゲージ／絶対／差圧／封圧）の区別・ダイヤフラム式伝送器の選定・ゼロトリム・過圧保護（スナッバー／サイフォン／3弁マニホールド操作）が本ページの範囲です。
- 4-20 mA ループ・HART・故障判定閾値の数値は [計装基礎](basics.md)、差圧流量計・オリフィスは [流量計測](flow.md)、導圧管の施工・配線は [計装配線](wiring.md) が正典です。本ページでは再記述しません。

### 一次計算で検算済み（2026-08-06）

- **ゲージ圧⇔絶対圧の換算例**: 0.5 MPaG + 0.101325 MPa = 0.601325 MPaA ≒ 0.601 MPaA（本文の丸め表示と一致）。標準大気圧 101.325 kPa は定義値です。
- **3弁マニホールドの弁操作順序**: 投入（HP 開 → 均圧閉 → LP 開）・停止（LP 閉 → 均圧開 → HP 閉）の全ステップで両室の圧力差を追い、どの時点でも片側過圧（過差圧）がダイヤフラムに掛からないことを論理検算しました（均圧弁が開いている間は両室短絡で差圧ゼロ）。

### 是正の記録（2026-08-06）

- **「封圧＝ダイヤフラムシール付き」の定義誤りを是正**: 封圧（シールドゲージ圧）は**基準室を封止した固定基準**の圧力種別であり、接液部の方式であるダイヤフラムシール（リモートシール）とは別概念です。圧力種別表の定義を改め、混同しない旨を注記しました。
- **高温流体でシールが必要な機序を是正**: 旧「伝送器電子回路が過熱する」→ 正しくは**接液部・封入液の耐熱上限**の問題です（電子回路は接液部から離れており、直接の制約は接液部側）。
- **ゼロトリムの適用条件を明示**: 「4.000 mA になることを確認」は LRV = 0 のゲージ圧レンジの場合に限る旨を追記し、**絶対圧伝送器を大気開放でゼロトリムすると約 0.1 MPa ずれた誤校正になる**危険を新規警告として追加しました。
- **標準大気圧の表記**: 「約0.101325 MPa」→ 101.325 kPa は標準大気圧の定義値、実大気圧は変動すると明記。

### 実務慣行（規格・法令の裏付けなし）

- 定常運転圧力をスパンの 30〜80% に置く選定目安、ダイヤフラムシール要否の 120℃ 目安、キャピラリー長片側 3 m 程度の目安は、実務慣行・メーカー推奨レベルの数値であり、規格の規定値として照合したものではありません。機種の仕様書・カタログ値が優先します。
- ダイヤフラム材質の選定表（SUS316L／ハステロイC-276／タンタル）は代表的な組み合わせの目安です。実選定はメーカーの耐食表と流体条件（濃度・温度）で確認してください。

### 限界の明示

- オーバーレンジ保護圧力・最大使用温度は機種のカタログ値が正であり、本ページには個別数値を書いていません。
- 圧力計測を法令要求（計量法のトレーサビリティ・高圧ガス設備の検査等）に使う場合の校正・検査の要件は本ページの範囲外です。
